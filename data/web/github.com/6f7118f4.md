# 使用本地llm和duckduckgo实现AI网页搜索助手

结合Llama 3.2构建强大的本地AI网页搜索助手：实时信息检索与上下文感知答案指南
- **方面介绍：**
    - 本地LLM集成：支持Llama.cpp或Ollama的本地执行。
    - 实时网页搜索：使用DuckDuckGo进行隐私保护搜索。
    - 网页抓取：通过抓取相关搜索结果获取丰富的上下文数据。
    - 自我改进搜索：能够优化查询词汇和时间范围进行多次搜索迭代。
    - 用户体验增强：使用多彩的动画控制台输出提升互动性。
    - 灵活的模型配置：支持多种指令模型的实验性配置。

- **实施步骤：**
    1. **克隆仓库和安装依赖**：
       - `git clone https://github.com/TheBlewish/Web-LLM-Assistant-Llamacpp-Ollama`
       - `cd Web-LLM-Assistant-Llamacpp-Ollama`
       - `pip install -r requirements.txt`

    2. **设置Ollama并下载必要模型**：
       - 启动Ollama服务器：`ollama serve`
       - 拉取模型：`ollama pull llama3.2` 和 `ollama pull nomic-embed-text`

    3. **更新配置**：
       - 在`llm_config.py`文件中更新模型名称为“llama3.2”。

    4. **运行Web-LLM助手**：
       - 运行脚本：`python3 WEB-LLM.py`

    5. **与助手交互**：
       - 输入以斜杠（/）开头的查询，从而触发网络搜索。
