# 使用llamaindex生成论文报告

- 离线阶段：
    1. 从arxiv上拉取论文pdf。
    2. 调用llamaparse将pdf解析为markdown文本。
        - 顺带提取元数据：作者、单位、领域标签
    3. 构建索引存储数据。
    4. 实例化query引擎。
    5. 提供报告大纲作为报告参考，RAG将逐步填充大纲所需的各个具体内容部分。。
    6. 提供函数工具供Agent使用。
        - classify_query：根据query内容将query路由为“ LLM ”或“INDEX”。
        - parse_outline_and_generate_queries：解析大纲并调用generate_query_with_llm为每个部分和小节生成query。
- 在线阶段：
    1. 根据大纲部分所需内容生成query来检索知识库。
    2. 根据知识库提供的内容生成大纲所需内容。
    3. 格式化所有内容成报告的格式。
