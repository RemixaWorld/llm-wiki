# 使用LLM结合兼容office办公文件格式的编辑器LibreWriter进行自动化文本生成

- **一句话描述：** 文章介绍了如何在LibreWriter中整合Ollama、GGUF和HuggingFace模型，以实现多语言的文本生成功能。
- **文章背景：** 随着人工智能技术的快速发展，利用大型语言模型（LLM）进行文本生成的需求逐渐增加，LibreWriter作为一个开源办公套件为用户提供了高效的写作工具。
- **文章主题：** 介绍如何在LibreWriter中使用LocalWriter插件整合Ollama及其他语言模型，产生高质量的文本输出。
- 3个部分：
    - **第1部分：**
        - **方面介绍：**
            - 整合Ollama模型与LibreWriter，用于生成各种类型的文本（故事、问答、代码、学术主题等）。
            - 支持多种语言生成，包括但不限于英语、法语、德语、西班牙语等。
        - **实施步骤：**
            1. 安装LibreOffice（支持Mac和Windows用户）。
            2. 从GitHub或LibreOffice网站下载LocalWriter插件。
            3. 在LibreOffice中打开下载的插件。
            4. 接受条款并启动LibreWriter。
            5. 连接Ollama，确保其在localhost:11434运行。
            6. 配置Ollama模型设置，包括选择模型和令牌。
            7. 输入问题并选择扩展以获取详细答案。
            8. 整合如Aya和Qwen2.5等其他模型。
    - **第2部分：**
        - **安装与配置说明：**
            1. 安装文本生成UI，使用命令：`git clone https://github.com/oobabooga/text-generation-webui.git`
            2. 启动文本生成UI，用命令下载相关依赖并提供WebUI。
            3. 获取喜欢的HuggingFace LLM模型的URL并下载。
            4. 在LibreWriter中配置本地模型接口的URL。
        - **实施步骤：**
            1. 克隆文本生成UI的代码库。
            2. 运行启动命令并访问提供的WebUI地址。
            3. 下载所需的HuggingFace模型。
            4. 修改LibreWriter的设置以连接到本地模型。
            5. 开始提问并获取生成的答案。
    - **第3部分：**
        - **方面介绍**：
            - 使用LibreWriter进行故事、问答、编程、学术主题等写作。
            - 支持多种语言，包括英语、法语、德语、中文等。
            - 整合Ollama、GGUF及HuggingFace模型以提升写作能力。
        - **实施步骤**：
            1. 将GGUF模型放入文本生成UI模型文件夹。
            2. 运行命令启动WebUI并下载依赖：
               - `./start_linux.sh --api`（Linux）
               - `./start_macos.sh --api`（Mac）
            3. 访问`http://localhost:7860`并选择模型。
            4. 从列表中选择支持的GGUF模型并加载。
            5. 在Notebook中测试GGUF模型的响应。
            6. 启动本地写作设置，整合Qwen2.5或Aya模型，并向其提问。
