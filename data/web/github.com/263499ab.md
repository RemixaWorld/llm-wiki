**Synthetic Data RL** fine-tunes language models using only synthetic data generated from a task definition. No human-labeled data required.

**Key Results on Qwen-2.5-7B:**

- GSM8K: 91.7% (+29.2% over base model)
- MATH: 72.0% (+8.7%)
- GPQA: 73.1% (+13.1%)
- MedQA: 64.5% (+8.9%)
- CQA (law): 92.4% (+17.7%)
- CFA (finance): 73.2% (+13.7%)

The system has 4 components:

**Passage Retriever**: Finds relevant text from Wikipedia/other sources**Data Generator**: Creates synthetic training examples using GPT-4**Data Re-writer**: Adjusts difficulty based on model performance**RL Trainer**: Fine-tunes the model on high-potential samples

**Extract keywords**from task definition → Retrieve relevant passages**Generate synthetic data**using task patterns and retrieved knowledge**Adjust difficulty**: Make harder/easier versions based on what model can solve**Train with RL**on samples where model shows partial understanding
