# 使用llamaindex构建可调用rag工具的agent，也即Agentic RAG模式

Agentic RAG答题类似该图：使用独立的Agent管理单个知识库，构成一个子系统，由主控TopAgent调度来决定驱动哪些子系统，子系统内部ToolAgent再自主决定如何根据给定的RAG工具来从所负责的知识库中检索回所需内容。
