# 使用llamaindex的PPT文档场景的contextual多模态RAG

这里提及的contextual可以理解为之前anthropic的那个RAG工作，就是将每个块处理成能独立表述的形式，也就是具备充足上下文信息的形式。
PPT其实是需要强上下文信息的，尤其是每页内容比较简短的情况下，要陈述清楚事情则需要结合其他页的内容来看，所以这是个需要contextual retrieval的场景。  
主要策略是：
- 离线
    1. 用llamaparser来解析ppt（实则为.pdf文件）文档。
    2. TextNode对象的metadate存储解析得到的图片的路径、解析得到的纯文本、页码之类的。
    3. 使用llm根据全部上下文，改写每个TextNode的纯文本，使其具备足够的上下文陈述信息，然后这个上下文陈述又可存入metadata中。
    4. 对处理好的TextNode进行embedding并index化。
- 在线
    1. 照常使用检索即可。
