# GraphRAG的本地化、简化实现可用于学习理解GraphRAG的Nano GraphRAG

通过与Ollama的集成，Nano GraphRAG实现了对GraphRAG的简化，使得用户可以更有效地利用本地大型语言模型（LLM）。

- 关键点：
    - **RAG（检索增强生成）**：结合LLM与外部知识源，用于改善模型的上下文理解。
    - **GraphRAG**：通过图形索引技术，捕捉实体及其关系，解决传统RAG的局限性。
    - **Nano GraphRAG**：轻量级、简化的GraphRAG版本，旨在提高集成与使用的效率。
- 方面介绍：
    - RAG工作原理：
        - 将私有数据拆分成小块并转化为数值嵌入。
        - 通过向量数据库存储并在查询时进行检索。
    - GraphRAG的两个阶段：
        - 实体提取与关系识别。
        - 背景总结与生成。
- 实施步骤：
    1. 克隆代码库并安装依赖：
       - `git clone https://github.com/gusye1234/nano-graphrag.git`
       - `cd nano-graphrag`
       - `pip install -e .`
    2. 修改示例脚本更新参数。
    3. 定义查询函数获取响应。
    4. 定义插入函数读取并索引内容。
    5. 生成嵌入函数以使用Ollama生成嵌入向量。
    6. 运行脚本进行数据索引和查询测试。
