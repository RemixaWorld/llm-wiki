# 使用llamaindex的workflows实现Agentic形式的RFP（标书）内容生成

- 离线：
    1. 读取有助于RFP内容撰写的本地文档（企业年度报告、企业官网页面、企业百科页面、有关部门或甲方的PPT）。
    2. 使用llamaparser解析文档（其中视觉内容使用多模态模型来进行内容提取）。
    3. 后续每个文档文件会被转换成“工具”，所以要为每个文档文件生成摘要，这个摘要将被用作“工具描述”，此将决定在何时调用该工具（文档）用作检索。——这就是AgenticRAG的核心思想。
    4. 进行embedding并构建index。
- 在线：
    1. 用户提供RFP模板。
    2. 使用llamaparser解析RFP模版，实际上就是从中检测出需要填写的key-value对。
    3. 调用AgenticRAG来检索相关知识库，填写所需key-value内容。
    4. 将补充完整的key-value对与模版一起传给llm生成最终报告。
