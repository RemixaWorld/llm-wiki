# 模型使得LLM预测的概率分布高熵时使用pause token促使模型不断持续思考直到取得低熵（top2的概率差值大过某个阈值）才输出的解码方法Entropix

当我们需要LLM输出确定答案时，往往会选择贪婪解码，即将温度参数设置得极低，概率分布变得尖锐，从而取得“一厢情愿”的确定性答案，但其实这个有点“屈打成招”的意味，因为这个概率分布本身就是模型自己给出的信心，如果一昧拔高高置信项，那么其实是在促成“模型过度自信”。所以需要考虑其他更加自发的、本质的方法来获得所谓确定性答案。  
谷歌的论文证明了LLM具有内部推理能力，并不一定需要cot之类的显式陈述才能实现系统2推理，所以可以考虑这个性质，在LLM预测的概率分布出现高熵（分布平坦）的时候，强制让其思考，直到分布不再过于平坦（即1st token和2nd token的概率差值比较大）为止。
