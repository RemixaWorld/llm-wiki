# 使用fastapi_mcp快速将FastAPI服务转换并启动成MCP服务器

**目标**  
将基于 FastAPI 的 ML API 转换为功能完整的 **Model Context Protocol (MCP)** 服务器。

**项目示例**  
使用 Hugging Face 的电气工程领域 **命名实体识别（NER）** 模型（`disham993/electrical-ner-bert-base`），提取以下实体：  
- 产品、组件、设计参数  
- 材料、标准、供应商等  

**实施步骤**  

1. **环境准备**  
   - 克隆仓库：`https://github.com/di37/nlp-fastapi-mcp-server`  
   - 创建虚拟环境并安装依赖项。  

2. **代码解析（`main.py`）**  
   - **基础配置**  
     - 导入库：FastAPI、CORS 中间件、`FastApiMCP`（MCP 适配层）、NER 模型工具类。  
   - **FastAPI 应用定义**  
     - 初始化 `FastAPI` 实例，配置 CORS 允许跨域请求。  
   - **定义端点**  
     - `/all_entities`：返回所有支持的实体类型。  
     - `/predict`：接收用户输入文本，调用 NER 模型提取实体，并返回结构化结果（成功/失败状态、实体列表）。  
   - **挂载 MCP 层**  
     - 通过 `FastApiMCP` 将 FastAPI 转换为 MCP 服务器，仅需两行代码：  
       ```python
       mcp = FastApiMCP(app, include_operations=["extract_entities", "get_all_entities"])
       mcp.mount()
       ```  
     - 使用 Uvicorn 启动服务（端口 5152）。  

3. **连接 Cascade（Windsurf IDE）**  
   - 快捷键 `CTRL/Command + L` 打开 Cascade。  
   - 安装 MCP 插件后，在配置文件中添加 MCP 服务器地址：  
     ```json
     "mcpServers": {
       "electrical-ner-mcp": {
         "serverUrl": "http://localhost:5152/mcp"
       }
     }
     ```  
   - 绿色图标表示连接成功。  

**MCP 的优势**  
- **自然语言调用**：无需手动构造 JSON，直接用英文描述请求。  
- **自动发现与文档**：MCP 暴露工具元数据（名称、参数、描述），供智能代理动态调用。 
- **跨平台兼容性**：支持所有 MCP 客户端（如 Microsoft Copilot、Cursor）。  
- **可组合的工作流**：提取的实体可直接用于下游任务，无需中间处理。  
- **简化架构**：单一 MCP 接口替代多个定制化连接器。  
- **安全部署**：支持本地或云部署（AWS/Azure），可集成 OAuth 认证。
