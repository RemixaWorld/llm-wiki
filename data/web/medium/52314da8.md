I was creating a podcast generator and needed a TTS (text-to-speech) solution that could produce speech as close to natural as possible. In my search for free frameworks, models, and libraries that could convert text to speech, I encountered several options. However, many produced robotic, unnatural-sounding voices. The ones that worked well often had limitations and eventually required payment. Then, I discovered a Hugging Face space that truly delivered on quality — it’s called Parler-TTS.

Parler-TTS is a reproduction of work from the paper [Natural language guidance of high-fidelity text-to-speech with synthetic annotations](<https://www.text-description-to-speech.com/>) by Dan Lyth and Simon King, from Stability AI and Edinburgh University respectively. It produces high quality, noise free and natural sounding voices and that too completely for free since it is fully open-sourced and can run locally on device offline. It has 2 models:

Parler-TTS Mini, an 880M parameter model.

Parler-TTS Large, a 2.3B parameter model.

Both of them are trained on audiobook data. The Parler-TTS Mini comes in another variant named Parler-TTS Jenny that is fine-tuned on the jenny dataset.

We control various aspects of the generated speech of the any TTS model by adjusting some parameters like pitch, gender, reverberation, speaking rate, etc. in different ways:

**By modifying the properties using methods (for pyttsx3):**

```python import pyttsx3engine = pyttsx3.init()def set_rate(rate=200): engine.setProperty('rate', rate)def set_volume(volume=1.0): engine.setProperty('volume', volume)def set_gender(gender='male'): voices = engine.getProperty('voices') if gender == 'female': engine.setProperty('voice', voices[1].id) # female voice else: engine.setProperty('voice', voices[0].id) # male voiceset_rate(150) set_volume(0.9) set_gender('female') engine.save_to_file("Hello, this is Satyajeet.", 'output_audio.wav')engine.runAndWait() ```

**By defining the audio output parameters in the class objects (for texttospeech by Google Cloud):**

```python from google.cloud import texttospeechclient = texttospeech.TextToSpeechClient()text_input = texttospeech.SynthesisInput(text="Hello, I hope you're having a great day!")voice = texttospeech.VoiceSelectionParams( language_code="en-US", name="en-US-Wavenet-D", ssml_gender=texttospeech.SsmlVoiceGender.MALE,)audio_config = texttospeech.AudioConfig( audio_encoding=texttospeech.AudioEncoding.MP3, speaking_rate=1.2, pitch=5.0, volume_gain_db=-1.0 )response = client.synthesize_speech( input=text_input, voice=voice, audio_config=audio_config)with open("output.wav", "wb") as out: out.write(response.audio_content) print("Audio content written to file 'output.wav'") ```

But for Parler-TTS, the way to set the parameters is something that really stands out.

**Using text prompt to modify the properties (for Parler-TTS):**

```python import torchfrom parler_tts import ParlerTTSForConditionalGenerationfrom transformers import AutoTokenizerimport soundfile as sfdevice = "cuda:0" if torch.cuda.is_available() else "cpu"model = ParlerTTSForConditionalGeneration.from_pretrained("parler-tts/parler-tts-mini-v1").to(device)tokenizer = AutoTokenizer.from_pretrained("parler-tts/parler-tts-mini-v1")prompt = "Hey, how are you doing today?"description = "A female speaker delivers a slightly expressive and animated speech with a moderate speed and pitch. The recording is of very high quality, with the speaker's voice sounding clear and very close up."input_ids = tokenizer(description, return_tensors="pt").input_ids.to(device)prompt_input_ids = tokenizer(prompt, return_tensors="pt").input_ids.to(device)generation = model.generate(input_ids=input_ids, prompt_input_ids=prompt_input_ids)audio_arr = generation.cpu().numpy().squeeze()sf.write("parler_tts_out.wav", audio_arr, model.config.sampling_rate) ```

In the above code the following part sets the properties for the output:

``` description = "A female speaker delivers a slightly expressive and animated speech with a moderate speed and pitch. The recording is of very high quality, with the speaker's voice sounding clear and very close up." ```

For many other libraries, like pyttsx3 and Google Cloud Text-to-Speech, setting properties like voice, speed, volume, and gender can be somewhat tedious. It requires knowing and specifying individual parameters through functions or accessing documentation for various configurations (e.g., language_code, ssml_gender, etc.). This often involves either remembering or looking up the correct property names and values, making the process a bit more involved.

However, when using Parler TTS, setting properties is much easier and more intuitive. Instead of explicitly setting each property (like pitch, speed, or gender) through separate functions or configurations, you just describe the speech characteristics (e.g., “A female speaker delivers a slightly expressive and animated speech…”). Parler TTS processes this natural language description and adjusts the generated speech accordingly. This makes the process more straightforward and user-friendly, such that even a non-technical person can use it.

There are multiple voices supported, as parler-tts-mini-v1 was also trained on 34 speakers, characterized by name. So, instead of a male or female speaker (which generates a random voice), there are names like Jon, Lea, Gary, Jenna, Mike, Laura, etc. that can be used to get a different speaker.

Example:

``` description = "Jon's voice is monotone yet slightly fast in delivery, with a very close recording that almost has no background noise." ```

Note: Since this is a text prompt, sometimes when the same prompt is run, I have seen some minor inconsistencies in the audio output.

## Improving model speed and streaming

It takes a considerable amount of time to run this model on CPU only. Hence, a GPU is preferred. If you do not have GPU, Google Colab or Kaggle notebook can be helpful.

There are a number of optimizations that can make the model up to 4x faster. We can also stream audio as it’s being generated, and we can achieve time-to-first audio in under 500ms on a modern GPU.

Find a guide and code to do so [here](<https://github.com/huggingface/parler-tts/blob/main/INFERENCE.md>).
