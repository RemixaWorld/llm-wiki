In the current phase of autonomous AI agents, where systems are designed to reason, decide, and act independently, one critical aspect often remains underemphasized — **evaluation**. Building agents that can intelligently use tools and make decisions is only half the journey; ensuring that these agents are accurate, reliable, and performant is what truly defines their success. Agent Evaluation is not just a validation step — it is the foundation that builds trust and confidence in your agentic workflows.

### The Overview Of the Experiment

The core intent of this experiment is to systematically evaluate AI agents powered by `Agno` through a structured assessment of their `**Accuracy** , **Performance** , and **Reliability**`, ensuring these agents are not only operational but also trustworthy and production-ready. While most agentic systems focus on building reasoning workflows and multi-tool orchestration, the real value lies in understanding how well these agents perform against measurable metrics. This experiment was designed to close that critical gap by building an evaluation loop where a user query is processed by the AI agentic team, and the outcomes are published as observable metrics for the user to analyze. The architecture clearly reflects this closed feedback system, where evaluation is not an afterthought but an integral part of the agent lifecycle.

The evaluation methodology leverages `Agno Evals` to decompose the agent assessment into three focused layers. The **accuracy evaluation** measures how well the agent’s responses align with the expected answers across different scenarios, presenting a clear statistical breakdown through mean, max, min, standard deviation, and average scores. This quantitative measurement eliminates subjectivity and provides a transparent view of the agent’s reasoning capabilities. Complementing this, the **performance evaluation** captures critical operational metrics like memory consumption and response time, offering insights into the resource efficiency of the agentic workflow. These metrics ensure that the agent is not only correct but also optimized in terms of runtime behavior and scalability potential. The **reliability evaluation** focuses on the agent’s ability to make correct tool calls consistently, ensuring that the agent follows the designed reasoning path and tool usage logic without deviation. Here, each query is evaluated for pass or fail status along with the count of tool calls involved, giving a clear picture of the agent’s operational stability.

The entire setup is backed by a clean modular code structure where individual scripts handle specific evaluation tasks like accuracy, performance, and reliability, and results are stored as JSON documents in mongodb for reproducibility and traceability. These outputs are then visualized through intuitive dashboards that make the metrics easily consumable, helping developers and stakeholders observe trends, outliers, and improvement areas at a glance. Through this experiment, the focus shifts from just building agents to `**building agents that can be trusted**`, reinforcing the idea that rigorous evaluation is the true backbone of successful agentic systems. The outcomes of this experiment not only validate the effectiveness of the agents but also pave the way for continuous improvement cycles, where agents evolve based on data-driven feedback rather than assumptions.

### The Accuracy Evaluation

This below code defines the function `evaluate_agent_accuracy`, which evaluates the correctness of an AI agent’s response against an expected answer using the **Agno Evals framework**. The function takes a `question` and its `expected_answer`, and leverages **Claude** as the evaluator model (acting as the judge) and **OpenAI GPT-4.1** as the agent that generates the answer.

```python from textwrap import dedentfrom typing import Optional, List, Anyfrom agno.agent import Agentfrom agno.eval.accuracy import AccuracyEval, AccuracyResultfrom agno.models.openai import OpenAIChatfrom agno.models.anthropic import Claude# from agno.tools.thinking import ThinkingTools# from agno.tools.reasoning import ReasoningToolsfrom dotenv import load_dotenv, find_dotenvload_dotenv(find_dotenv())results:List[Any] = []def evaluate_agent_accuracy(question: str, expected_answer: str) -> None: evaluation = AccuracyEval( model=Claude(id="claude-3-7-sonnet-20250219"), question=question, expected_answer=expected_answer, num_iterations=1, debug_mode=True, evaluator_context=dedent("""\ You are a Math EvaluatorX with a huge knowledge on high school math and university math. Your job is to evaluate the answer given by the Agent and the expected answer and finally return the accuracy score.\ """), agent=Agent( model=OpenAIChat(id='gpt-4.1'), system_message='Be concise, Always respond with one sentence.', description=dedent("""\ You are a Math professorX with a huge knowledge on high school math and university math. Your job is to analyse, compute and answer the given math problem with proper output with explanation.\ """), instructions=dedent("""\ As a Math professorX while solving the given problem you need to follow the given rules. Rules: ------- 1. First properly analyse and understand the given problem 2. Think twice and Frame your solution for the problem given 3. Solve the problem according to the solution framed in the step 2 4. Finally give the out of the problem in a explainable mode along with final answer.\ """) ) ) result: Optional[AccuracyResult] = evaluation.run(print_results=True) results.append({ "mean score": result.mean_score, "min score": result.min_score, "max score": result.max_score, "std dev score": result.std_dev_score, "avg score": result.avg_score }) ```

The evaluator is guided by a clear context that defines its role as a math expert, while the agent is shaped through a system message, description, and structured instructions to ensure a thoughtful and explainable problem-solving approach. The evaluation is executed using the `AccuracyEval` class, which compares the agent’s output with the expected answer and produces key scoring metrics like mean, min, max, standard deviation, and average score.

The results from each evaluation run are collected into the global `results` list, allowing the scores to be tracked and analyzed for multiple questions. This setup offers a simple yet effective way to quantify the agent’s reasoning quality through structured, model-driven accuracy evaluation.

### The Performance Evaluation

The below code function `wrapper(question: str)` defines an inner function `evaluate_agent_performance`, which sets up the AI agent using **OpenAI GPT-4.1** (`OpenAIChat`) as the reasoning engine. The agent is configured with a system message to keep responses concise and with `add_history_to_messages=True` to maintain conversational context if needed. The `agent.run(message=question)` call triggers the agent to process the given question. The wrapper ensures that the question context is bound to the evaluation function when called.

```python from typing import List, Anyfrom agno.agent import Agentfrom agno.models.openai import OpenAIChatfrom agno.eval.perf import PerfEvalfrom dotenv import load_dotenv, find_dotenvload_dotenv(find_dotenv())results:List[Any] = []def wrapper(question: str): def evaluate_agent_performance() -> None: agent = Agent(model=OpenAIChat(id='gpt-4.1'), system_message='Be concise, reply with one sentence.', add_history_to_messages=True ) agent.run(message=question) return evaluate_agent_performance ```

The main performance evaluation is conducted using the `**PerfEval**` class, which wraps the agent's execution logic (using the `wrapper`) and measures performance across one iteration (`num_iterations=1`) with no warmup runs. This evaluation captures several performance metrics, including:

* **Memory usage:** max, min, average, and 95th percentile (`p95`)
* **Run time:** min, max, average, and 95th percentile (`p95`)

The results of each evaluation are appended to the global `results` list as structured dictionaries for later analysis or visualization.

If any error occurs during the evaluation of a question, the exception is caught, and a failure status is logged into the results with placeholders for tool call data (though tool calls aren’t directly evaluated in this performance-specific script).

### The Reliability Evaluation

This code focuses on **evaluating the reliability** of an AI agent by verifying whether it correctly uses the available tools to solve a given problem. The agent is powered by **OpenAI GPT-4.1** and is equipped with the **CalculatorTools** , enabling it to perform mathematical operations whenever required.

The core function `evaluate_agent_reliability` takes a `question` as input and initializes the agent with specific instructions that clearly inform it about the presence of tools and encourage the intelligent use of these tools when necessary. The agent is configured with a retry mechanism (`retries=3`), allowing it to attempt the task multiple times if initial tool calls fail.

```python from typing import Optional, List, Anyfrom agno.agent import Agentfrom agno.eval.reliability import ReliabilityEval, ReliabilityResultfrom agno.models.openai import OpenAIChatfrom agno.tools.calculator import CalculatorToolsfrom agno.run.response import RunResponsefrom dotenv import load_dotenv, find_dotenvimport logginglogging.basicConfig(level=logging.INFO)logger = logging.getLogger(__name__)load_dotenv(find_dotenv())results:List[Any] = []def evaluate_agent_reliability(question: str) -> None: agent=Agent( model=OpenAIChat(id="gpt-4.1"), instructions="Be Informed that you have set of tools, using which you can accomplish certain tasks. " "Use the tools accordingly as per your intelligence.", tools=[CalculatorTools(enable_all=True)], retries=3 ) response: RunResponse = agent.run(message=question) evaluation = ReliabilityEval( agent_response=response ) result: Optional[ReliabilityResult] = None try: result = evaluation.run() print(result) results.append({ "eval_status": result.eval_status, "passed_tool_calls": result.passed_tool_calls, "failed_tool_calls": result.failed_tool_calls }) except Exception as e: raise ```

The agent processes the input question through the `agent.run()` method, which generates a `RunResponse` containing the agent’s output and any tool interactions made during the response generation. This response is then passed to `ReliabilityEval`, which acts as the evaluator, checking whether the agent used the tools correctly as per the problem requirements.

The evaluation result, of type `ReliabilityResult`, includes key reliability metrics such as the **evaluation status** (`eval_status`), the list of **passed tool calls** , and any **failed tool calls**. These results are appended into the global `results` list, storing the evaluation outcome for each question.

If the evaluation process encounters any exception, it is captured in the exception handling block. In such cases, a failure entry is recorded into the results with `FAILED` status and empty tool call details, ensuring that every question's reliability assessment is logged, even in the case of execution errors.
