## How It Works: Nerd Level 9000 🚀

Now, let’s break down the code that makes this happen. We’re using some cool libraries here, like FAISS for indexing, the **sentence-transformers** model to understand documents, and **Ollama’s LLM** to generate answers based on your files.

I’ll walk you through the important parts of this setup because, let’s be honest, _it’s all about the details_. 🧐

## 1\. Getting the Basics Set Up🛠️

```python import osimport faissimport numpy as npfrom sentence_transformers import SentenceTransformerimport PyPDF2import docxfrom pptx import Presentationimport jsonimport streamlit as stimport ollama ```

We’re importing all the cool libraries:

* **FAISS** : Our nerdy indexing champion, handling fast similarity search.
* **SentenceTransformer** : To create those sweet embeddings from your files.
* **PyPDF2** , **docx** , **pptx** : Because we want to handle all file types like a pro.
* **Streamlit** : To give it a nice UI that even non-nerds can use.
* **Ollama** : For generating awesome AI-powered responses.

## 2\. Initialize the Search Engine’s Brain 🧠

``` model = SentenceTransformer('sentence-transformers/msmarco-bert-base-dot-v5')dimension = 768index = faiss.IndexFlatIP(dimension)metadata = [] ```

Here’s where the magic starts! We’re loading up a pre-trained **BERT model** to convert your documents into meaningful vectors. Then we set up **FAISS** to perform some cool inner-product (IP) magic to compare these vectors and find similar chunks of text.

* **768 dimensions** : That’s how many dimensions our vectors will have. It’s like saying each text chunk has 768 characteristics to compare.
* **FAISS Index** : The powerhouse to store and search through these vectors.

## 3\. Reading All Your Nerdy Files📁

Now we need to grab content from your local PDFs, DOCXs, PPTs, and plain text files.📄🗂️

```python def read_pdf(file_path): with open(file_path, 'rb') as file: reader = PyPDF2.PdfReader(file) return ' '.join([page.extract_text() for page in reader.pages])def read_docx(file_path): doc = docx.Document(file_path) return ' '.join([para.text for para in doc.paragraphs])def read_pptx(file_path): prs = Presentation(file_path) return ' '.join([shape.text for slide in prs.slides for shape in slide.shapes if hasattr(shape, 'text')]) ```

Each file type has its own special reading function 📚. We loop through the content, extract the text, and prepare it for indexing 📜.

## 4\. Chunking Text Like a Pro✂️

We need to split documents into smaller chunks for effective search results. Here’s how:

```python def chunk_text(text, chunk_size=500, overlap=50): words = text.split() chunks = [] for i in range(0, len(words), chunk_size - overlap): chunks.append(' '.join(words[i:i + chunk_size])) return chunks ```

This function splits the text into **500-word chunks** (with a slight overlap), making sure our search results are detailed yet manageable.

## 5\. Indexing All the Nerdy Data📊

This is where the magic happens! We index every chunk of text so it can be searched later.

```python def index_documents(directory): global metadata documents = [] for root, _, files in os.walk(directory): for file in files: content = "" if file.endswith('.pdf'): content = read_pdf(file_path) elif file.endswith('.docx'): content = read_docx(file_path) elif file.endswith('.pptx'): content = read_pptx(file_path) if content: chunks = chunk_text(content) for i, chunk in enumerate(chunks): documents.append(chunk) metadata.append({"path": file_path, "chunk_id": i}) embeddings = model.encode(documents) index.add(np.array(embeddings)) ```

You give it a query like “What’s my project deadline?” and the engine responds with relevant chunks from your files — even if you didn’t use the word “deadline” in the file. The magic of AI, right?

* **Index Documents** : It reads the files, splits them into chunks, and embeds them using our BERT model.
* **FAISS Index** : We store all the embeddings in FAISS so it can handle the search queries efficiently.

## 6\. The Search Wizardry🔍

When you type a search query, here’s how the engine searches through your files:

```python def semantic_search(query, k=10): query_vector = model.encode([query])[0] distances, indices = index.search(np.array([query_vector]), k) results = [] for idx in indices[0]: meta = metadata[idx] content = read_document_chunk(meta["path"], meta["chunk_id"]) results.append({"path": meta["path"], "content": content}) return results ```

* **Semantic Search** : We convert your search query into an embedding, compare it against all the document embeddings, and return the closest matches.
* **Top-K** : You get the top 10 results based on similarity!

## 7\. Generating Answers with AI🤖💬

You can ask for an answer and our little AI buddy (using **Ollama**) generates a response, citing the exact document chunks it referenced. Here’s how:

```python def generate_answer(query, context): prompt = f"""Answer the user's question using the documents given in the context...""" response = ollama.generate(model='tinyllama', prompt=prompt) return response['response'] ```

It reads through your indexed files and pulls out the relevant content to craft an intelligent answer. **Boom** — you’ve got yourself a smart, nerdy assistant!

## 8\. The Streamlit UI Magic🎨✨

Finally, we’ve got a UI powered by **Streamlit**. It makes the whole thing look cool and easy to use.

```python def main(): st.markdown('<p class="big-font">Local GenAI Search 🔍</p>') documents_path = st.text_input("📁 Enter the path to your documents folder:") if st.button("🚀 Index Documents"): index_documents(documents_path) question = st.text_input("🤔 What would you like to know?") if st.button("🔍 Search and Answer"): search_results = semantic_search(question) answer = generate_answer(question, search_results) st.markdown(f"### 🤖 AI Answer:
{answer}") ```

* **Input fields** : For entering your document folder path and questions.
* **Search button** : To let the engine search your indexed files.
* **Answer display** : Shows the AI’s response along with the relevant documents.
