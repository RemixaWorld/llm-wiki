### Getting Started with Cody

Open VSCode, navigate to ‘Extensions’ tab and search for ‘Cody’.

Find ‘Cody AI’ in search results and install the ‘Pre-release version’

Press enter or click to view image in full size

It will then ask you to sign-in, I will use my Gmail account.

Select your purpose of use

Press enter or click to view image in full size

Then authorize Cody and copy your VSCode extension token

Once it’s authorized, it will open VSCode again and we are ready to start — voila!

By default, Cody uses gpt-4 and it’s free till February, and then will be $9/month, which is not bad at all considering all of its features.!

## Running Cody with Local LLM using Ollama

Next, open your browser and navigate to Ollama.ai and install Ollama for your system, it’s available for macOS and Linux. Since I’m using WSL 2 on Windows, I’ll setup the linux version.

Which will take a few seconds to complete.

Press enter or click to view image in full size

## Setting up Code Llama 7B

To start working with Ollama, we first need to start the Ollama server by running:

``` ollama serve ```

Press enter or click to view image in full size

Then in another terminal, run:

``` ollama pull codellama:7b-code ```

which will start downloading the Code Llama 7B.

Press enter or click to view image in full size

While it’s downloading, let me briefly explain you the capabilities of Code Llama 7B.

Code Llama is a specialized version of Llama 2, that is trained extensively on code-specific datasets, offering superior coding abilities. It’s designed to understand and generate code, as well as natural language explanations about code, in response to both code and natural language prompts.

Press enter or click to view image in full size

Code Llama is also adept at code completion and debugging. It supports a wide range of popular programming languages, including Python, C++, Java, PHP, Typescript (Javascript), C#, and Bash, which makes a perfect LLM for our use-case!

OK, model is ready to use.

Press enter or click to view image in full size

Now, navigate to the ‘Settings’ of Cody

And click ‘Cody Extension Settings’

Press enter or click to view image in full size

Scroll down and find ‘Cody > Autocomplete > Advanced: Provider’, and select ‘unstable-ollama’

Press enter or click to view image in full size

Great, let’s test it!

## Getting Familiar with Cody Commands

If you navigate back to Cody extension, you can see that there are several commands you can run:

Press enter or click to view image in full size

* Chat, to chat with Cody using provided LLMs such as Claude, ChatGPT and Mixtral
* Document, to add documentation to code.
* Edit, to edit code with instructions
* Explain, to explain code snippets or entire files
* Smell, to identify code smells
* Test, to write unit tests
* Custom, to introduce custom commands
