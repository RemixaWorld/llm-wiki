## What Are We Building?

Our goal is to create a **Retrieval-Augmented Generation (RAG)** system. Here’s what it will do:

1. **Users upload a PDF file** : We extract its contents for processing.
2. **Users ask questions** : A chatbot answers them based on the content of the PDF.
3. **Relevant text is highlighted in the PDF** : When the chatbot finds an answer, it highlights the matching text in the document.

## Key Concepts

Before jumping into the code, let’s cover some important terms:

* **Streamlit** : A Python library that lets you create web applications with simple Python code. It’s perfect for building interactive UIs.
* **RAG (Retrieval-Augmented Generation)** : Combines information retrieval with text generation. The system first retrieves relevant information from a document, then uses a language model to generate answers based on that information.
* **PDF Annotations** : Highlights or marks certain parts of a document, helping users see relevant sections.
* **Embeddings** : A way to represent text (like sentences or paragraphs) as numbers so that similar texts have similar representations. This allows us to search for related text more effectively.
* **FAISS** : A library that enables fast search of similar text embeddings, making it easier to find related information in large documents.
* **PyMuPDF (Fitz)** : A Python library used to read and manipulate PDFs, including searching for specific text within the document.

## Step 1: Setting up the User Interface with Streamlit

We start by creating a web interface where users can upload a PDF file. **Streamlit** makes this process super simple. Here’s how:

``` st.set_page_config(page_title="📚 ChatPDF")st.markdown("<h1 style='text-align: center;'>📚 ChatPDF</h1>", unsafe_allow_html=True)st.subheader("Upload a document to get started.") ```

* `**set_page_config**`: Sets the title of the page that will appear on the browser tab.
* `**markdown**`: Adds a heading with an icon (📚) to give a polished, friendly appearance.
* `**subheader**`: Provides a brief instruction for the user to upload their PDF.

This sets up a minimalistic yet engaging user interface.

## Step 2: Uploading and Extracting the PDF

The next step is to allow users to upload a PDF file. Once uploaded, we need to extract the content of the PDF for further processing. We use a library called **PyPDFLoader** for this purpose.

```python def extract_documents_from_file(uploaded_file): with tempfile.NamedTemporaryFile(delete=False) as temp_file: temp_file.write(uploaded_file.read()) loader = PyPDFLoader(temp_file.name) documents = loader.load() os.unlink(temp_file.name) return documents ```

Here’s a breakdown of what happens:

* `**uploaded_file.read()**`: Reads the content of the uploaded PDF.
* `**tempfile.NamedTemporaryFile**`: Temporarily stores the PDF on disk so we can process it.
* `**PyPDFLoader**`: Loads the PDF and extracts its text into a format we can process.

This function returns the document’s text, which we will later use to answer user questions.

## Step 3: Chunking the Document for Better Search

Large documents can be overwhelming for an AI to process in one go. That’s why we break the document into smaller **chunks**. Each chunk is a smaller part of the document, making it easier to retrieve relevant sections.

``` text_splitter = CharacterTextSplitter(chunk_size=512, chunk_overlap=0)text_chunks = text_splitter.split_documents(documents) ```

* `**CharacterTextSplitter**`: Splits the document into chunks of 512 characters each. This ensures each chunk is small enough to process but large enough to capture useful information.
* `**split_documents**`: Applies the splitter to the extracted document.

By splitting the document into smaller chunks, we make it easier for our AI model to find relevant information.

## Step 4: Embeddings — Turning Text into Numbers

Now that we have chunks of text, we need to represent them in a way that the AI can understand. This is where **embeddings** come in. Embeddings are mathematical representations of text, where similar texts have similar numerical representations.

``` embeddings = OllamaEmbeddings( model="nomic-embed-text", base_url="http://localhost:11434") ```

* `**OllamaEmbeddings**`: This is the model that converts text into embeddings. We use a model called "nomic-embed-text", which is designed to create embeddings suitable for text search.
* **Embeddings in a Nutshell** : Think of embeddings as a way to convert a paragraph into a series of numbers (like coordinates in a high-dimensional space). Similar paragraphs will have similar coordinates, making it easy to compare them.

These embeddings will later be used to search the document for relevant text.

## Step 5: Storing Embeddings with FAISS

Once the text is converted into embeddings, we need to store these embeddings somewhere for efficient search. This is where **FAISS** comes in.

```json vector_store = FAISS.from_documents(text_chunks, get_embeddings())retriever = vector_store.as_retriever( search_type="mmr", search_kwargs={"k": 2, "fetch_k": 4}) ```

* `**FAISS.from_documents**`: Creates a **vector store** from the document chunks. This store allows us to quickly search through all chunks of the document.
* `**retriever**`: The retriever is responsible for finding the most relevant chunks when a user asks a question.
* `**search_type="mmr"**`: We use **Maximum Marginal Relevance (MMR)** , a search method that balances relevance and diversity, ensuring we get diverse but useful results.

In simpler terms, FAISS helps us search through a large number of chunks and find the ones that best match the user’s question.

## Step 6: Setting Up the Question-Answering System (RAG)

Now that we can retrieve relevant text, we need a way to answer user questions. This is where **Langchain** and **ChatGroq** come into play. **Langchain** helps us connect different components (like the retriever and the language model) to create a seamless **RAG** system.

```json qa_system = RetrievalQA.from_chain_type( initialize_language_model(), chain_type="stuff", retriever=retriever, return_source_documents=True, chain_type_kwargs={"prompt": CUSTOM_PROMPT},) ```

* `**RetrievalQA.from_chain_type**`: Combines the retriever (which finds relevant text) and the language model (which generates an answer based on that text).
* `**initialize_language_model()**`: Loads the **ChatGroq** language model, which generates the final answers based on the retrieved information.
* `**return_source_documents=True**`: Ensures the system returns the specific parts of the document that were used to generate the answer.

This system allows users to ask questions, and the model will respond with answers based on the contents of the PDF.

## Step 7: Chat Interface — User Interaction

The chat interface allows users to ask questions and get real-time answers. Every time the user submits a question, we process the input, pass it through the **RAG** system, and display the response.

```json if user_input := st.chat_input("Your message"): result = qa_system.invoke({"query": user_input}) parsed_result = json.loads(result['result']) answer = parsed_result['answer'] sources = parsed_result['sources'] st.chat_message("assistant").write(answer) ```

* `**st.chat_input**`: This is the chat box where users type their questions.
* `**qa_system.invoke**`: Passes the user’s question to the RAG system to generate a response.
* `**st.chat_message("assistant").write(answer)**`: Displays the generated answer in the chat window.

## Step 8: Highlighting the Relevant Text in the PDF

Once the system generates an answer, we also highlight the parts of the PDF that contain the relevant information. This helps the user see exactly where the answer came from.

```python def generate_highlight_annotations(document, excerpts): annotations = [] for page_num, page in enumerate(document): for excerpt in excerpts: for inst in page.search_for(excerpt): annotations.append({ "page": page_num + 1, "x": inst.x0, "y": inst.y0, "width": inst.x1 - inst.x0, "height": inst.y1 - inst.y0, "color": "red", }) return annotations ```

* `**page.search_for(excerpt)**`: Searches for the exact location of the relevant text in the PDF.
* `**annotations.append(...)**`: Creates a list of coordinates where the text should be highlighted.

These annotations are then rendered on the PDF using Streamlit.

## Final Output — Putting it All Together

After setting up all the components, we render the PDF with the highlighted excerpts and provide navigation controls for users to browse through the pages.

``` pdf_viewer( file, width=700, height=800, annotations=annotations, pages_to_render=[first_page_with_excerpts],) ```

This creates an interactive PDF viewer where users can upload documents, ask questions, and see the answers highlighted in real-time.
