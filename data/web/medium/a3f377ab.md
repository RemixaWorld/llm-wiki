## Introduction

Random Forests are a type of ensemble learning algorithm that uses multiple decision trees to make predictions. Ensemble learning is a machine learning paradigm where multiple models are combined together to produce a more accurate and robust model. Random Forests are one of the most popular ensemble learning algorithms, and they are widely used in a variety of machine learning tasks, including classification and regression.

## How it works: Bootstrapping & Bagging

Let’s introduce two concepts: bootstrapping and bagging.

**Bootstrapping** is a technique for generating new datasets by sampling from an existing dataset with replacement. This means that some data points may be sampled multiple times, while other data points may not be sampled at all.

**Bagging** is a technique for building multiple machine learning models on different bootstrap samples of a dataset. The predictions of the individual models are then averaged to produce the final prediction.

![Bootstrapping & Bagging](https://miro.medium.com/v2/resize:fit:440/0*jD3dxidTgNzEhBdT.png)

In Random Forests, bootstrapping is used to generate different training datasets for each tree in the forest. This helps to ensure that the trees in the forest are not learning the same patterns in the data, which can lead to overfitting.

Bagging is then used to average the predictions of the individual trees in the forest. This helps to reduce the variance of the predictions and improve the overall accuracy of the model.

Therefore, Random Forests works by creating multiple decision trees and then averaging their predictions. This averaging process helps to reduce the variance of the predictions and improve the overall accuracy of the model.

### Steps to create a Random Forest Model

To create a Random Forest, the following steps are followed:

1. A random subset of the training data is selected.
2. A decision tree is trained on the selected subset of the data.
3. Steps 1 and 2 are repeated multiple times to create a collection of decision trees.
4. To make a prediction on a new data point, each decision tree in the collection makes a prediction. The final prediction is the average of the predictions of all the decision trees.

## Assumptions

Random Forests make the following assumptions:

* The data is independent and identically distributed (i.i.d.). This means that each data point is sampled independently from the same distribution.
* The target variable is categorical for classification tasks and continuous for regression tasks.

Random Forests are relatively robust to violations of these assumptions, but their performance may be degraded if the assumptions are violated severely.

## Benefits

Random Forests offer a number of benefits, including:

* **Accuracy** : Random Forests are typically very accurate machine learning models.
* **Robustness** : Random Forests are relatively robust to overfitting and noise in the data.
* **Interpretability** : Random Forests are more interpretable than other machine learning models, such as neural networks.

## Pitfalls

Random Forests also have some pitfalls, including:

* **Computational complexity** : Training a Random Forest can be computationally expensive, especially for large datasets.
* **Hyperparameter tuning** : Random Forests have a number of hyperparameters that need to be tuned to achieve optimal performance.

Some of the most important hyperparameters of Random Forests in scikit-learn you may want to consider during your tuning are:

* **n_estimators** : The number of trees in the forest. The number of trees in the forest controls the overall accuracy and overfitting of the model. More trees generally lead to better accuracy, but also increase the risk of overfitting.
* **max_depth** : The maximum depth of the individual decision trees in the forest. The maximum depth of the individual trees in the forest controls the complexity of the model. Deeper trees are more complex and can learn more complex relationships between the features and the target variable, but they are also more prone to overfitting.
* **min_samples_leaf** : The minimum number of samples in a leaf node of the individual decision trees in the forest. The minimum number of samples in a leaf node of the individual decision trees in the forest controls the overfitting of the model. Larger values of min_samples_leaf will lead to less overfitting, but also have the potential to reduce the accuracy of the model.
* **criterion** :The function to measure the quality of a split. Supported criteria are “gini” for the Gini impurity and “entropy” for the information gain. The function to measure the quality of a split controls how the trees in the forest are split. The Gini impurity is often a good choice for classification tasks, while the information gain is often a good choice for regression tasks.
* **bootstrap** : Whether or not to perform bootstrap sampling when building the forest. Bootstrap sampling is a technique that helps to reduce the overfitting of the model. When bootstrap sampling is enabled, each tree in the forest is trained on a different subset of the training data. This helps to ensure that the trees in the forest are not learning the same patterns in the data, which can lead to overfitting.
* **oob_score** : Whether or not to compute the out-of-bag score when training the forest. The out-of-bag score is a measure of the accuracy of the forest on the data that was not used to train the individual trees. The out-of-bag score is a measure of the accuracy of the forest on the data that was not used to train the individual trees. The out-of-bag score can be used to estimate the accuracy of the forest on new data, and it can also be used to tune the hyperparameters of the forest.

It is important to note that these are just some of the most important hyperparameters of Random Forests in scikit-learn. There are a number of other hyperparameters that can be tuned, such as the maximum number of features to consider when splitting a node and the minimum impurity decrease required to split a node.

The best way to tune the hyperparameters of a Random Forest model is to use a cross-validation technique. This will help to ensure that the model is not overfitting to the training data. Moreover, consider using GridSearch, RandomSearch, or Bayes Optimization to find the best combinations of the hyperparameters.

## Implementation From Scratch in Python

While above we defined few parameters of Random Forest in scikit-learn, here we will try to recreate random forest keeping only three parameters: n_trees (n_estimators in scikit-learn), min_sample_leaf, and max_depth.

The overall code for the model can be broken down into three classes:

* **Node** : a decision tree is the composition of several nodes, this class only retains the information at the node level.
* **DecisionTreeClassifier** : this code operates in a similar fashion to CART (Classification and Regression Tree). It creates the individual model, used later in the Random Forest model.
* **RandomForestClassifier:** this latest class is the orchestrator of the three classes. It iterates over the DecisionTreeClassifier class for a number of times specified in n_trees predicting the data on each iteration, and then average out the predictions.

Let’s start defining the Node class:

```python class Node: """ Represents a node in a decision tree. Attributes: gini (float): The Gini impurity of the node. num_samples (int): The total number of samples in the node. num_samples_per_class (list): The number of samples per class in the node. predicted_class (int): The predicted class for the node. feature_index (int): The index of the feature used for splitting the node. threshold (float): The threshold value used for splitting the node. left (Node): The left child node. right (Node): The right child node. """ def __init__(self, gini, num_samples, num_samples_per_class, predicted_class): self.gini = gini self.num_samples = num_samples self.num_samples_per_class = num_samples_per_class self.predicted_class = predicted_class self.feature_index = 0 self.threshold = 0 self.left = None self.right = None ```

This class initializes several attributes which will be used from the Decision Tree Classifier. Here’s a breakdown of the attributes:

\- _gini_ : This is the Gini impurity of the node. The Gini impurity is a measure of how often a randomly chosen element from the set would be incorrectly labeled if it was randomly labeled according to the distribution of labels in the subset.

\- _num_samples_ : This is the total number of samples present at the node.

\- _num_samples_per_class_ : This is a list that contains the number of samples per class at the node.

\- _predicted_class_ : This is the class that would be predicted if a sample falls into this node.

\- _feature_index_ : This is the index of the feature that is used for splitting the node. The feature with this index is used to decide whether a sample goes to the left child node or the right child node.

\- _threshold_ : This is the threshold value used for splitting the node. If the value of the feature at `feature_index` for a sample is less than `threshold`, the sample goes to the left child node, otherwise it goes to the right child node.

\- _left_ : This is the left child node. It represents the subset of samples that have a feature value less than the threshold.

\- _right_ : This is the right child node. It represents the subset of samples that have a feature value greater than or equal to the threshold.

Now let’s define the DecisionTreeClassifier class:

```python class DecisionTreeClassifier: """ Decision tree classifier. Parameters ---------- max_depth : int, optional (default=None) The maximum depth of the tree. If None, then nodes are expanded until all leaves are pure. min_samples_leaf : int, optional (default=1) The minimum number of samples required to be at a leaf node. Attributes ---------- n_classes_ : int The number of classes. n_features_ : int The number of features when `fit` is performed. tree_ : Node The root of the decision tree. Methods ------- fit(X, y) Build a decision tree classifier from the training set (X, y). predict(X) Predict class for X. _gini(y) Compute Gini impurity of a non-empty node. _best_split(X, y) Find the best split for a node. _grow_tree(X, y, depth) Build a decision tree by recursively finding the best split. _predict(inputs) Predict class for a single sample. """ def __init__(self, max_depth=None, min_samples_leaf=1): self.max_depth = max_depth self.min_samples_leaf = min_samples_leaf self.tree_ = None def fit(self, X, y): self.n_classes_ = len(set(y)) self.n_features_ = X.shape[1] self.tree_ = self._grow_tree(X, y) def predict(self, X): return [self._predict(inputs) for inputs in X] def _gini(self, y): m = len(y) return 1.0 - sum((np.sum(y == c) / m) ** 2 for c in range(self.n_classes_)) def _best_split(self, X, y): m, n = X.shape if m <= self.min_samples_leaf: return None, None num_parent = [np.sum(y == c) for c in range(self.n_classes_)] best_gini = 1.0 - sum((n / m) ** 2 for n in num_parent) best_idx, best_thr = None, None for idx in range(n): thresholds, classes = zip(*sorted(zip(X[:, idx], y))) num_left = [0] * self.n_classes_ num_right = num_parent.copy() for i in range(1, m): c = classes[i - 1] num_left[c] += 1 num_right[c] -= 1 gini_left = 1.0 - sum((num_left[x] / i) ** 2 for x in range(self.n_classes_)) gini_right = 1.0 - sum((num_right[x] / (m - i)) ** 2 for x in range(self.n_classes_)) gini = (i * gini_left + (m - i) * gini_right) / m if thresholds[i] == thresholds[i - 1]: continue if gini < best_gini: best_gini = gini best_idx = idx best_thr = (thresholds[i] + thresholds[i - 1]) / 2 return best_idx, best_thr def _grow_tree(self, X, y, depth=0): num_samples_per_class = [np.sum(y == i) for i in range(self.n_classes_)] predicted_class = np.argmax(num_samples_per_class) node = Node( gini=self._gini(y), num_samples=len(y), num_samples_per_class=num_samples_per_class, predicted_class=predicted_class, ) if depth < self.max_depth: idx, thr = self._best_split(X, y) if idx is not None: indices_left = X[:, idx] < thr X_left, y_left = X[indices_left], y[indices_left] X_right, y_right = X[~indices_left], y[~indices_left] node.feature_index = idx node.threshold = thr node.left = self._grow_tree(X_left, y_left, depth + 1) node.right = self._grow_tree(X_right, y_right, depth + 1) return node def _predict(self, inputs): node = self.tree_ while node.left: if inputs[node.feature_index] < node.threshold: node = node.left else: node = node.right return node.predicted_class ```

Here’s a breakdown of the class:

\- ___init__(self, max_depth=None, min_samples_leaf=1):_ This is the constructor method that initializes the decision tree classifier. It takes two optional parameters: `max_depth` which is the maximum depth of the tree, and `min_samples_leaf` which is the minimum number of samples required to be at a leaf node.

\- _fit(self, X, y)_ : This method is used to train the decision tree classifier on the training set `(X, y)`. It first determines the number of classes and the number of features, and then it grows the decision tree.

\- _predict(self, X)_ : This method is used to predict the class for the input `X`. It applies the `_predict` method to each input in `X`.

\- __gini(self, y)_ : This private method computes the Gini impurity of a non-empty node. The Gini impurity is a measure of how often a randomly chosen element from the set would be incorrectly labeled.

\- __best_split(self, X, y)_ : This private method finds the best split for a node. It iterates over all features and all possible thresholds to find the feature and the threshold that minimize the Gini impurity.

\- __grow_tree(self, X, y, depth=0)_ : This private method builds a decision tree by recursively finding the best split. It creates a new node, determines the best split, and then recursively grows the left and right subtrees.

* __predict(self, inputs)_ : This private method predicts the class for a single sample. It starts at the root of the tree and moves to the left or right child depending on whether the feature value is less than the threshold or not. It continues this process until it reaches a leaf node, and then it returns the predicted class of the leaf node.

Lastly, let’s define the RandomForestClassifier class:

```python class RandomForestClassifier: """ A custom Random Forest Classifier. Parameters ---------- n_trees : int, optional (default=100) The number of trees in the forest. max_depth : int, optional (default=10) The maximum depth of the tree. min_samples_leaf : int, optional (default=1) The minimum number of samples required to be at a leaf node. Attributes ---------- trees : list The list of DecisionTreeClassifier instances forming the forest. Methods ------- fit(X, y) Build a forest of trees from the training set (X, y). predict(X) Predict class for X by averaging predictions of all trees in the forest. """ def __init__(self, n_trees=100, max_depth=10, min_samples_leaf=1): self.n_trees = n_trees self.max_depth = max_depth self.min_samples_leaf = min_samples_leaf self.trees = [] def fit(self, X, y): # Create a bootstrap sample of the data. bootstrap_samples = [] for _ in range(self.n_trees): bootstrap_sample = X.sample(n=len(X), replace=True) bootstrap_samples.append(bootstrap_sample) # Train a decision tree on each bootstrap sample. for bootstrap_sample in bootstrap_samples: tree = DecisionTreeClassifier(max_depth=self.max_depth, min_samples_leaf=self.min_samples_leaf) y_bootstrap = y.iloc[bootstrap_sample.index] tree.fit(bootstrap_sample.values, y_bootstrap.values) self.trees.append(tree) def predict(self, X): # Make predictions for each data point using each decision tree in the forest. predictions = [] for tree in self.trees: predictions.append(tree.predict(X)) # Average the predictions of all the decision trees to get the final prediction. final_predictions = np.mean(predictions, axis=0) return final_predictions ```

Here’s a breakdown of the class:

\- ___init__(self, n_trees=100, max_depth=10, min_samples_leaf=1)_ : This is the constructor method that initializes the random forest classifier. It takes three optional parameters: `n_trees` which is the number of trees in the forest, `max_depth` which is the maximum depth of the tree, and `min_samples_leaf` which is the minimum number of samples required to be at a leaf node. It also initializes an empty list `trees` to store the decision trees in the forest.

\- _fit(self, X, y)_ : This method is used to train the random forest classifier on the training set `(X, y)`. It first creates a bootstrap sample of the data for each tree in the forest. Then, it trains a decision tree on each bootstrap sample and adds the trained tree to the `trees` list.

\- _predict(self, X)_ : This method is used to predict the class for the input `X`. It applies the `predict` method of each decision tree in the forest to `X` and collects the predictions in a list. Then, it averages the predictions of all the decision trees to get the final prediction.

The random forest classifier works by training multiple decision trees on different subsets of the data and then averaging their predictions. This approach helps to reduce the variance of the predictions and improve the generalization performance of the classifier.
