## 🧭 Introduction

Heard about **Model Context Protocol (MCP)** but unsure how to use it in practice? Skip the theory — this guide walks you through converting your FastAPI-based ML API into a fully functional MCP server, seamlessly compatible with Windsurf’s **Cascade** — agentic coding assistant.

Cascade goes beyond code autocompletion — it actively navigates your project, performs multi-file edits, executes commands, and integrates external APIs like the MCP server we’ll build today.

## 🛠️ Step-by-Step: Converting FastAPI to MCP

For working with this project please clone the repository — <https://github.com/di37/nlp-fastapi-mcp-server>. Create virtual environment and install the requirements.

Breakdown of `main.py` as follows.

### Step 1 — Basic Setup

```python # Standard library importsimport osfrom datetime import datetime# Third-party importsfrom fastapi import FastAPI, HTTPExceptionfrom fastapi.middleware.cors import CORSMiddlewarefrom fastapi_mcp import FastApiMCPimport uvicorn# Local application importsfrom ner import electrical_ner_modelfrom utilities.helper import clean_and_group_entitiesfrom schema import UserInput, EntitiesResponse, EntityGroup ```

### Step 2 — FastAPI App Definition

``` app = FastAPI( title="Electrical NER API", description="API for Named Entity Recognition in electrical/engineering domain", version="1.0.0")app.add_middleware( CORSMiddleware, allow_origins=["*"], # Allows all origins allow_credentials=True, allow_methods=["*"], # Allows all methods allow_headers=["*"], # Allows all headers) ```

### Step 3 — Define Endpoints

```python @app.get("/all_entities", operation_id="get_all_entities")async def all_entities(): """ Get all entities """ return [entity.value for entity in EntityGroup]@app.post("/predict", operation_id="extract_entities")async def predict(input_data: UserInput): """ Extract entities from the input text """ try: ner_results = electrical_ner_model.predict(input_data.text) cleaned_entities = clean_and_group_entities(ner_results) if cleaned_entities: return EntitiesResponse(success=True, message="Entities detected successfully", entities=cleaned_entities) else: return EntitiesResponse(success=False, message="Entities detection failed", entities=[]) except Exception as e: raise HTTPException(status_code=500, detail=str(e)) ```

### Step 4 — Mount the MCP Layer

```json mcp = FastApiMCP(app, include_operations=["extract_entities", "get_all_entities"])mcp.mount()if __name__ == "__main__": uvicorn.run("api_mcp:app", host="0.0.0.0", port=5152, reload=True, workers=4) ```

Run `main.py` to spin up both the API and MCP server. Note that only with two lines of code at the end, we achieve the full MCP server functionality.

## 🧩 Connecting to Cascade (Windsurf IDE)

1. Open Windsurf IDE.
2. Press `CTRL + L` / `Command + L` to open Cascade.
3. Under the chat input bar, there is hammer icon -> Configure.

4\. The following window will show up. If you don’t see the “View raw config” option, install the MCP plugin from the extension marketplace.

5\. Add your MCP server like this to the config file:

```json { "mcpServers": { "electrical-ner-mcp":{ "serverUrl": "http://localhost:5152/mcp" } }} ```

6\. The MCP server is ready to be used if you see green icon followed by the name of the MCP server.

## ✅ Advantages of Using an NER Model as an MCP Tool

Here are the key advantages of exposing your Electrical‑NER model via MCP, especially when it accepts natural language input too:

**1\. Natural-language invocation:** Call entity extraction with plain English — no need to format JSON or write code.

**2\. Auto-discovery & self-documenting tools:** MCP exposes tool metadata (name, params, descriptions), enabling agentic systems like Windsurf’s Cascade to dynamically find and use your NER service.

**3\. Cross-platform interoperability:** Works with any MCP-aware client (e.g., Microsoft Copilot, Cursor) without bespoke integrations.

**4\. Composable agentic workflows:** Use extracted entities as inputs to downstream tasks — without intermediaries — thanks to structured tool responses and persistent context.

**5\. Simplified, maintainable architecture:** One MCP interface replaces numerous custom connectors, reducing boilerplate and enabling plug-and-play use cases.

**6\. Secure, controlled deployment:** Host it within your infrastructure, enforce authentication, and control access at the tool level.

By wrapping your Electrical‑NER as an MCP server, you transform it from a simple API into a conversational, interoperable, secure, and context-aware tool — perfect for agentic systems and advanced developer workflows.
