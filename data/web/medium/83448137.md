In this day of HTML, CSS, etc., is there room for terminal applications that interact with users?

My answer is a resounding yes — especially if they look half-decent.

Moreover, a few Python libraries are now available that can abstract away many of the complications around creating terminal apps, which is a win-win situation.

One of those libraries -`**textual**`\- is what we’ll talk about now.

Looking at the textual GitHub repository, it looks like it was created around 2 years ago by Will McGugan, who also created the well-known `rich` Python library. In fact, Textual is built on top of `rich` with an overall aim of allowing developers to,

> “Build sophisticated user interfaces with a simple Python API … that can be run in the terminal or a browser”

Textual runs in Windows, macOS or Linux and requires Python 3.8 or higher.

### Set up a dev environment.

Before we start coding, let’s set up a separate development environment. That way, all our projects will be siloed and won’t interfere with each other. I use conda for this, but use whichever tool you’re familiar with.

``` (base) $ conda create -n textual python=3.12 -y(base) $ conda activate textual ```

Installation of textual is easy — install it with pip.

```python (textual) $ pip install textual ```

## The Code

### Example 1 — A simple input field with a button

In this example, we take whatever is entered into the input field, capitalise it and re-display the capitalised version when the button is clicked.

```python from textual.app import App, ComposeResultfrom textual.containers import Verticalfrom textual.widgets import Input, Button, Staticclass SimpleApp(App): def compose(self) -> ComposeResult: """Compose the layout.""" with Vertical(): # Input field yield Input(placeholder="Enter text here", id="input-field") # Button placed below the input field yield Button("Capitilize", id="submit-button") # Area to display the output yield Static("", id="output-display") def on_button_pressed(self, event: Button.Pressed) -> None: """Handle button presses.""" if event.button.id == "submit-button": # Get input value and update the output display input_field = self.query_one("#input-field", Input) output_display = self.query_one("#output-display", Static) output_display.update(input_field.value.upper()) # Display uppercase textif __name__ == "__main__": SimpleApp().run() ```

Save the above code to a file, e.g. test1.py and run as normal

``` (textual) $ python test1.py ```

### Example 2— Style components with CSS!

The above output doesn’t look very good, but we can improve it using CSS styling. For example, we’ll make the button blue in colour and change the output text to yellow.

```python from textual.app import App, ComposeResultfrom textual.containers import Verticalfrom textual.widgets import Input, Button, Staticclass CapitalizeApp(App): CSS = """ Button { background: blue; color: white; border: round; } Static#output-display { color: yellow; text-style: bold; } """ def compose(self) -> ComposeResult: """Compose the layout.""" with Vertical(): yield Input(placeholder="Enter text here", id="input-field") yield Button("Capitalize", id="capitalize-button") yield Static("", id="output-display") # To display the capitalized text def on_button_pressed(self, event: Button.Pressed) -> None: """Handle button presses.""" if event.button.id == "capitalize-button": # Get input value input_field = self.query_one("#input-field", Input) output_display = self.query_one("#output-display", Static) # Capitalize the text and display it output_display.update(input_field.value.upper())if __name__ == "__main__": CapitalizeApp().run() ```

### Example 3 — A TODO list

This is a more complicated and complete example. We’ve built a simple TODO list application. It shows the use of CSS and a grid component, which means the tasks are displayed from left to right, top to bottom.

```python from textual.app import App, ComposeResultfrom textual.containers import Horizontal, Gridfrom textual.widgets import Header, Footer, Input, Checkbox, Button, Staticfrom textual.validation import Lengthfrom textual import onclass TodoItem(Static): def __init__(self, task_text): super().__init__() self.task_text = task_text def compose(self) -> ComposeResult: yield Checkbox(self.task_text) yield Button("Delete", variant="error") def on_button_pressed(self, message: Button.Pressed) -> None: """Handle button presses to delete the task.""" if message.button.variant == "error": self.remove()class TodoApp(App): CSS = """ Screen { align: center middle; } #todo-grid { width: 80%; grid-size: 3; /* Number of columns */ grid-rows: auto; grid-columns: auto; grid-gutter: 1; align: center middle; border: tall $background; padding: 1; } #input-row { width: 80%; height: auto; align: center middle; } Input { width: 70%; margin-right: 1; } Button { width: auto; } TodoItem { width: auto; height: auto; border: round $accent; padding: 1; align: center middle; } """ def compose(self) -> ComposeResult: yield Header() with Horizontal(id="input-row"): yield Input(placeholder="Enter new task", id="task-input", validators=[Length(minimum=1)]) yield Button("Add Task", variant="success", id="add-task") with Grid(id="todo-grid"): pass # Tasks will be added dynamically yield Footer() @on(Button.Pressed, "#add-task") def add_task(self) -> None: """Handle the Add Task button.""" task_input = self.query_one("#task-input", Input) task = task_input.value.strip() if task: todo_grid = self.query_one("#todo-grid") todo_grid.mount(TodoItem(task)) task_input.value = "" @on(Input.Submitted) def submit_task(self, message: Input.Submitted) -> None: """Handle task submission via Enter key.""" task = message.input.value.strip() if task: todo_grid = self.query_one("#todo-grid") todo_grid.mount(TodoItem(task)) message.input.value = ""if __name__ == "__main__": TodoApp().run() ```

### Example 4 — Dark/Light mode

Adding dark/light themes to an app is easy. You just need to add the following line at the top of your main class.

``` BINDINGS = [("d", "toggle_dark", "Toggle dark mode")] ```

So, in the above TODO example, our changed code looks like this,

```python ......class TodoApp(App): BINDINGS = [("d", "toggle_dark", "Toggle dark mode")] CSS = """ Screen { align: center middle; }...... ```
