## Getting Started with Phidata

Ready to dive in? Here’s how to set up and start building your first Phidata agent.

### Installation

First things first, install the Phidata library:

```python pip install -U phidata ```

### Create Your First Agent

Let’s say you want to build a web search agent. With Phidata, it’s as easy as:

```python from phi.agent import Agentfrom phi.model.openai import OpenAIChatfrom phi.tools.duckduckgo import DuckDuckGoweb_agent = Agent( name="Web Agent", model=OpenAIChat(id="gpt-4o"), tools=[DuckDuckGo()], instructions=["Always include sources"], show_tool_calls=True, markdown=True,)web_agent.print_response("Tell me about OpenAI Sora?", stream=True) ```

### Run Your Agent

Once your virtual environment and libraries are set up, execute your agent script:

``` python web_search.py ```

That’s it! You now have an operational web agent.
