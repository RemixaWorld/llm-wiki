In the rapidly evolving field of speech recognition, achieving high accuracy while maintaining low latency is a significant challenge. OpenAI’s Whisper model has set new benchmarks in automatic speech recognition (ASR). However, its size can be a barrier for real-time applications on resource-constrained devices.

To address this, we can leverage **Distil-Whisper** , a distilled version of the Whisper model provided by Hugging Face, which reduces the model size while retaining much of its performance. In this blog post, we’ll explore how to implement a **live speech-to-text system** using Distil-Whisper, taking input directly from the microphone. Additionally, we’ll discuss integrating **Redis** for efficient inter-process communication and how to structure the code for modularity and ease of integration.

For this implementation, we used a system with the following specifications:

* **Processor** : Intel Core i7
* **Graphics Card** : NVIDIA GeForce RTX 2060 with 6GB VRAM
* **Memory** : 32GB DDR4 RAM
* **Storage** : 1TB SSD

## Key Features

* **Live Speech-to-Text** : Real-time transcription from microphone input.
* **Redis Pub/Sub Communication** : Efficient message passing for further processing.
* **Modular Codebase** : Organized structure for easy understanding and modification.
* **Easy Integration** : Simplifies incorporation into larger projects.

## Understanding Distil-Whisper

Distil-Whisper is a lighter version of OpenAI’s Whisper, distilled to be faster and more memory-efficient while still providing impressive transcription capabilities. This makes it suitable for use cases requiring real-time transcription where performance is critical.

In this project, we integrate **Distil-Whisper** into a live speech-to-text pipeline. The key features include:

* **Live input** from a microphone for real-time transcription.
* Use of **Redis Pub/Sub** for sending transcribed text to other services or applications.
* A modular structure that makes the code easy to extend and integrate into other projects.

## Project Overview

The project’s goal is to create a live speech-to-text system that listens to microphone input, transcribes the audio in real-time using Distil-Whisper, and publishes the transcribed text to a Redis server for downstream applications.

### Project Structure

``` ├── configs│ └── config.toml├── internal│ ├── app.py│ ├── core│ │ ├── audio_src.py│ │ ├── stt.py│ ├── server│ │ └── pubsub.py│ └── utils│ ├── config.py│ ├── logger.py│ ├── noise_check.py│ └── textformat.py├── logs│ └── server.log├── main.py├── README.md└── requirements.txt ```

* **configs/config.toml** : Configuration file for setting microphone details and other parameters.
* **internal/app.py** : Entry point for the application logic.
* **internal/core** : Contains core functionalities like audio capture and speech-to-text processing.
* **audio_src.py** : Handles microphone input.
* **stt.py** : Manages the speech-to-text conversion using Distil-Whisper.
* **internal/server/pubsub.py** : Implements Redis Pub/Sub for message communication.

## Getting Started

### Prerequisites

* **Python 3.10** or higher
* **PyTorch** 2.0 or higher
* **Redis Server** (for Pub/Sub functionality)
* **Docker** (optional, for containerized development)

### Step 1: Clone the Repository

``` git clone https://github.com/yourusername/distil-whisper-live.gitcd distil-whisper-live ```

### Step 2: Install Dependencies

It’s recommended to use a virtual environment to manage dependencies.

```python python3 -m venv venvsource venv/bin/activate # On Windows use `venv\Scripts\activate`pip install -r requirements.txt ```

### Step 3: Configure the Application

Edit the `configs/config.toml` file to match your microphone settings:

``` [microphone]name = "Your Microphone Name"sample_rate = 16000 # Adjust as neededchunk_size = 1024 ```

You may need to adjust the `noise_threshold` in `config.toml` based on your environment to filter out background noise effectively.

### Step 4: Run the Redis Server

Ensure that a Redis server is running locally. You can start one using Docker:

``` docker run -p 6379:6379 redis ```

### Step 5: Run the Application

``` python main.py ```

The application will start capturing audio from your microphone, perform speech-to-text transcription in real-time, and publish the results to the Redis server.

## How It Works

### Audio Capture

The `audio_src.py` module uses the `pyaudio` library to capture audio data from the microphone in real-time. It handles audio stream initialization, reading chunks of audio data, and closing the stream when the application stops.

### Speech-to-Text Processing

The `stt.py` module loads the Distil-Whisper model using Hugging Face's `transformers` library. It processes the audio chunks, performs necessary preprocessing, and feeds the data to the model for transcription.

### Noise Detection

The `noise_check.py` module includes functionality to detect and filter out silence or background noise, ensuring that only significant audio is processed, which improves efficiency and accuracy.

### Redis Pub/Sub Communication

The `pubsub.py` module handles publishing the transcribed text to a Redis channel. This allows other applications or services to subscribe to the channel and receive the transcribed text in real-time, facilitating decoupled and scalable architectures.

### Modular Design

The codebase is organized into modules, each responsible for specific functionality. This modularity makes it easier to maintain, extend, and integrate the system into larger projects.

## Why Redis Pub/Sub?

Redis Pub/Sub allows for efficient message broadcasting between services. In this project, once the transcription is done, the text is published to a Redis channel. Any service that subscribes to this channel can receive the transcriptions in real time. This is particularly useful for:

* Integrating with **backend systems** that require real-time text input.
* Developing **chatbots** or **virtual assistants** that need immediate transcriptions.
* Feeding the transcriptions into **analytics pipelines** for further processing.
