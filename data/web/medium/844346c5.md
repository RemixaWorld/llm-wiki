## **The wizard behind the curtain: Small Language Models (SLMs)**

First of all… what are Small Language Models? If you read the news, in the past few days Meta-AI released Llama-3. So let’s make it clear from now: 8 Billion parameters is not a Small Language Model!

An SLM is a model that can run on low-spec hardware, even on a mobile phone with decent speed, and good accuracy, and NOT a super iPhone 19X Pro whatsoever.

TinyLlama is a perfect example of what we are talking about a 1.1 Billion parameter model. Let’s say, that everything within 3 Billion parameters can be considered a Small Model. In fact, if you try to run on a Laptop with only your CPU you get a reply in seconds… not in minutes!

## **The power of the prompt: from simple Commands to spellbinding Instructions**

Recent studies upset AI predictions: word order in the instructions still matters for any Language Model, especially the Small ones. While larger models might eventually learn to optimize their own prompts, the human touch remains invaluable, especially for smaller language models. We bring more than just prompt-writing skills to the table. We understand context, nuance, and the desired outcome.

The thing is that Small Language Models are super-sensible to word and instruction positions in the prompt. Here human skill (and a proper combination of creativity) comes in handy. We flip the table and we must become LLM-psychologists, able to grasp what are our model preferences and how to make them understand better.

### Reply to questions based only on the given context (RAG)

It took me almost 3 weeks to understand how to get Qwen to say I DON’T KNOW. It is a complicated matter, by the way. It is really hard for a Language Model to say that.

TIP: sometimes only changing the word/sentence position will get you a totally different result. For example, the standard RAG prompt based only on the context looks like this:

``` Given the below contex, reply to the question. If the answer is not provided in the context say /unanswerable/.ContextQuestion: ```

For a Small parameters model there are plenty of issues here:

1. context is not recognized as a meaning but as a word
2. unanswerable… better to say ‘I don’t know’
3. The question is too far from the instructions.

I changed the words and put the question **before** the text. Voila!

### Create a table of contents

Believe it or not, this was the biggest challenge in my daily usage of Small Language Models. I have to read TONS of engineering documentation and I created my own personal Exploratory Document Analysis.

You may have already guessed that also all the prompts above are related to the task: use the model to start an investigation process to the document so that key persons, locations, subjects/topics are explored and highlighted.

But imagine that even **the spaces** in the instructions are sensible. One new line may be too much for the model to understand the prompt.

Anyway, the _teenager_**Qwen 1.8 — qwen1_5–1_8b-chat-q4_k_m.gguf** did a good job, here is the initial prompt:

``` Given a block of text, please extract and return the Table of Contents (ToC) or an outline in a formatted list format that represents the main headings and subheadings present within the text. Please ensure that each heading is numbered sequentially and accurately reflects its position within the context of the overall content. Note: The Table of Contents should not include any unnecessary or repetitive headings that are only present for formatting purposes, such as page numbers or section headers (e.g., "Section 1" vs. Page 23).[start of context]your text here....says that, to some extent in this early phase of the field, the only overriding rule seems to be the absence of rules. “It’s kind of the Wild, Wild West for this right now.” he says.[end of context]Table of Contents: ```
