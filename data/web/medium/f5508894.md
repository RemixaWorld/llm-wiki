Mesop is a new UI framework that enables Python developers to quickly create enjoyable web applications in a scalable way. Many Python UI frameworks are easy to get to grips with, but customizing beyond the default settings often requires diving into JavaScript, CSS and HTML — a steep learning curve for many developers

## What is Mesop?

Mesop is a Python-based user interface framework that lets you quickly create web applications such as demos and in-house applications. It’s intuitive for user interface novices. You can write the user interface in idiomatic Python code. It offers an easy-to-understand responsive user interface paradigm.

![image](https://miro.medium.com/v2/resize:fit:700/0*NmLUWogCYkwJ3SFj)

* **Intuitive for UI novices** : You can write the UI in idiomatic Python code
* **Ready-to-use components** : Mesop offers a variety of ready-to-use components to speed up development
* **Frictionless development workflows** : Mesop provides hot reloading, so the browser automatically reloads and preserves state
* **Rich IDE support with strong type safety** : Mesop offers rich IDE support with strong type safety
* **Flexible for enjoyable demonstrations** : You can build custom user interfaces without writing Javascript/CSS/HTML
* **Compose your user interface in components** : With Mesop, your components are simply Python functions

## How do I get started with Mesop? A rapid example

You can try Mesop on Colab or locally. To install it locally, use the

```python pip install mesopcommand ```

In this example, you code it on google collab to show you quickly the result.

```python import mesop as me@me.page(path="/button")def button(): me.text("Button types:", style=me.Style(margin=me.Margin(bottom=12))) # This creates a text element with the content "Button types:". The style is set to have a bottom margin of 12 pixels. with me.box(style=me.Style(display="flex", flex_direction="row", gap=12)): me.button("default") me.button("raised", type="raised") me.button("flat", type="flat") me.button("stroked", type="stroked") # This creates a box with a flex display, row direction, and a gap of 12 pixels. Inside this box, four buttons are created with different types: "default", "raised", "flat", and "stroked". me.text("Button colors:", style=me.Style(margin=me.Margin(bottom=12))) # This creates another text element with the content "Button colors:". The style is set to have a bottom margin of 12 pixels. with me.box(style=me.Style(display="flex", flex_direction="row", gap=12)): me.button("default", type="flat") me.button("primary", color="primary", type="flat") me.button("secondary", color="accent", type="flat") me.button("warn", color="warn", type="flat") # This creates another box with a flex display, row direction, and a gap of 12 pixels. Inside this box, four buttons are created with different types and colors: "default" (type "flat"), "primary" (color "primary", type "flat"), "secondary" (color "accent", type "flat"), and "warn" (color "warn", type "flat").me.colab_show(path="/button")# Finally, this line shows the /button page in a Colab notebook. ```
