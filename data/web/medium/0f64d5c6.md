# Matryoshka-Adaptor : LLM tuning framework for dimensionality reduction while maintaining performance

Embeddings from Large Language Models (LLMs) has variety of applications including information retrieval. While high-dimensional embeddings capture more information, therefore demonstrate superior performance, but associated applications suffer from high latency and compute cost.

To address those challenges, authors of this paper[1] introduce Matryoshka-Adaptor, a novel tuning framework designed for the customization of LLM embeddings.Matryoshka-Adaptor facilitates substantial dimensionality reduction while maintaining comparable performance levels, thereby achieving a significant enhancement in computational efficiency and cost-effectiveness.

Key contributions:

* propose a novel tuning framework, Matryoshka-Adaptor that achieves substantial dimensionality reduction in embeddings without sacrificing performance achieved by tailoring embeddings to better fit specific datasets.
* Matryoshka-Adaptor is applicable in both unsupervised and supervised settings, consistently improving retrieval performance across various datasets. Also, Matryoshka-Adaptor demonstrates a roughly two-fold (unsupervised) and six-fold (supervised) reduction in dimensionality, with no loss in performance
* benefits of Matryoshka-Adaptor extend to multimodal learning and multilingual scenarios.

## Unsupervised Matryoshka-Adaptor

### i) Problem formulation

* proposed framework is formulated within the context of information retrieval, but can be can be readily generalized to any application involving embeddings.
* In unsupervised settings, we assume the availability of a corpus set, denoted as C = {c1, c2, …, cN} and a pre-trained embedding model (E)
* embeddings extracted from the corpus are represented as CE = {ce1, ce2, …, ceN}, where each embedding vector cei = E(ci) ∈ Rd
* our framework
* permits the embedding model, E, to be treated as a black-box model, and Matryoshka-Adaptor can be directly applied to the extracted embeddings, CE.
* A Matryoshka embedding, characterized by m dimensions, is defined as the initial m dimensions of the original d-dimensional embedding, where m < d. This can be expressed as CE[: m] = {ce1[: m], ce2[: m], …, ceN[: m]} where each reduced embedding vector cei[: m] ∈ Rm.
* Matryoshka embeddings is characterized by their capacity to preserve the essential properties of the original embeddings, even within a reduced dimensional space.

### ii) Tuning objective functions

* proposed Matryoshka-Adaptor, represented by the function f : Rd → Rd, is designed to modify the original embeddings in order to enhance their inherent Matryoshka properties
* We define the set of customized corpus embeddings as ˆ CE = { ˆ ce1, ˆ ce2, …, ˆ ceN} and their corresponding Matryoshka embeddings as ˆ CE[: m] = { ˆ ce1[:m], ˆ ce2[: m], …, ˆ ceN[: m]} where ˆ cei = f(cei).
* primary objective of the function f is to maximize the Matryoshka properties through this customization process, thus ensuring consistency similarity between any two embeddings, irrespective of high-dimensional space or reduced low-dimensional space

## Supervised Matryoshka-Adaptor

### i) Problem formulation

* introduce a method to further refine the Matryoshka-Adaptor by utilizing (a limited number of) pairwise data samples
* Let Q = {q1, q2, …, qM} denote the set of queries, and let R = {(qi, cj , yij)}i=1:M,j=1:N represent the set of query-corpus relevance triplets, where yij > 0 signifies the relevance score between query qi and corpus cj .
* query embeddings extracted from the model (E) are denoted as QE = {qe1, qe2, …, qeN} with each query embedding vector qei = E(qi) ∈ Rd.
* Furthermore, we define Matryoshka query embeddings as QE[: m] = {qe1[: m], qe2[: m], …, qeN[: m]}, where qei[: m] ∈ Rm. Note that m can be any integer less than the original embedding dimension

### ii) Tuning objective functions

* In supervised setting, Matryoshka-Adaptor (f) undergoes optimization to enhance both its Matryoshka properties and the retrieval performance of the Matryoshka embeddings.
* It is accomplishe through the utilization of paired query-corpus samples, in conjunction with the original query and corpus embeddings
* Matryoshka ranking loss, denoted as Lrank, is introduced to align the ranking between query and corpus considering different Matryoshka embedding dimensions, where sij [: m] represents the cosine similarity between the adapted query embedding ˆ qei[: m] (where ˆ qei = qei +f(qei)) and the adapted corpus embedding ˆ cej [: m]

## Experiments

* Matryoshka-Adaptor is extensively evaluated across a diverse set of 13 BEIR datasets (bei), 17 MIRACL datasets (mir), and 5 Fashion-200K datasets
* Query and corpus embeddings are generated using state-of-the-art models, including Google Gecko text embeddings (English and multilingual) (gcp), Google multimodal embeddings, and OpenAI text embeddings (ope).

### i) Unsupervised tuning

* Matryoshka-Adaptor can be applied exclusively with corpus embeddings, referred to as the unsupervised setting, enabling customization of embeddings solely on the corpus side
* Fig. a and b below, illustrate that the Matryoshka-Adaptor yields significant performance improvements, particularly for lower dimensions, compared to the embeddings of the same dimensionality without it.

![image](https://miro.medium.com/v2/resize:fit:466/1*xQiZoSq3tpW9cWtYpfqvWA.png)
* lower dimensional embeddings processed with Matryoshka-Adaptor achieve comparable performance to original embeddings of high dimensionality.
* adaptor achieves a
* faster saturation in performance with embedding dimensionality, towards the retrieval performance of original embeddings, underscoring its substantial impact in significantly reducing latency and memory requirements for retrieval applications
* latest OpenAI embeddings are already trained with Matryoshka Representation Learning (MRL) (ope), therefore additional performance gains achieved by Matryoshka-Adaptor are attributed to the tuning process
* With PCA, som improvements are observed for lower dimensions, however, at higher dimensions, noticeable performance degradation occurs, resulting in inferior performance as compared to original embeddings, thereby highlighting the superiority of the Matryoshka-Adaptor which has salient information preservation for similarity within lower dimensions as compared to PCA.

### ii) Supervised tuning

* In this context, the Supervised Matryoshka-Adaptor is trained utilizing paired query-corpus data.
* effectiveness of the Supervised Matryoshka-Adaptor is evaluated on 13 BEIR, 17 MIRACL, and 5 Fashion-200K datasets, with query and corpus embeddings being generated using the latest Google Gecko models, including its multilingual and multimodal versions
* As shown in figure below, the Supervised Matryoshka-Adaptor consistently outperforms the alternatives, such as Search-Adaptor [2], particularly for lower embedding dimensions.

## Limitations

* In the unsupervised setting, picking the optimal hyperparameters for Matryoshka-Adaptor poses challenge due to the absence of validation data.
* While alternative metrics can be employed, those may exhibit higher levels of noise compared to supervised validation metrics.
* One major risk associated with Matryoshka-Adaptor lies in the potential for overfitting to the tuning data, during the tuning process

## Conclusion

* presented Matryoshka-Adaptor framework offers a solution to higher compute costs and latency issues associated with high-dimensional embeddings, by enabling substantial dimensionality reduction while minimizing performance degradation, in both supervised and unsupervised scenarios.
* due to its versatile nature and applicability to any embedding model, regardless of access to model parameters, the Matryoshka-Adaptor constitutes a valuable tool for improving the efficiency and practicality of embedding-based applications.
