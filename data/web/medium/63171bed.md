Before we move ahead, lets talk a bit about this Hypothesis analysis agent.

> Hypothesis Testing is a type of [statistical analysis](<https://www.simplilearn.com/what-is-statistical-analysis-article>) in which you put your assumptions about a population parameter to the test. It is used to estimate the relationship between 2 statistical variables.
>
> Let’s discuss few examples of statistical hypothesis from real-life -
>
> A teacher assumes that 60% of his college’s students come from lower-middle-class families.
>
> A doctor believes that 3D (Diet, Dose, and Discipline) is 90% effective for diabetic patients.

For this agent, our intention is to analyze the marketing campaign performance (see below the data model). Once the agent is invoked, the idea would be to make certain assumptions (hypothesis) and evaluate those statistically to confirm or deny the same.

**Solution**

Let us understand the system behaves based on the setup I have.

Again, we start by choosing the right agents (one or multiple) from agent marketplace. Once we choose the Hypothesis Analysis Agent, it goes through the same Agent Initialization and state management.

![image](https://miro.medium.com/v2/resize:fit:700/1*RD8AJ4RvPwjziFOlo7Jvyw.png)

Once the agent is initialized, it goes into its state and asks me for a query to ask. The query is the “null” hypothesis that we can establish. I will explain with 2 examples below what questions I ask.

![image](https://miro.medium.com/v2/resize:fit:700/1*WKka-dtLu_xF2cORd97UtQ.png)

The below data model provides insights on what kind of hypothesis we can establish.

![image](https://miro.medium.com/v2/resize:fit:700/0*ItyyMo-0bIDgoTDZ)

The first question is around “if campaign 1 has performed better than campaign 2”.

Once asked, the system performs the analysis of the sample and calculates the p_value to reject the hypothesis and not. For example, the question came back with the analysis that campaign 1 did not perform better than campaign 2.

![image](https://miro.medium.com/v2/resize:fit:700/1*DkbCyFX3YTchsXrZQ5dbhA.png)

Similarly, the second question is around — if more people who purchased fruit complained more than who purchased meat.

![image](https://miro.medium.com/v2/resize:fit:700/1*UfWoDiif4nYmrfv9z7DnzA.png)

The answer comes back and mentions that the hypothesis can be rejected.

The final solution is similar to the other agents — we invoke the SQL tool, the tool gets the data organized and indexed, the indexed data is then analyzed using Statistical Tool which generates a p_value which provides if we can reject the hypothesis or not.
