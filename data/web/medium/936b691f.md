As the volume of digital content grows exponentially, the ability to retrieve relevant and precise information quickly has become increasingly essential. Traditional search engines and knowledge retrieval systems are often limited by their one-size-fits-all approach, which may not always cater to the diverse range of queries users have. This is where Retrieval-Augmented Generation (_RAG_) systems come into play. By combining retrieval mechanisms with powerful generative models like _OpenAI’s GPT_ , RAG systems not only fetch relevant information but also synthesize responses that are coherent and contextually rich.

However, even _RAG_ systems have limitations when a single retrieval strategy is applied to all query types. To overcome this, **Adaptive Retrieval-Augmented Generation (_RAG_)** takes the next step, tailoring its retrieval process based on the nature of the query itself. This adaptive system ensures that every query, whether factual, analytical, opinion-based, or contextual, receives a customized response by adjusting both the retrieval method and how the information is processed.

**_Overview_**

The Adaptive _RAG_ system presents an advanced framework that adapts its retrieval strategy to the type of query it encounters. By utilizing Language Models (_LLMs_) at different stages of retrieval, it generates responses that are more accurate, relevant, and contextually aware. This approach not only broadens the scope of the system’s capabilities but also enhances its flexibility in handling various types of user requests.

**_Motivation_**

Traditional _RAG_ systems typically apply a uniform retrieval approach, which may not work well across different types of questions. For instance, while factual queries demand high precision, analytical or opinion-based queries benefit from broader, more comprehensive retrieval strategies. Understanding that different types of queries require distinct retrieval methods is the core motivation behind this adaptive system.

The goal is to optimize retrieval for each type of query, ensuring that the user receives the most suitable and tailored information. By doing so, the system bridges the gap between precision and breadth, giving a more satisfying and informative response.

**_Key Components_**

The Adaptive RAG system is built on four main components:

1. **_Query Classifier_** : A mechanism that determines the type of query (Factual, Analytical, Opinion, or Contextual).
2. **_Adaptive Retrieval Strategies_** : Four distinct retrieval strategies that correspond to each query type; _Factual Strategy, Analytical Strategy, Opinion Strategy, and Contextual Strategy._
3. **_LLM Integration_** : LLMs enhance retrieval and document ranking, optimizing the selection of relevant information.
4. **_OpenAI GPT Model_** : The generative model that uses the retrieved documents as context to create a final, polished response.

**_Method Details_**

1. ** _Query Classification_**

The first step in the adaptive system is to classify the user’s query into one of four categories:

* **_Factual_** : For queries seeking concrete, verifiable information.
* **_Analytical_** : For complex questions that require detailed explanations or multi-faceted analysis.
* **_Opinion_** : For subjective queries that explore personal perspectives or multiple viewpoints.
* **_Contextual_** : For queries that depend on user-specific context or background information.

This classification ensures that the retrieval method is aligned with the nature of the question, setting the stage for optimal information gathering.

2\. **_Adaptive Retrieval Strategies_**

Each query type is addressed using a unique retrieval strategy:

* **_Factual Strategy._** For factual queries, accuracy and precision are paramount. The system enhances the user’s original query using an LLM to ensure it captures the right nuances. It then retrieves documents that closely match the query and uses another _LLM_ to rank them by relevance, ensuring the most precise information is selected.
* **_Analytical Strategy._** Analytical queries often require a deeper exploration of a topic. To achieve this, the system breaks down the original question into multiple sub-queries using an _LLM_ , each addressing a different facet of the main topic. Documents are retrieved for each sub-query, and the system uses an _LLM_ to select a diverse yet relevant set of documents, ensuring comprehensive coverage of the subject.
* **_Opinion Strategy_**. Opinion-based queries benefit from diverse viewpoints. The system identifies different perspectives on the topic using an _LLM_ and retrieves documents representing each viewpoint. It then ranks the documents in such a way that multiple opinions are showcased, allowing the user to see a well-rounded range of responses.
* **_Contextual Strategy._** Contextual queries rely heavily on user-specific information. The system incorporates this context into the query using an _LLM_ , ensuring that the retrieved documents are relevant not just to the query, but to the user’s particular circumstances. Documents are ranked by considering both their relevance to the query and the user’s context.

3.**_LLM-Enhanced Ranking_**

Once the relevant documents are retrieved, an _LLM_ performs a final ranking to ensure the most appropriate information is selected. This ranking process is crucial as it fine-tunes the selection, especially in cases where multiple retrieval strategies generate a large volume of documents.

4.**_Response Generation_**

Finally, the selected documents are passed to an _OpenAI GPT_ model, which generates the final response. This model synthesizes the retrieved information and presents it in a coherent, context-aware, and well-structured form, ensuring that the response is both informative and easy to understand.

**_Benefits of this Approach_**

The Adaptive _RAG_ system offers several distinct advantages over traditional approaches:

* **Improved Accuracy** : By adjusting retrieval strategies based on query types, the system delivers more accurate and relevant information, especially for factual and precise queries.
* **Flexibility** : The system is versatile enough to handle various types of queries, from simple fact-checking to complex analysis or subjective opinion gathering.
* **Context-Awareness** : For contextual queries, the system integrates user-specific information to tailor the response, ensuring more personalized and relevant answers.
* **Diverse Perspectives** : For opinion-based queries, the system ensures that multiple viewpoints are represented, offering a balanced and comprehensive understanding of the topic.
* **Comprehensive Analysis** : The analytical strategy is designed to dig deep into complex questions, ensuring that no aspect of a query is left unexplored.

* _Import necessary libraries and set up environment variables_

```python """Import necessary libraries"""import osimport sysfrom dotenv import load_dotenvfrom langchain.prompts import PromptTemplatefrom langchain.vectorstores import FAISSfrom langchain.embeddings import OpenAIEmbeddingsfrom langchain.text_splitter import CharacterTextSplitterfrom langchain.prompts import PromptTemplatefrom langchain_core.retrievers import BaseRetrieverfrom typing import Dict, Anyfrom langchain.docstore.document import Documentfrom langchain_openai import ChatOpenAIfrom langchain_core.pydantic_v1 import BaseModel, Fieldsys.path.append(os.path.abspath(os.path.join(os.getcwd(), '..'))) # Add the parent directory to the path sicnce we work with notebooksfrom helper_functions import *from evaluation.evaluate_rag import *# Load environment variables from a .env fileload_dotenv()# Set the OpenAI API key environment variableos.environ["OPENAI_API_KEY"] = os.getenv('OPENAI_API_KEY') ```
* _Define the Query Classifier Class_

```python """Define the Query classifier class"""class categories_options(BaseModel): category: str = Field(description="The category of the query, the options are: Factual, Analytical, Opinion, or Contextual", example="Factual")class QueryClassifier: def __init__(self): self.llm = ChatOpenAI(temperature=0, model_name="gpt-4o", max_tokens=4000) self.prompt = PromptTemplate( input_variables=["query"], template="Classify the following query into one of these categories: Factual, Analytical, Opinion, or Contextual.
Query: {query}
Category:" ) self.chain = self.prompt | self.llm.with_structured_output(categories_options) def classify(self, query): print("clasiffying query") return self.chain.invoke(query).category ```
* Define the Base Retrieval Class

```python """Define the base retrieval class"""class BaseRetrievalStrategy: def __init__(self, texts): self.embeddings = OpenAIEmbeddings() text_splitter = CharacterTextSplitter(chunk_size=800, chunk_overlap=0) self.documents = text_splitter.create_documents(texts) self.db = FAISS.from_documents(self.documents, self.embeddings) self.llm = ChatOpenAI(temperature=0, model_name="gpt-4o", max_tokens=4000) def retrieve(self, query, k=4): return self.db.similarity_search(query, k=k) ```
* _Define the Factual Retriever Strategy_

```python """Define the factual retriever strategy"""class relevant_score(BaseModel): score: float = Field(description="The relevance score of the document to the query", example=8.0)class FactualRetrievalStrategy(BaseRetrievalStrategy): def retrieve(self, query, k=4): print("retrieving factual") # Use LLM to enhance the query enhanced_query_prompt = PromptTemplate( input_variables=["query"], template="Enhance this factual query for better information retrieval: {query}" ) query_chain = enhanced_query_prompt | self.llm enhanced_query = query_chain.invoke(query).content print(f'enhande query: {enhanced_query}') # Retrieve documents using the enhanced query docs = self.db.similarity_search(enhanced_query, k=k*2) # Use LLM to rank the relevance of retrieved documents ranking_prompt = PromptTemplate( input_variables=["query", "doc"], template="On a scale of 1-10, how relevant is this document to the query: '{query}'?
Document: {doc}
Relevance score:" ) ranking_chain = ranking_prompt | self.llm.with_structured_output(relevant_score) ranked_docs = [] print("ranking docs") for doc in docs: input_data = {"query": enhanced_query, "doc": doc.page_content} score = float(ranking_chain.invoke(input_data).score) ranked_docs.append((doc, score)) # Sort by relevance score and return top k ranked_docs.sort(key=lambda x: x[1], reverse=True) return [doc for doc, _ in ranked_docs[:k]] ```
* _Define Analytical Retriever Strategy_

```python """Define Analytical Retriever Strategy"""class SelectedIndices(BaseModel): indices: List[int] = Field(description="Indices of selected documents", example=[0, 1, 2, 3])class SubQueries(BaseModel): sub_queries: List[str] = Field(description="List of sub-queries for comprehensive analysis", example=["What is the population of New York?", "What is the GDP of New York?"])class AnalyticalRetrievalStrategy(BaseRetrievalStrategy): def retrieve(self, query, k=4): print("retrieving analytical") # Use LLM to generate sub-queries for comprehensive analysis sub_queries_prompt = PromptTemplate( input_variables=["query", "k"], template="Generate {k} sub-questions for: {query}" ) llm = ChatOpenAI(temperature=0, model_name="gpt-4o", max_tokens=4000) sub_queries_chain = sub_queries_prompt | llm.with_structured_output(SubQueries) input_data = {"query": query, "k": k} sub_queries = sub_queries_chain.invoke(input_data).sub_queries print(f'sub queries for comprehensive analysis: {sub_queries}') all_docs = [] for sub_query in sub_queries: all_docs.extend(self.db.similarity_search(sub_query, k=2)) # Use LLM to ensure diversity and relevance diversity_prompt = PromptTemplate( input_variables=["query", "docs", "k"], template="""Select the most diverse and relevant set of {k} documents for the query: '{query}'
Documents: {docs}
Return only the indices of selected documents as a list of integers.""" ) diversity_chain = diversity_prompt | self.llm.with_structured_output(SelectedIndices) docs_text = "
".join([f"{i}: {doc.page_content[:50]}..." for i, doc in enumerate(all_docs)]) input_data = {"query": query, "docs": docs_text, "k": k} selected_indices_result = diversity_chain.invoke(input_data).indices print(f'selected diverse and relevant documents') return [all_docs[i] for i in selected_indices_result if i < len(all_docs)] ```
* _Define Opinion Retriever Strategy_

```python """Define Opinion Retriever Strategy"""class OpinionRetrievalStrategy(BaseRetrievalStrategy): def retrieve(self, query, k=3): print("retrieving opinion") # Use LLM to identify potential viewpoints viewpoints_prompt = PromptTemplate( input_variables=["query", "k"], template="Identify {k} distinct viewpoints or perspectives on the topic: {query}" ) viewpoints_chain = viewpoints_prompt | self.llm input_data = {"query": query, "k": k} viewpoints = viewpoints_chain.invoke(input_data).content.split('
') print(f'viewpoints: {viewpoints}') all_docs = [] for viewpoint in viewpoints: all_docs.extend(self.db.similarity_search(f"{query} {viewpoint}", k=2)) # Use LLM to classify and select diverse opinions opinion_prompt = PromptTemplate( input_variables=["query", "docs", "k"], template="Classify these documents into distinct opinions on '{query}' and select the {k} most representative and diverse viewpoints:
Documents: {docs}
Selected indices:" ) opinion_chain = opinion_prompt | self.llm.with_structured_output(SelectedIndices) docs_text = "
".join([f"{i}: {doc.page_content[:100]}..." for i, doc in enumerate(all_docs)]) input_data = {"query": query, "docs": docs_text, "k": k} selected_indices = opinion_chain.invoke(input_data).indices print(f'selected diverse and relevant documents') return [all_docs[int(i)] for i in selected_indices.split() if i.isdigit() and int(i) < len(all_docs)] ```
* _Define Contextual Retriever Strategy_

```python """ Define Contextual Retriever Satrategy"""class ContextualRetrievalStrategy(BaseRetrievalStrategy): def retrieve(self, query, k=4, user_context=None): print("retrieving contextual") # Use LLM to incorporate user context into the query context_prompt = PromptTemplate( input_variables=["query", "context"], template="Given the user context: {context}
Reformulate the query to best address the user's needs: {query}" ) context_chain = context_prompt | self.llm input_data = {"query": query, "context": user_context or "No specific context provided"} contextualized_query = context_chain.invoke(input_data).content print(f'contextualized query: {contextualized_query}') # Retrieve documents using the contextualized query docs = self.db.similarity_search(contextualized_query, k=k*2) # Use LLM to rank the relevance of retrieved documents considering the user context ranking_prompt = PromptTemplate( input_variables=["query", "context", "doc"], template="Given the query: '{query}' and user context: '{context}', rate the relevance of this document on a scale of 1-10:
Document: {doc}
Relevance score:" ) ranking_chain = ranking_prompt | self.llm.with_structured_output(relevant_score) print("ranking docs") ranked_docs = [] for doc in docs: input_data = {"query": contextualized_query, "context": user_context or "No specific context provided", "doc": doc.page_content} score = float(ranking_chain.invoke(input_data).score) ranked_docs.append((doc, score)) # Sort by relevance score and return top k ranked_docs.sort(key=lambda x: x[1], reverse=True) return [doc for doc, _ in ranked_docs[:k]] ```
* _Define the Adaptive Retriever Class_

```python """Define the Adaptive Retriever Class"""class AdaptiveRetriever: def __init__(self, texts: List[str]): self.classifier = QueryClassifier() self.strategies = { "Factual": FactualRetrievalStrategy(texts), "Analytical": AnalyticalRetrievalStrategy(texts), "Opinion": OpinionRetrievalStrategy(texts), "Contextual": ContextualRetrievalStrategy(texts) } def get_relevant_documents(self, query: str) -> List[Document]: category = self.classifier.classify(query) strategy = self.strategies[category] return strategy.retrieve(query) ```
* _Define Additional Retriever that inherits from LangChain’s BaseRetriever_

```python """Define aditional retriever that inherits from langchain BaseRetriever"""class PydanticAdaptiveRetriever(BaseRetriever): adaptive_retriever: AdaptiveRetriever = Field(exclude=True) class Config: arbitrary_types_allowed = True def get_relevant_documents(self, query: str) -> List[Document]: return self.adaptive_retriever.get_relevant_documents(query) async def aget_relevant_documents(self, query: str) -> List[Document]: return self.get_relevant_documents(query) ```
* _Define the Adaptive RAG Class_

```python """Define the Adaptive RAG Class"""class AdaptiveRAG: def __init__(self, texts: List[str]): adaptive_retriever = AdaptiveRetriever(texts) self.retriever = PydanticAdaptiveRetriever(adaptive_retriever=adaptive_retriever) self.llm = ChatOpenAI(temperature=0, model_name="gpt-4o", max_tokens=4000) # Create a custom prompt prompt_template = """Use the following pieces of context to answer the question at the end. If you don't know the answer, just say that you don't know, don't try to make up an answer. {context} Question: {question} Answer:""" prompt = PromptTemplate(template=prompt_template, input_variables=["context", "question"]) # Create the LLM chain self.llm_chain = prompt | self.llm def answer(self, query: str) -> str: docs = self.retriever.get_relevant_documents(query) input_data = {"context": "
".join([doc.page_content for doc in docs]), "question": query} return self.llm_chain.invoke(input_data) ```

**_Conclusion_**

The Adaptive Retrieval-Augmented Generation (_RAG_) system represents a significant advancement in the field of information retrieval and response generation. By dynamically adjusting retrieval strategies based on the type of query and leveraging _LLMs_ throughout the process, the system ensures more accurate, contextually relevant, and nuanced responses. Whether the user seeks hard facts, detailed analysis, diverse opinions, or personalized answers, the Adaptive RAG system rises to the challenge, providing an experience that is both highly effective and user-centered.

This approach marks a new era in intelligent systems, where adaptability and precision coexist to meet a wide range of information needs.
