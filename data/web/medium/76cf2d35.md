## What if you already have done the Search job?

I have to say, the best way to use newspaper3k (and in general to have reliable and useful sources) is to do the search by yourself.

Maybe for news feed the automated web-search is ok, but for articles, papers and good quality content our eyes are always better!

You can create a good python list with all the resources you consider high quality, something like this:

```python from newspaper import Articlemylist = ['https://www.rtbhouse.com/blog/generative-ai-vs-predictive-ai','https://www.emergentmind.com/topics/token-order-prediction-top','https://news.mit.edu/2025/generative-ai-approach-to-predicting-chemical-reactions-0903','https://www.nature.com/articles/s44387-025-00014-w','https://chatpaper.com/paper/185122'] ```

The we iterate over the list:

```python myresources = []for url in mylist: article = Article(url) # create an instance article.download() #scrape the content from the web article.parse() # return structured content if article.top_image is not None: myresources.append({'text':article.text,'image':article.top_image}) else: print('There is no banner image...') myresources.append({'text':article.text,'image':None})import urllib.requestfrom PIL import Imagedef pImage(url): urllib.request.urlretrieve(url,'banner.png') img = Image.open("banner.png") img.show()for items in myresources: if items['image'] is not None: pImage(items['image']) ```
