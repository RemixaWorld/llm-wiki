In many machine learning tasks, we encounter datasets with a mix of **categorical and numerical features and t** raditional models often require **extensive preprocessing** to convert categorical data into numerical form, using techniques like **One-Hot Encoding** or **Label Encoding**.

However, these methods have limitations, such as **high dimensionality** (for One-Hot Encoding) and **artificial ordinal relationships** (for Label Encoding)

In this article I will cover a solution to those problems called **CatBoost (Categorical Boosting) It’s a gradient boosting algorithm** specifically designed to handle categorical data efficiently, without requiring extensive preprocessing steps

### CatBoost

CatBoost (Categorical Boosting) is a **gradient boosting algorithm** specifically optimized for datasets containing **categorical features**

Unlike traditional machine learning models that require extensive preprocessing, CatBoost can directly handle :

* **Text features**
* **Categorical features**
* **Numerical features**

**One of CatBoost’s advantages is its ability to :**

* Performs well even with a limited amount of data
* As mentioned earlier, CatBoost is particularly well-suited for datasets with many categorical variables, where traditional methods might struggle

### Why is CatBoost Effective for Categorical Data?

To understand why CatBoost performs well on categorical data, let’s consider a dataset where we have:

* **A categorical feature:** city names (“Draria”, “Algiers”, “Oran”)
* **A target variable:** a binary value (**1** if the city is considered ‘smart’, **0** otherwise)

In traditional machine learning, you usually need to encode the categorical values into numerical formats. **Some popular techniques for encoding categorical variables include :**

* **One-Hot Encoding** : Converts categorical variables into binary columns. However, this can significantly **increase the number of features** , especially with high-cardinality categorical variables
* **Label Encoding** : Assigns a unique integer to each category, but this can introduce**unintended ordinal relationships between values**

![Label Encoding and One Hot Encoding. Image Source : https://medium.com/@michaeldelsole/what-is-one-hot-encoding-and-how-to-do-it-f0ae272f1179](https://miro.medium.com/v2/resize:fit:700/0*x_8J_SU5qYXsYiV3)

The problem with these methods is that they **do not inherently preserve the relationship between the categorical feature and the target variable**

CatBoost introduces two key techniques to handle categorical features **efficiently and without target leakage** :

**1 — Ordered Boosting** :

* Traditional gradient boosting methods **compute category statistics using the entire dataset** , which can lead **to**[**data leakage**](<https://www.ibm.com/think/topics/data-leakage-machine-learning>)
* **CatBoost processes data sequentially (** It first **shuffles** the dataset and **only uses past observations** to compute encoding values, avoiding target leakage)

**2 — Target-Based Encoding** : Instead of assigning arbitrary numbers, CatBoost**dynamically computes category encodings** using a statistical transformation 👇🏼

![Target-Based Encoding. Image Source : Dr. Walid Soula](https://miro.medium.com/v2/resize:fit:700/1*h2__TW84XhwJ0fH1es2Sag.jpeg)

* **Current Count** is the number of times the category has appeared with target = 1 before the current row
* **Max Past Count** (Max count)is the total number of times the category appeared **before** the current row (regardless of target value)
* **Prior** is the smoothing parameter (usually **0.5**)

![Example. Image Source : Dr. Walid Soula](https://miro.medium.com/v2/resize:fit:700/1*wf1x19QRM8DrZ56gh5AqJQ.jpeg)

### Mathematics Behind CatBoost

I think for better understanding, I’ll break down the math behind this into several blocks, as it’s a gradient boosting algorithm. I’ll start with the basics of gradient boosting

Gradient boosting builds a model step by step, improving it at each stage, we have :

* The Loss function which measures the difference between the true values and the predictions
* Then we will update our model by adding small corrections at each step

![Prediction model for Gradient Boosting. Image Source : Dr. Walid Soula](https://miro.medium.com/v2/resize:fit:700/1*_o7zfGB-Cll-H4qK9qEQog.jpeg)
* Ft(x) is the current model.
* ht(x) is the new decision tree we add
* γ is a learning rate

Most boosting algorithms use **past and future data** together while training trees, which can lead to **target leakage** (unfairly learning from future data)

But as I already said, CatBoost **fixes this** with **ordered boosting by using only information from previous observations (The example of Draria above),** so**** for each instance xi we would have 👇🏼

![Ordered Boosting. Image Source : Dr. Walid Soula](https://miro.medium.com/v2/resize:fit:700/1*o4wd6rQ1RLKxFQZraZnWbw.jpeg)

* **y^i** is the predicted value for the instance **xi**
* **Ft(xi)** is the model’s prediction at step **𝑡** for instance**x𝑖**
* **∑j <i​** is the sum of all previous boosting iterations
* **hj(xi)** is the weak learner (decision trees with low depth) at iteration**j** , trained only on past data
* **γ** is the learning rate

Now, incorporating the **encoded value** we discussed earlier, we arrive at the final form 👇🏼

![Catboost. Image Source : Dr. Walid Soula](https://miro.medium.com/v2/resize:fit:700/1*J07yufthsb0FhXUXLbdvZQ.jpeg)

* **y^** is the final prediction of the model
* **FT(x)** is the full model’s prediction after **T** iterations
* **T** is the total number of boosting iterations
* **∑j <i​ **represents the sum of all previous boosting iterations
* **hj(xi)** is the weak learner at step **t**
* **γ** is the learning rate

### Importants parameters in Catboost

* **Loss function :** there are differents loss function to chosoie from for both classification (Logloss, CrossEntropy…) and regression (RMSE, MAE…)
* **Pool :** Internal data structure to efficiently store and process categorical and numerical data (It’s not a hyperparameter)
* **GPU/CPU :** Select where you want to run your algorithm
* **Feature Importance :** Determine the parameters that is important for you according to your business domaine
* **Bootstrap :** Defines how data is sampled for each tree (Bayesian (default), MVS (Minimal Variance Sampling) good to reduces overfitting, Bernoulli, Poisson…)
* **Depth :** Controls the depth of trees (affects overfitting)
* **Learning rate :** Controls how fast the model learns
* **L2 leaf reg :** [L2](<https://ai.plainenglish.io/l2-regularization-ridge-regression-cf073e3e67fd>) regularization to prevent overfitting
* **Iterations :** Number of boosting iterations (trees)
* **Cat features :** Specifies categorical features for handling automatically
* **One hot max size :** Defines threshold for one-hot encoding vs categorical encoding

**Note about One hot max size :**

* If a categorical feature has **fewer unique values than one_hot_max_size** , it will be one-hot encoded, for example 2 to 3 categories like “Yes” or “No”
* If a categorical feature has **more unique values** , it will use CatBoost’s internal categorical encoding (based on target statistics) instead, an example of it would be user IDs or ZIP codes
