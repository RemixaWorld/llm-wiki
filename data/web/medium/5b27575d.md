### Kotaemon

[**Kotaemon**](<https://github.com/Cinnamon/kotaemon>) is an open-source, customizable RAG (Retrieve, Augment, Generate) UI designed for both end users and developers to perform QA on documents. It supports various LLM API providers and local LLMs, offering a clean and minimalistic interface forRAG-based QA.

It’s an open-source project to help developers diagnose issues in CI pipelines by analyzing logs and outputs.

The [**repository**](<https://github.com/Cinnamon/kotaemon>) contains Docker images, sample configurations, and a readme that outlines its features and usage.

![image](https://miro.medium.com/v2/resize:fit:700/1*1XW1WB4iJIA_wyEoejon2Q.png)

### Gptme

[**GPTme**](<https://github.com/ErikBjare/gptme>) by Erik Bjare is a command-line interface (CLI) tool that allows users to interact with large language models (LLMs) directly from the terminal.

[**GPTme**](<https://github.com/ErikBjare/gptme>) enables running shell commands, executing code, reading and writing files, and even web browsing through a Playwright integration. GPTme also supports multiple LLM providers and can use local models.

The tool is geared towards developers who want AI-powered assistance for coding, prototyping, and automation tasks within a terminal environment.

![image](https://miro.medium.com/v2/resize:fit:1000/1*4RCgzwsqkV-A5d0UsJlNiA.png)

### Window ai

[**Window AI**](<https://windowai.io>) is a platform that provides in-browser AI capabilities, allowing developers to use AI models directly on client-side applications. It integrates with JavaScript to run models locally in the browser or interact with external APIs.

It is easier to add [**AI**](<https://windowai.io>) functionality such as natural language processing, image recognition, or custom AI logic to web apps without needing a backend infrastructure.

![image](https://miro.medium.com/v2/resize:fit:1000/1*7fLhGucb3FTUklQqDkFGUA.png)

### Dokku

[**Dokku**](<https://dokku.com>) is an open-source platform-as-a-service (PaaS) that helps developers deploy and manage applications easily. It’s often described as a “self-hosted Heroku,” using Docker containers to run apps in isolated environments. Dokku supports multiple languages and databases, integrates with Git for deployment, and allows users to scale applications with minimal effort.

It also includes features for managing SSL, domains, and persistent storage.

![image](https://miro.medium.com/v2/resize:fit:1000/1*6VZSvLq7UFpqK8t2TKS5yA.png)

### Distributed llama

[**Distributed LLaMA**](<https://github.com/b4rtaz/distributed-llama>) focuses on running LLaMA models across distributed systems for scaling large language model inference. It explains how to deploy and manage LLaMA on multiple nodes, allowing for efficient load distribution and scaling.

The documentation covers installation, architecture, and usage with Docker and Kubernetes setups to facilitate seamless large-model deployment across clusters.

![image](https://miro.medium.com/v2/resize:fit:1000/1*S02hUHk4lng4uEWBPVH5vQ.png)

### Appflowy

[**AppFlowy**](<https://appflowy.io>) is an open-source alternative to tools like Notion, providing users with more control over data and customization options. It’s designed for building personal knowledge management systems, task management, and more.

[**AppFlowy**](<https://appflowy.io>) is cross-platform and offers flexibility with plugins and extensions, allowing developers to customize their workflow or add specific features.

![image](https://miro.medium.com/v2/resize:fit:700/1*2I5cqYKA53f730Y9K6-0YQ.png)

### Sherlock

The [**Sherlock Project**](<https://github.com/sherlock-project/sherlock>) is a command-line tool that helps users search for social media profiles based on a given username. It scans hundreds of platforms (like Twitter, Instagram, Reddit, etc.) to see if the username is registered on those sites.

[**Sherlock**](<https://github.com/sherlock-project/sherlock>) is useful for cybersecurity professionals, investigators, and individuals who want to track down an online presence or verify someone’s social media footprint. The tool can also export results for further analysis.

![image](https://miro.medium.com/v2/resize:fit:1000/1*yiaL6tGHkGnyjlRysfHGvA.png)

### Humanifyjs

[**Humanify**](<https://github.com/jehna/humanify>) project is a simple JavaScript library that converts machine-generated data, such as file paths or programmatic strings, into a more human-readable format. It’s particularly useful for transforming technical or code-heavy output into something more understandable and user-friendly.

The tool is useful for developers who want to make data, logs, or error messages more approachable for non-technical users.

![image](https://miro.medium.com/v2/resize:fit:700/1*KzBHcVkQDJTJ3WgJFz8Gag.png)

### Devtools-x

[**DevTools-X**](<https://github.com/fosslife/devtools-x>) is a comprehensive collection of offline-first developer utilities designed to be lightweight, secure, and feature-rich. It is built on top of Tauri, leveraging both web and Rust technologies to create a fast and small application.

The project aims to provide a unified platform for developers across different operating systems, addressing thelimitations of macOS-only `devutils` and Windows-only `devtoys`.
