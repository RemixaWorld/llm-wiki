### Overview of Twelve Labs

Twelve Labs is an AI company specializing in video understanding technology, offering tools for video search, analysis, and content generation. The company’s core focus is on building AI models that can understand videos as well as humans can, which they achieve through their video-native encoder model, **Marengo** , and their video-language model, **Pegasus**.

![Source: Twelve Labs website](https://miro.medium.com/v2/resize:fit:700/0*W_M0d3MBRRJ6c9hE.png)

**Key Features and Capabilities:**

* **Multimodal Embeddings:** Twelve Labs’ Embed API supports embedding content across multiple modalities, allowing users to create connections between text, images, video, and audio data. This enables any-to-any search and retrieval tasks. The Embed API can be used for retrieval augmented generation (RAG), hybrid search, training models, creating high-quality training data, and anomaly detection.
* **Video Search:** The company’s models can search through videos for specific moments using natural language or image queries. This includes searching across speech, text, audio, and visuals. Twelve Labs’ technology can pinpoint exact moments in vast video libraries.
* **Text Generation:** Twelve Labs’ AI can generate text about videos through prompting, including summaries, detailed reports, title suggestions, highlights, and chapters.
* **Customization:** Twelve Labs allows users to fine-tune models with their own data, enabling search in language natural to a team. This customization is a key differentiator from other companies that offer general-purpose models.
* **Multi-vector Approach:** Marengo 2.7 uses a unique multi-vector approach that creates separate vectors for different aspects of the video, such as visual elements, motion, and audio, for more accurate video analysis.

**Technology and Models:**

![Source: Twelve Labs website](https://miro.medium.com/v2/resize:fit:700/0*c0IktREM1_S25oJ7.png)

* **Marengo:** This video-native encoder model is designed to analyze visual frames and their temporal relationships, along with speech and sound for a thorough understanding of both visual and auditory elements. Marengo has been recognized for its performance and powers millions of searches.
* **Marengo 2.7:** This model uses a multi-vector approach, generating separate vectors for visual, motion and audio information. It achieves state-of-the-art performance across several benchmarks, with significant improvements in image-to-visual search capabilities.
* **Pegasus:** This video-language model merges reasoning skills learned from large language models with the perceptual understanding gained from Marengo. Pegasus can generate any text about a video and understands videos in their totality.

**Few Applications:**

Twelve Labs’ technology can be applied to various use cases, including:

* Content moderation
* Ad insertion
* Automated highlight reel generation
* Anomaly detection
* Enterprise video search and analysis

**Step 2: Set up a Vector Database**

```python import lancedbimport pyarrow as pa# Create or connect to a LanceDB databasedb = lancedb.connect("my_video_embeddings_db")# Define the schema for your video embeddings# 1024 is the dimension of video embeddings provided by Twelve Labs Embed APIschema = pa.schema( [ pa.field("video_id", pa.string()), pa.field("embedding", pa.list_(pa.float32(), 1024)), # Adjust the vector dimension as needed pa.field("start_time", pa.float32()), pa.field("end_time", pa.float32()), pa.field("video_url", pa.string()) ])# Create a table for storing video embeddings, providing the schematable = db.create_table("video_embeddings", schema=schema, mode="overwrite") ```

**Step 3: Generating Embeddings with Twelve Labs API**

```python from twelvelabs import TwelveLabsfrom twelvelabs.models.embed import EmbeddingsTask# Initialize the Twelve Labs clienttwelvelabs_client = TwelveLabs(api_key=TL_API_KEY)def generate_embedding(video_url): # Create an embedding task task = twelvelabs_client.embed.task.create( model_name="Marengo-retrieval-2.7", video_url=video_url ) print(f"Created task: id={task.id} status={task.status} model_name={task.model_name}") # Define a callback function to monitor task progress def on_task_update(task: EmbeddingsTask): print(f" Status={task.status}") # Wait for the task to complete status = task.wait_for_done( sleep_interval=2, callback=on_task_update ) print(f"Embedding done: {status}") # Retrieve the task result task_result = twelvelabs_client.embed.task.retrieve(task.id) # Extract and return the embeddings embeddings = [] # Access the segments through video_embedding.segments for segment in task_result.video_embedding.segments: embeddings.append({ 'embedding': segment.embeddings_float, 'start_offset_sec': segment.start_offset_sec, 'end_offset_sec': segment.end_offset_sec, 'embedding_scope': segment.embedding_scope }) return embeddings, task_result# Example usagevideo_url = "video_url"embeddings, task_result = generate_embedding(video_url)print(f"Generated {len(embeddings)} embeddings for the video")for i, emb in enumerate(embeddings): print(f"Embedding {i+1}:") print(f" Scope: {emb['embedding_scope']}") print(f" Time range: {emb['start_offset_sec']} - {emb['end_offset_sec']} seconds") print(f" Embedding vector (first 5 values): {emb['embedding'][:5]}") print() ```

**Step 5: Querying and Retrieving Embeddings**

```python # Function to perform similarity searchdef similarity_search(query_embedding, k=2): results = table.search(query_embedding).limit(k).to_list() return results# Function to get embedding for a text querydef get_text_embedding(text_query): result = twelvelabs_client.embed.create( model_name="Marengo-retrieval-2.7", text=text_query, text_truncate="start" ) # Get embedding from the first (and likely only) segment embedding_vector = None if result.text_embedding.segments: segment = result.text_embedding.segments[0] embedding_vector = segment.embeddings_float return embedding_vector# Example usage: Text-based searchtext_query = "An window with skyscrapers"query_embedding = get_text_embedding(text_query)print("
Query embedding length:", len(query_embedding) if query_embedding else "No embedding found")if query_embedding: search_results = similarity_search(query_embedding) for i, result in enumerate(search_results): print(f"
Match {i+1}:") print(f"Distance: {result['_distance']:.4f}") # Similarity score (lower is better) print(f"Time range: {result['start_time']:.2f}s - {result['end_time']:.2f}s") print(f"Video ID: {result['video_id']}") print(f"Video URL: {result['video_url']}") ```

This code searches for videos similar to a sample text query “An window with skyscrapers”.

* First, it calls the `get_text_embedding` function to get the embedding for the text query "An window with skyscrapers".
* Then, it checks if the embedding was retrieved successfully and prints the length of the embedding vector.
* If the embedding is retrieved, it calls the `similarity_search` function to find the 2 most similar videos (by default) in the database to the query embedding.
* Finally, it iterates over the search results and prints information about each similar video, including the distance (similarity score), time range, video ID, and video URL.
