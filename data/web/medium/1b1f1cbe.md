In a major development, OLLAMA has integrated support for the **Llama 3.2 Vision** models, allowing users to run the 11-billion and 90-billion parameter models. These models are **multimodal** , meaning they can process and understand both text and images as part of a prompt, opening new avenues for advanced AI applications.

Previously, OLLAMA did not support vision models because Llama CPP lacked this capability. However, with the latest update, users can now leverage vision models within OLLAMA for tasks like optical character recognition (OCR), object detection, and even more complex image-based applications.

In this article, we’ll walk through the step-by-step process of setting up OLLAMA for Vision models, testing them with examples, and demonstrating practical use cases.

## Setting Up OLLAMA for Vision Models

To get started with OLLAMA’s new vision model support, the first step is to ensure that you are using **OLLAMA version 0.4** or later. If you’re already using OLLAMA, you’ll need to upgrade your installation to the latest version to access these capabilities.

## Steps to Set Up OLAMA:

1. **Download the latest OLLAMA version** : [Ensure your system has at least **0.4 version.**](<https://ollama.com/download>)
2. **Start the OLAMA server** : Open your terminal and type `olama pull <model_name>`. For example, to download the **11 billion version** , you would run `ollama pull llama3.2-vision`. For 90b Model download run `ollama run llama3.2-vision:90b`
3. **Choose your model** : Depending on your system resources, you can select either the **11-billion model** or the larger **90-billion model**. For users with high VRAM, the 90-billion model is an option.
4. **Run the model** : After downloading, use the command `olama run <model_name>` to run the model.

You can now start processing both text and images. In this tutorial, we’ll be focusing on the model’s **vision** capabilities, which allow it to interpret images.

## Running and Testing Vision Models

With OLLAMA’s multimodal Llama 3.2 Vision models, users can interact with images by providing a **text prompt** followed by an image input. For example, you can ask, “What is in this image?” and upload an image. The model will analyze and describe the contents.
