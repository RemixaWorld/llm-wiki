Simulating and interacting with real-world environments is one of the next frontiers for generative AI models. From robotics to self-driving vehicles, there are countless of scenarios that require generative AI agents to perform actions in real-world environments. Part of the challenges when building these models has to do with the size of the training corpus. Collecting data from real-world environments is particularly complex and expensive. But can we create generative AI agents that simulate entire environments with high fidelity? This is the goal of a [new research from Google DeepMind that showcased GameNGen](<https://arxiv.org/html/2408.14837v1>), pronounced as “game engine”, a model that can simulate a DOOM game using a diffusion model.

GameNGen operates as a generative diffusion model designed to simulate video games. Traditional video games rely on a loop that gathers player inputs, updates the game state, and renders visuals on the screen. This loop runs at high speeds, creating the immersive experience that players enjoy. While these games usually run on standard computers, some unconventional hardware has been used to emulate games like DOOM, though the underlying software remains manually crafted. Regardless of the hardware, the core of game simulation involves predefined rules set by programmers.

Diving Into GameNGen

Recent advancements in generative models, particularly diffusion models, have shown impressive capabilities in creating images and videos based on various inputs. However, generating interactive game worlds involves more than just rapid video generation. The need to account for real-time player actions presents unique challenges for existing diffusion models, leading to instability and difficulties in maintaining the game’s flow over time.

Though several neural models have attempted to simulate interactive games, they often fall short in terms of complexity, speed, stability, or visual quality. This raises an important question: Can a neural model effectively simulate a complex game in real-time while maintaining high visual quality?

GameNGen demonstrates that a complex video game like DOOM can run on a neural network, specifically an enhanced version of Stable Diffusion v1.4, in real-time. The neural model can handle intricate game state updates such as tracking health and ammo, attacking enemies, and interacting with the environment, all while maintaining a quality comparable to the original game.

GameNGen represents a step towards a new paradigm in game engines, where games could be generated automatically, akin to how recent neural models generate images and videos. However, questions remain about how these neural game engines would be trained and how to effectively incorporate human input in the creation process.

GameNGen functions as a generative diffusion model that learns to simulate games within specific settings. To train this model, an initial phase involves a separate model interacting with the game environment. This data, collected from the agent’s actions and observations, forms the training dataset for the generative model.

## Data Collection through Agent Play

The ultimate goal is to have human players interact with the simulation. However, since it’s challenging to gather such data at scale, an automated agent is trained to play the game in a manner resembling a human play. Unlike typical reinforcement learning, which focuses on maximizing scores, this approach prioritizes generating diverse examples to enhance training data efficiency. The reward function, the only environment-specific aspect of the method, is designed to support this goal.

## Training the Generative Diffusion Model

The generative diffusion model is trained using the data collected from the agent’s gameplay. By repurposing a pre-trained text-to-image diffusion model, Stable Diffusion v1.4, the model is conditioned on the agent’s actions and observations. This involves encoding past observations into a latent space and integrating them into the model’s input. Various experiments were conducted to optimize the conditioning process, ultimately refining the model’s performance.

### Agent Training

The agent model is trained using Proximal Policy Optimization (PPO), with a convolutional neural network (CNN) as the feature network. The agent processes downscaled game frames and maps at a resolution of 160x120, utilizing past actions to inform its decisions. The training environment, Vizdoom, is run in parallel across multiple instances, allowing the agent to learn over millions of environment steps. The network is fine-tuned using a batch size of 64 over several epochs, achieving a balance between speed and accuracy.

### Generative Model Training

For simulation, all models are trained from a checkpoint of Stable Diffusion 1.4. Training involves a large batch size and a learning rate optimized for performance. The model undergoes noise augmentation and is trained using a substantial amount of data generated from the agent’s gameplay. The training setup ensures that the model can simulate long trajectories with high fidelity, using context frames to maintain continuity.

## **Latent Decoder Fine-Tuning**

GameNGen utilizes a pre-trained auto-encoder from Stable Diffusion v1.4, designed to compress 8x8 pixel patches into 4 latent channels. However, when predicting game frames, this compression can introduce artifacts that impact small details, particularly affecting elements like the bottom bar HUD (“heads-up display”). To address this while still taking advantage of the pre-trained model, GameNGen focuses on fine-tuning just the decoder part of the latent auto-encoder. This fine-tuning process uses an MSE loss calculated against the target frame pixels, helping to improve the overall image quality.

While this method improves visual fidelity, there is potential for further enhancement by employing a perceptual loss, such as LPIPS, though this remains an area for future exploration. It’s important to note that this fine-tuning of the decoder is done independently from any adjustments made to the U-Net, ensuring that the auto-regressive generation process remains unaffected. This process only involves conditioning on the latent, not directly on the pixels.

## Simulation Quality

GameNGen’s simulation quality closely matches that of the original game, especially over extended gameplay sessions. In short sequences, human evaluators struggle to distinguish between the simulated game and the actual game. The model’s performance is quantified using metrics like LPIPS and PSNR, with results indicating a visual quality comparable to high-compression JPEG images.
