Let’s get started.

Step 01: Now first we need to make sure that we have libreoffice in Mac and Windows, Ubuntu already have libreoffice installed. You can download LibreOffice Installer from Libreoffice website and install it with self explanatory instruction for Installation.

## [Download LibreOffice | LibreOffice - Free and private office suite - Based on OpenOffice …Download free office suite for Windows, macOS and Linux. Microsoft compatible, based on OpenOffice, and updated…www.libreoffice.org](<https://www.libreoffice.org/download/download-libreoffice/?source=post_page-----0b2fe32e9b6a--------------------------------------->)

![image](https://miro.medium.com/v2/resize:fit:700/1*gGr4cEbl31qAClrk7jBdmw.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*aSj23kqqCe9t7Vf_CFOFyA.png)

Step 02: Now Download Localwriter plugin from github repository or libreoffice website.

![image](https://miro.medium.com/v2/resize:fit:700/1*X-GAqkf_ur7rOGTrymsCsg.png)

Step 03: Now open the downloaded plugin with Libreoffice.

![image](https://miro.medium.com/v2/resize:fit:700/1*nMiQXTpJJVzaRAhJuZQ2GQ.png)

Step 04: Click on ok to proceed further.

![image](https://miro.medium.com/v2/resize:fit:700/1*pRrgq7iSI9X6WrXxyufVaA.png)

Step 05: Check and Accept Terms and Conditions to proceed further.

![image](https://miro.medium.com/v2/resize:fit:700/1*DBPcJEWgALyAA0jEKJdnJQ.png)

Step 06: Now open Librewriter from Libreoffice as shown in below screenshot.

![image](https://miro.medium.com/v2/resize:fit:700/1*2TR1vZyP0DuwvHiRnNolKQ.png)

Step 07: Now click on localwriter settings so that we can input details for Ollama or Other LLM Runner.

![image](https://miro.medium.com/v2/resize:fit:700/1*JxLgY7NaFFW-gZAXVnSW8Q.png)

Step 08: Now before we connect librewriter with Ollama make sure that Ollama is serving at localhost:11434 with below command, if you do not have Ollama Installed then just type in Terminal (Mac/Linux) “ curl -fsSL <https://ollama.com/install.sh> | sh” or download installer for windows <https://github.com/ollama/ollama/releases/download/v0.4.7/OllamaSetup.exe>

After Installation finish, just type in Terminal “ollama run llama3” to run the model.

``` ollama serve ``` ![image](https://miro.medium.com/v2/resize:fit:700/1*GtGSzuonTTLffdCBIkV7Iw.png)

Step 09: Now check your Ollama Models which you want to Integrate with Localwriter.

![image](https://miro.medium.com/v2/resize:fit:700/1*Tg6onz378L5RUGA60xYZww.png)

Step 10: Now enter the Ollama settings as shown in below screenshots, Host URL will remain same but you can choose models and tokens as per your requirement, If you are using it in cloud then URL also needs to be changed as per your cloud host.

![image](https://miro.medium.com/v2/resize:fit:700/1*3OHOY_ZcQLbgxjAlJafCEA.png)

Step 11: Now write your question and click on extend selection to get the detailed answer.

![image](https://miro.medium.com/v2/resize:fit:700/1*P2QTiJ019VJo5j6RsSqSSQ.png)

Step 12: You can expect answer as shown below.

![image](https://miro.medium.com/v2/resize:fit:700/1*EFUxyuPYNbh4WmEp9TrDbw.png)
