Diffusers using Civitai FLUX

Hugging Face Diffusers includes a [script ](<https://github.com/huggingface/diffusers/blob/main/scripts/convert_flux_to_diffusers.py>)to convert the original `sft` FLUX1 [model file](<https://huggingface.co/black-forest-labs/FLUX.1-dev/tree/main>) ([flux1-dev.safetensors](<https://huggingface.co/black-forest-labs/FLUX.1-dev/blob/main/flux1-dev.safetensors>))to Diffusers format. However, the script _can not_ convert FLUX Safetensors models from Civitai.com into Diffusers format.

After drilling down into the Civitai FLUX models, I figured out a solution to convert all those FLUX1 from Civitai.com into Diffusers so that we can use and deploy FLUX model with Python. In this article, I am going to cover the conversion and model usage step-by-step

### 1\. Install sd_embed

I uploaded the model conversion source code [here](<https://github.com/xhinker/sd_embed/blob/main/src/sd_embed/conversion_tools.py>). Feel free to download and use it in your own way. The easiest way will be installing the package with the following pip command:

```python pip install git+https://github.com/xhinker/sd_embed.git@main ```

This package also includes embedding functions that support unlimited prompt size with weighting (Yes, Diffusers users deserve the best Diffusion embedding), I may cover the long weighted prompt embedding in another post.

### 2\. Download and convert the Flux1 model from civitai.com

This article will use the highest rated [model: STOIQO NewReality | FLUX, SD, XL, Lightning](<https://civitai.com/models/161068/stoiqo-newreality-or-flux-sd-xl-lightning?modelVersionId=728048>) as the example.

Press enter or click to view image in full size

[model: STOIQO NewReality | FLUX, SD, XL, Lightning](<https://civitai.com/models/161068/stoiqo-newreality-or-flux-sd-xl-lightning?modelVersionId=728048>)

When you have the script or the `sd_embed` package installed, you can convert the model to Diffusers as simple as:

```python from sd_embed.conversion_tools import Flux1Convertorconvertor = Flux1Convertor()model_path = "/path/to/STOIQONewrealityFLUXSD_F1DPreAlpha.safetensors"convertor.convert_to_diffuses(input_safetensor_file_path=model_path) ```

After seconds, you will see a new folder — `STOIQONewrealityFLUXSD_F1DPreAlpha` is created in the same folder of the source safetensors file, inside the folder, a `transformer `folder includes all the converted weights and JSON configuration files.

The structure will be like this:

``` STOIQONewrealityFLUXSD_F1DPreAlpha|---- transformer | ---- config.json | ---- diffusion_pytorch_model-00001-of-00003.safetensors | ---- diffusion_pytorch_model-00002-of-00003.safetensors | ---- diffusion_pytorch_model-00003-of-00003.safetensors | ---- diffusion_pytorch_model.safetensors.index.json ```

That is it, simple and straightforward. Note that only the Transformer weights are converted here, we can reuse the base VAE, CLIP and T5 text encoder from Diffusers base Flux1 model.

Next, let’s load up the model.

### 3\. Load up the converted model with Diffusers

Using the `torchao` solution covered in the [Use Flux.1 Diffusion model with Python — #1](</use-flux-1-diffusion-model-with-python-1-cd5da48f1a6c>) we can load up the quantized model to fit into a GPU with 16GB VRAM.

First, let's load up the Transformer module:

```python import torchfrom diffusers import DiffusionPipeline, FluxTransformer2DModelfrom torchao.quantization import quantize_, int8_weight_only, int4_weight_onlymodel_path = "/path/to/STOIQONewrealityFLUXSD_F1DPreAlpha"transformer = FluxTransformer2DModel.from_pretrained( model_path , subfolder = "transformer" , torch_dtype = torch.bfloat16)quantize_(transformer, int8_weight_only()) ```

And then initialize the FLUX pipeline by reusing VAE and Text encoders from `black-forest-labs/FLUX.1-schnell`.

``` model_path = "black-forest-labs/FLUX.1-schnell"# model_path = "/path/to/black-forest-labs/FLUX.1-dev_main"pipe = DiffusionPipeline.from_pretrained( model_path , transformer = transformer , torch_dtype = torch.bfloat16)pipe.enable_model_cpu_offload() ```

### 4\. Generate images

Now that we have the pipeline, we can use the `sb_embed` to generate embeddings without the 77-token size limitation.

```python from sd_embed.embedding_funcs import get_weighted_text_embeddings_flux1prompt = """\Traditional Chinese Architecture,high quality realistic photo of a female asian women, she is wearing kimono made by silk, belt, beaded bracelet and sandals, (her left hand is handing an old paper with ink brush style English text "Diffusers use civitai FLUX" to the viewer:2.0),she is squatting down with one knee on the ground, her head is heading up and her eyes are looking down to the viewer, she has a sweet smile in face, background is the street of an ancient Chinese town, outdoor, at the day time, natural lighting from the front, the photo is taken from below angle with viewer's Point-of-view shot, """prompt_embeds, pooled_prompt_embeds = get_weighted_text_embeddings_flux1( pipe = pipe , prompt = prompt) ```

Then use the embedding to generate an image.

``` image = pipe( prompt_embeds = prompt_embeds , pooled_prompt_embeds = pooled_prompt_embeds , width = 1024#1280#1024#896 , height = 1024#1280#1024#1280 , num_inference_steps = 25 , guidance_scale = 4.5 , generator = torch.Generator().manual_seed(8)).images[0]display(image) ```
