### Using questionary

The best way to learn about questionary is to look at a few examples.

**Example 1 — A text prompt with validation and default value**

```python ## test.py#import questionaryfrom prompt_toolkit.validation import ValidationError, Validatorclass NumberValidator(Validator): def validate(self, document): try: int(document.text) except ValueError: raise ValidationError( message="Please enter a valid integer.", cursor_position=len(document.text) )def main(): answer = questionary.text( "Enter your lucky number:", default="42", validate=NumberValidator() ).ask() print(f"Your lucky number is: {answer}")if __name__ == "__main__": main()################ Example outputs(base) C:\Users\thoma>python test.py? **Example 4 — Choose from a list of possible inputs**

This will display a list of possible choices. Note that you don’t type in the choice you want. rather, you scroll up and down the list with the arrow keys, then hit Enter on the option you want.

```python import questionarydef main(): fruit_list = ["Apple", "Banana", "Cherry", "Date", "Elderberry"] choice = questionary.select( "Pick your favorite fruit:", choices=fruit_list ).ask() print(f"Your chosen fruit is: {choice}")if __name__ == "__main__": main()################### Example outputs? Pick your favorite fruit: (Use arrow keys) Apple Banana Cherry » Date ElderberryYour chosen fruit is: Date(base) C:\Users\thoma>python test1.py? Pick your favorite fruit: (Use arrow keys) Apple Banana Cherry Date » ElderberryYour chosen fruit is: Elderberry ```

**Example 5— Choose multiple items from a list of possible inputs with optional disabled items**

This is similar to the above example but showcases how you can choose none, one or multiple items. You can also display one or more non-selectable items, i.e., C++, in our example. To choose multiple items, arrow up/down to the desired choice(s) and hit the `**space bar**`to select them. Once you’re happy with your choices, hit the `**Enter**` key.

```python import questionarydef main(): answers = questionary.checkbox( "Which programming languages do you use?", choices=[ "Python", "JavaScript", questionary.Choice(title="C++ (unsupported)", disabled=True), "Go", "Rust" ] ).ask() print("You selected:", answers)if __name__ == "__main__": main()############ Example outputs(base) C:\Users\thoma>python test1.py? Which programming languages do you use? (Use arrow keys to move, <space> to select, <a> to toggle, <i> to invert) ● Python ○ JavaScript - C++ (unsupported) » ● Go ○ RustYou selected: ['Python', 'Go'] ```

**Example 6 -Autocomplete searching a long list of items**

When the user enters text, all matching items in the list beginning with the text are displayed in a list box. The user can then arrow up/down to select their item or keep entering text until the list of possible items narrows.

```python import questionarydef main(): # Suppose we have a large list of country names countries = ["Argentina", "Australia", "Belgium", "Brazil", "Canada", "China", "Denmark", "Egypt", "France", "Germany", "India", "Japan", "Mexico", "Nigeria", "Russia", "South Africa", "United Kingdom", "United States", "Zimbabwe"] choice = questionary.autocomplete( "Type to search for a country:", choices=countries, validate=lambda text: True if text else "Please enter a country name." ).ask() print(f"You selected: {choice}")if __name__ == "__main__": main()##### Example output(base) C:\Users\thoma>python test1.py? Type to search for a country: C Canada China France Mexico South Africa? Type to search for a country: Can CanadaYou selected: Canada ```

**Example 7 — Path Prompt Autocomplete for File or Directory Selection**

Similar to the above example, this time, the user can start to enter a path name for a desired file or directory. A list of files and directories matching what the user has entered appears. **Example 8 — User Input Validation**

Many of the prompts support a `validate` argument, which allows the answer to be validated before being submitted. A user can not submit an answer if it doesn’t pass the validation.

In this example, we implement many common password validation steps that modern systems use. For example, the password must be at least 10 characters long and contain at least one uppercase character and one numeric character, etc ...

Note the actual validation function is written in regular Python. Questionary doesn’t support complex validation patterns; it just facilitates _using_ a validation function on user input.

```python import reimport questionarydef password_validator(password): # 1) Length check if len(password) < 10: return "Password must be at least 10 characters" # 2) Must contain a digit elif re.search("[0-9]", password) is None: return "Password must contain a number" # 3) Must contain a lowercase letter elif re.search("[a-z]", password) is None: return "Password must contain a lower-case letter" # 4) Must NOT contain the word 'password' (any case) elif re.search(r'(?i)password', password) is not None: return "Password must not contain the text 'password'" # 5) Must contain an uppercase letter elif re.search("[A-Z]", password) is None: return "Password must contain an upper-case letter" # If all checks pass else: return Trueprint( questionary.password( "Enter your password", validate=password_validator ).ask())######### Example output## Typed in password1234 to the prompt(base) C:\Users\thoma>python test1.py? Enter your password ************Password must not contain the text 'password'# Typed in this_is_my_secret1 to the prompt(base) C:\Users\thoma>python test1.py? Enter your password *******************Password must contain an upper-case letter# Typed in Mysecretword to the prompt(base) C:\Users\thoma>python test1.py? Enter your password ************Password must contain a number# Typed in Mysecretword1 into the prompt i.e a valid password(base) C:\Users\thoma>python test1.py? Enter your password *************Mysecretword1 ```
