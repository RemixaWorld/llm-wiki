## Small LLM Engineering #10

For years, my notes were just dead text files.

Press enter or click to view image in full size

Image generated using AI

Project ideas I forgot.
Research insights I never reused.
Hard-earned lessons buried in folders.

Last week, I did something extreme.

I fine-tuned a **1B parameter language model** on my own brain dump — and now it answers questions like a second version of me.

And honestly?
It terrified me far more than I expected.

## My “Second Brain” Was Actually a Graveyard

Like most people in tech, I hoarded information:

* Markdown files
* Notion pages
* Research PDFs
* Half-finished project docs
* Random ideas at 2 a.m.

On paper, I had a “knowledge system.”

In reality:

* I couldn’t search it properly.
* I couldn’t connect ideas.
* And I definitely couldn’t _think with it_.

Every time I needed something, I went back to Google, ChatGPT, or Stack Overflow — even though the answers already existed in my own notes.

That contradiction finally broke me.

## Why I Didn’t Use RAG (The Controversial Part)

Yes, I could’ve built a standard RAG (Retrieval-Augmented Generation) pipeline:

* Embed notes
* Store vectors
* Retrieve chunks
* Pass them to GPT-4

I’ve done that. Many times.

But I was frustrated by four big problems:

1. **It never sounded like me.**
It answered like a helpful assistant — not like my thinking.
2. **Context always leaked.**
It forgot long-term assumptions unless I stuffed them into every prompt.
3. **Privacy felt fake.**
My research and private thoughts were constantly leaving my machine.
4. **It searched instead of remembered.**
I didn’t want retrieval.
I wanted _internalized knowledge_.

Then the idea hit me:

> _What if my notes didn’t get searched…
>  What if they got _**_learned_** _?_

RAG gave me access to information.
Fine-tuning gave me access to **my reasoning**.

One searches.
The other remembers.

I didn’t want a search engine for my past.

I wanted a **compressed version of my thinking**.

## The Wild Experiment: Training My Own “Personal LLM”

So I stopped retrieving my knowledge…

…and decided to **teach a model to think in my patterns**.

I didn’t use a giant 70B monster.
I used a **1B parameter model**.

Small enough to run locally.
Large enough to generalize.

The goal was simple:

> _If I ask a question I’ve written about before,
>  it should answer the way I would have answered six months ago._

If this failed, I’d just lose a few hours.
If it worked, I’d be talking to my own thinking.

## The First Real Test (This Is Where It Got Weird)

After training, I asked it something I had **never explicitly written as a Q &A pair**:

> _“What mistake keeps showing up in my AI projects?”_

ChatGPT would usually say something generic:

> _“You may underestimate data quality or overcomplicate architecture…”_

My fine-tuned model answered:

> _“You consistently optimize models before validating if the problem is even worth solving.
>  You did this in the GPS tracking project, the Assamese NLP classifier, and the SQL automation tool.
>  In all three cases, you later simplified the pipeline.”_

That hurt.

Because it was **precisely true — and painfully specific**.

It wasn’t just finding facts.
It had learned my **pattern of failure**.

That was the exact moment this experiment stopped feeling like a demo —
and started feeling like a mirror.

## Phase 2: Turning Notes into a Dataset

I converted messy Markdown notes into `(instruction, response)` pairs.

```python import jsonfrom pathlib import PathDATA_DIR = Path("./my_notes")OUTPUT_FILE = Path("train.jsonl")def build_dataset(): data = [] for path in DATA_DIR.rglob("*.md"): content = path.read_text(encoding="utf-8", errors="ignore").strip() if len(content) < 100: continue topic = path.stem.replace("-", " ").title() entry = { "instruction": f"Explain my thoughts on {topic}.", "response": content } data.append(entry) with open(OUTPUT_FILE, "w", encoding="utf-8") as f: for entry in data: f.write(json.dumps(entry) + "
") print(f"Converted {len(data)} notes.")build_dataset() ```

## Phase 3: The Critical Tokenization Step

⚠️ **Most tutorials break here.**
If you use `padding="max_length"` without masking pad tokens with `-100`, the model learns how to predict silence.

```python from transformers import AutoTokenizerfrom datasets import load_datasetMODEL_ID = "meta-llama/Llama-3.2-1B-Instruct"tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)tokenizer.pad_token = tokenizer.eos_tokendataset = load_dataset("json", data_files="train.jsonl", split="train")PROMPT_TEMPLATE = """You are a specific version of Manash's brain.### Instruction:{instruction}### Response:{response}"""def format_and_tokenize(example): text = PROMPT_TEMPLATE.format( instruction=example["instruction"], response=example["response"] ) tokens = tokenizer( text, truncation=True, max_length=1024, padding="max_length" ) tokens["labels"] = [ -100 if t == tokenizer.pad_token_id else t for t in tokens["input_ids"] ] return tokenstokenized_dataset = dataset.map(format_and_tokenize) ```

## Phase 4: QLoRA Fine-Tuning (The Training)

_This is where the actual brain surgery happens._

```python import torchfrom transformers import AutoModelForCausalLM, TrainingArguments, Trainerfrom peft import LoraConfig, get_peft_modelfrom transformers import BitsAndBytesConfigbnb_config = BitsAndBytesConfig( load_in_4bit=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype=torch.float16)model = AutoModelForCausalLM.from_pretrained( MODEL_ID, quantization_config=bnb_config, device_map="auto")peft_config = LoraConfig( r=16, lora_alpha=32, lora_dropout=0.05, bias="none", task_type="CAUSAL_LM", target_modules=["q_proj", "v_proj"])model = get_peft_model(model, peft_config)args = TrainingArguments( output_dir="llama-personal-brain", per_device_train_batch_size=1, gradient_accumulation_steps=8, num_train_epochs=3, learning_rate=2e-4, fp16=True, logging_steps=10, save_strategy="epoch")trainer = Trainer( model=model, args=args, train_dataset=tokenized_dataset,)trainer.train()model.save_pretrained("final_adapter") ```

Phase 5: Using Your New Brain

```python from transformers import pipelinepipe = pipeline( "text-generation", model=MODEL_ID, device_map="auto")pipe.model.load_adapter("final_adapter")def ask_brain(question): prompt = f"""You are a specific version of Manash's brain.### Instruction:{question}### Response:""" out = pipe(prompt, max_new_tokens=200, temperature=0.7) return out[0]["generated_text"]print(ask_brain("Why did my first RAG pipeline fail?")) ```

## The Verdict: Was It Worth It?

## ✅ Pros

* **Privacy:** Runs 100% offline
* **Speed:** 1B models are instant on consumer GPUs
* **Alignment:** Thinks like _you_ , not like a generic assistant

## ❌ Cons

* **Hallucinations:** Outside your notes, it may invent
* **Frozen Time:** It only knows what you knew at training time

## The Strange Psychological Side Effect

A few days after it started working well, something unexpected happened.

I stopped asking it technical questions.
I started asking it _why I made certain decisions years ago_.

Why I abandoned certain projects.
Why I kept repeating the same architectural mistakes.
Why I always optimized before validating.

Sometimes it defended me.
Sometimes it exposed me.

It no longer felt like a chatbot.

It felt like a **compressed, opinionated version of my past self**.

And that was… deeply uncomfortable.
