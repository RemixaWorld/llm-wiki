### Schema Based Extraction

Press enter or click to view image in full size

source: Xebia

Schema-based extraction is straightforward. Using schemas to define attributes and their types, you can easily leverage libraries like Pydantic.

The question of using schema-based extraction is why you should use Pydantic.

* **Powered by Type hints** — Pydantic uses type hints for schema validation and prompting. This means less to learn, less code to write, and better IDE integration.
* **Customizable** — Pydantic allows for custom validators, error messages, and more, making it highly customizable.
* **Widely Used** — Pydantic is the most popular data validation library for Python, with over 100M downloads a month. FastAPI, Typer, and many other popular libraries use it.

### Components

Various components are crucial in extracting structured data from unstructured or semi-structured data.

* **Pydantic BaseModel** — One of the crucial components in the extraction pipeline, as accurately naming attributes with their types becomes an important part. This step is critical for successful extraction.
* **Prompt** — It’s well known that the more descriptive and specific your prompts to an LLM, the better results you’ll get. Here, we only provide a Pydantic BaseModel as input. Frameworks like Instructor and Indexify then use this BaseModel to create prompts as per their defined prompt templates. This step is the deciding step as it determines how effectively the LLM will produce the desired results.
* **LLM** —In the pipeline, the LLM extracts all the information (with references from the given text) based on the provided prompt, which means better LLM we choose better extraction results we’ll get. These information chunks are then used to extract attributes and convert them into JSON format.
* **Validator** — It comes into play after the LLM step is completed. Validation is to ensure the results returned by the LLM are accurate or not. If the results are incorrect, an error is reported internally and a prompt is reframed, and the pipeline reiterates the extraction process.

## Implementation

We don’t have to start from scratch; we’ll utilize Tensorlake’s Indexify framework to extract these insights.

Indexify is a data framework created to build ingestion and extraction pipelines for unstructured data. These pipelines use declarative configuration, where each stage can perform structured extraction using AI models or transform ingested data. Once data is ingested into Indexify, the pipelines start operating immediately, making them well-suited for interactive applications and low-latency use cases.

source: Indexify

```python from indexify_extractor_sdk import load_extractor, Contentfrom pydantic import BaseModel# PDF extractor initializationpdfextractor, pdfconfig_cls = load_extractor("indexify_extractors.pdfextractor.pdf_extractor:PDFExtractor")# extract content from PDF filecontent = Content.from_file("BalanceSheet.pdf")config = pdfconfig_cls()pdf_result = pdfextractor.extract(content, config)# text content present in PDFtext_content = next(content.data.decode('utf-8') for content in pdf_result if content.content_type == 'text/plain')# define schemaclass Invoice(BaseModel): year: int captial_deposit: int total_liability: int total_assests: int ratio_of_assests_by_liabilities: float bills_collection: int increase_in_deposites_from_2021_to_2022: floatschema = Invoice.model_json_schema()client = IndexifyClient()extraction_graph_spec = f"""name: 'pdf_schema_extractor'extraction_policies: - extractor: 'tensorlake/marker' name: 'pdf_to_text' - extractor: 'tensorlake/schema' name: 'text_to_schema' input_params: service: 'openai' model_name: 'gpt-3.5-turbo' key: 'YOUR_OPENAI_API_KEY' schema_config: {schema} additional_messages: 'Extract information in JSON according to this schema and return only the output.' content_source: 'pdf_to_text'"""extraction_graph = ExtractionGraph.from_yaml(extraction_graph_spec)result = client.create_extraction_graph(extraction_graph)llm_content = next(content.data.decode("utf-8") for content in result if content.content_type == "text/plain")# print all the attributes extractedprint(llm_content) ```

Replace `YOUR_OPENAI_API_KEY` with your actual OpenAI API key.

Now you are ready to extract structured data from PDFs. Activate the default virtual environment created by Indexify to manage dependencies and prevent package conflicts. Use the following code to activate the environment:
