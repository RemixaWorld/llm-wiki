This article introduces a novel tuning-free style transfer method for the Diffusion model, “InstantStyle: Free Lunch towards Style-Preserving in Text-to-Image Generation [1].” Although many style transfer methods have been developed, tuning-free style transfer methods are rare. The advantages of the tuning-free method are that we don’t need to prepare a dataset or additional computation resources(!). In this blog, we will explore the theoretical background of InstantStyle, learn how to implement it in Python, and check its performance.

## **1\. What is Style Transfer?**

Before diving into the InstantStyle, let’s quickly recap the style transfer. As its name suggests, the style transfer can change the style of the target image to correspond to the style of the reference image. The illustration below is the concrete example.

Press enter or click to view image in full size

The illustration of the style transfer by the author. Images are adapted from [the tensorflow tutorial](<https://www.tensorflow.org/tutorials/generative/style_transfer>)

The target image refers to the content, and the reference image represents the style. In this case, the content is a dog, and the style is the art of the reference image. As you can see, the generated image preserves the dog feature but has the style of the reference.

But, how to do this? The important concept is how to clearly separate the style feature from the reference image and the content feature from the target image without leakage. While most research to date has used pre-trained deep neural networks to generate features, the style injection method has varied. One optimizes the network by fine-tuning it to be aligned with the style using a few images, such as DreamBooth [2]. The other utilizes an adapter-like module to separate and inject the style and content, such as IP-Adapter [3].

## 2\. InstantStyle architecture explained

InstantStyle is also one of the style transfer algorithms, but its advantage is that there is no need for fine-tuning or additional training. Even though its method is relatively simple, it can maintain the efficacy for the style transfer. How can it achieve this? To understand profoundly InstantStyle architecture, we will first learn the IP-Adapter.

### 2.1 Preliminary : IP-Adapter

IP-Adapter is one of the diffusion models that can generate the conditioned image. Concretely, it can generate an image with the same content as the reference image with a text condition. For architectural aspects, it introduces an additional adapter to align the feature of the given reference image and text prompt features. It utilizes the Encoder, such as CLIP, for extracting features. The following illustration shows the architecture of this model.

The decoupled cross-attention part is an adapter that aligns the Image Encoder and Text Encoder features. This part can effectively inject the image and text features into the diffusion model and help generate the conditioned image. We only need to train this lightweight adapter. ### 2.2 InstantStyle architecture

InstantStyle leverages the pre-trained diffusion model with IP-Adapter. The illustration below shows InstantStyle architecture.

Press enter or click to view image in full size

InstantStyle architecture adapted from the paper [1]

Likewise, InstantStyle separates the image and text features using IP-Adapter and injects them into the diffusion model to generate a conditioned image. The text feature produces the content, and the reference image has the style (For IP-Adapter, the image produces the content, and the text represents the style). What are the differences between IP-Adapter and InstantStyle? InstantStyle has the following unique features compared to IP-Adapter.

* Inject the style features only the relevant layers to change the style.
* Disentangle the content and style from the reference image by subtracting the content.

For the first line, the authors found that there are only several layers relevant to change the style and layout. Similar to the convolutional neural network, the diffusion model has layers that focus on the low-level representation, such as the shape, color, and etc, and the high-level representation, such as semantic information.

Please see the following table. The authors experimented with which layer is specific to the style and content by injecting the features one by one.

Press enter or click to view image in full size

The experiment result adapted from the paper [1]

The upper left image shows the original generated image without injecting any features. Other images show the generated images that only inject the one layer described to the text on the side below of each image. As you can see, only specific attention layers affect the style or layout of the generated image, such as “down_blocks.2.attentions.1” or “up_blocks.0.attentions.1.” Therefore, the style feature will only be injected into the specific layers.

For the second line, the authors utilize the CLIP Encoder’s characteristic to disentangle the style and content. CLIP Encoder shares the same space between image and text features because of the training loss function. Hence, we can subtract the content feature from the reference image. Here is a diagram of the process.

Press enter or click to view image in full size

The disentanglement process by the author

The reference image originally has the content and style. We want to use the style feature only, so we need to remove the content feature. So, we subtract the text feature that represents the content from the feature of the reference image. Consequently, we can get the feature that has only style information.

In summary, InstantStyle can change the style without additional fine-tuning because of the effective feature injection and disentanglement strategies. Now, we understand the theoretic core of InstantStyle. Let’s implement it using Python from the next section.

## 3\. Python implementation — style transfer using real world data

In this section, we first prepare the environment. Next, we check the capability of InstantStyle. In the last section, I will paste the experiment code to reproduce the results.

Firstly, let’s prepare an environment. I used a conda environment with Python 3.10. I experimented on Ubuntu 20.04 with cuda 11.0, 16 GB GPU and 64 GB RAM.

```python conda create -n InstantStyle python=3.10 -yconda activate InstantStyle# I use /opt/conda/envs/InstantStyle/bin/pip in my enviornment. ```

Next, we install the libraries below via pip and conda.

```python pip install diffusers transformers einops accelerate opencv-pythonpip install git+https://github.com/tencent-ailab/IP-Adapter.gitconda install pytorch torchvision torchaudio pytorch-cuda=12.1 -c pytorch -c nvidia -y ```

Next, we download the official Github repository.

``` git clone https://github.com/InstantStyle/InstantStyle.gitcd InstantStyle ```

We also need to download the pre-trained model weights. The weight files are so large, so we need to set [git-lfs](<https://git-lfs.com/>).

``` git lfs installgit clone https://huggingface.co/h94/IP-Adaptermv IP-Adapter/models modelsmv IP-Adapter/sdxl_models sdxl_models ```

The preparation is all done! Now, let’s implement the inference code. For the first step, we need to define the StableDiffusion-XL pipeline. To reduce the memory consumption, we set the method “enable_vae_tiling.” When this option is enabled, the VAE will split the input tensor into tiles to compute decoding and encoding in several steps.

``` base_model_path = "stabilityai/stable-diffusion-xl-base-1.0"image_encoder_path = "sdxl_models/image_encoder"ip_ckpt = "sdxl_models/ip-adapter_sdxl.bin"device = "cuda"# load SDXL pipelinepipe = StableDiffusionXLPipeline.from_pretrained( base_model_path, torch_dtype=torch.float16, add_watermarker=False,)# reduce memory consumptionpipe.enable_vae_tiling() ```

Next, we need to load the IP-Adapter and define the target blocks for injecting the style feature.

``` # load ip-adapter with the settings below# target_blocks=["block"] for original IP-Adapter# target_blocks=["up_blocks.0.attentions.1"] for style blocks only# target_blocks = ["up_blocks.0.attentions.1", "down_blocks.2.attentions.1"] # for style+layout blockstarget_blocks = ["up_blocks.0.attentions.1"]ip_model = IPAdapterXL(pipe, image_encoder_path, ip_ckpt, device, target_blocks=target_blocks) ```

We need to load the reference image in pil format with 512 resolution.

``` image_path = "<Your reference image path>"image = Image.open(image_path)image = image.resize((512, 512)) ```

Finally, we can generate the style-changed image to call the method below.

``` # generate image variations with only image promptimages = ip_model.generate(pil_image=image, prompt="a cat, masterpiece, best quality, high quality", negative_prompt= "text, watermark, lowres, low quality, worst quality, deformed, glitch, low contrast, noisy, saturation, blurry", scale=1.0, guidance_scale=5, num_samples=1, num_inference_steps=30, seed=42, #neg_content_prompt="a rabbit", #neg_content_scale=0.5, ) ```

Moreover, InstantStyle can also generate images that the style and content are provided from images. In this case, we condition the image using ControlNet [4]. Thanks to the diffusers library, we can easily create the pipeline, including ControlNet.

``` controlnet_path = "diffusers/controlnet-canny-sdxl-1.0"controlnet = ControlNetModel.from_pretrained(controlnet_path, use_safetensors=False, torch_dtype=torch.float16).to(device)# load SDXL pipelinepipe = StableDiffusionXLControlNetPipeline.from_pretrained( base_model_path, controlnet=controlnet, torch_dtype=torch.float16, add_watermarker=False,)pipe.enable_vae_tiling() ```

The rest of the steps are almost identical to the normal InstantStyle method. For the additional step, you need to load the image that represents the content and pass it to the pipeline. The argument “pil_image” represents the image for the style information, and the argument “image” represents the image for the content information.

``` images = ip_model.generate( pil_image=image, # <\- this image for the style information prompt="a cat, masterpiece, best quality, high quality", negative_prompt= "text, watermark, lowres, low quality, worst quality, deformed, glitch, low contrast, noisy, saturation, blurry", scale=1.0, guidance_scale=5, num_samples=1, num_inference_steps=30, seed=42, image=canny_map, # <\- this image for the content information controlnet_conditioning_scale=0.6, ) ```
