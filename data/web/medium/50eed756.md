PDFs are everywhere — invoices, reports, research papers, contracts, and more. Yet, extracting meaningful content from these files has always been a challenge.

![AI Generated Figure](https://miro.medium.com/v2/resize:fit:700/1*OayMx16WB9qK3Hh169n-fg.png)

Different tools specialise in extracting specific content — text, tables, images — but each comes with its own learning curve, syntax, and output format. This often forces developers and researchers to juggle multiple libraries just to get the job done.

[**ParseStudio**](<https://github.com/chatclimate-ai/ParseStudio>) changes this narrative. It provides a single, unified interface that supports multiple parsing backends, making document parsing consistent, beginner-friendly, and efficient. Whether you’re dealing with PDFs, extracting text and images, or analysing tables, it ensures you can focus on your goals, not the tools.

## Why ParseStudio?

## Unified Syntax Across Backends

One of the biggest challenges when working with multiple parsing libraries is learning their APIs. Each backend has its own quirks, which can slow down development and lead to code that’s hard to maintain. This package solves this problem by providing a **unified interface** for interacting with backends like:

* [Docling](<https://github.com/DS4SD/docling>): Ideal for Table extraction and LLM-ready parsed text.
* [PyMuPDF](<https://pymupdf.readthedocs.io/>): Lightweight and efficient.
* [LlamaParse](<https://github.com/run-llama/llama_parse>): Cloud-based and AI-enhanced extraction.

Allowing a quick switch between these backends by changing a single parameter, without modifying the rest of your code.

## Multimodal Parsing with Consistent Output

[ParseStudio](<https://github.com/chatclimate-ai/ParseStudio>) supports extracting **text** , **tables** , and **images** from PDFs using the same syntax. No need to learn separate APIs for each modality — one library handles it all.

First, install via pip:

```python pip install parsestudio ```

Then, use any backend provided to extract structured outputs. For instance:

```python from parsestudio.parse import PDFParser# Initialize the parserparser = PDFParser(parser="docling") # pymupdf, llama# Parse the PDFoutput = parser.run(["path/to/file.pdf"], modalities=["text", "tables", "images"])[0]# Access Text content (Markdown)outputs.text # Access Table contentfor table in outputs.tables: table.markdown # Table in Markdown format table.dataframe # Table as Pandas Dataframe table.metadata # Page number and Bounding Box# Access Image contentfor image in outputs.images: image.image.show() # PIL image image.metadata # Page number and Bounding Box ```

* **Text** : Clean, LLM ready text formatted with Markdown.
* **Tables** : Extracted as Markdown and Pandas DataFrames.
* **Images** : Delivered with metadata like page numbers and bounding boxes.
* **Metadata:** For table and image elements, metadata like the page number and bounding box.

## User-Friendly by Design

To experiment with PDF parsers without diving deep into multiple library documentations, this package abstracts backend-specific complexities. It allows you to focus on extracting content, not troubleshooting syntax.

Even experienced developers benefit from the simplified workflows and reduced setup time, making it a time-saving solution for anyone working with PDFs.

## Supported Backends

## 1\. Docling

![From Github: https://github.com/DS4SD/docling](https://miro.medium.com/v2/resize:fit:700/1*5tIHajoDzyxYAFhcHiui9A.png)

[Docling](<https://ds4sd.github.io/docling/>) is a robust backend, offering advanced document parsing capabilities tailored for complex documents.

**Key Features:**

* **Advanced PDF Understanding:** It comprehends detailed page layouts, reading orders, and table structures.
* **Optical Character Recognition (OCR):** For scanned PDFs or images containing text, Docling integrates OCR to convert images of text into machine-readable text..
* **Table Extraction with TableFormer:** Docling identifies and reconstructs table structures within documents using the TableFormer model.
* **Image Embedding in Markdown:** It allows embedding images directly within the parsed Markdown output, preserving the visual context of the original document.

**Example** **Usage** :

```python from parsestudio.parse import PDFParserfrom docling.datamodel.pipeline_options import PdfPipelineOptions, TableStructureOptions, EasyOcrOptions, TableFormerModefrom docling.backend.docling_parse_backend import DoclingParseDocumentBackend# Optional# Set pipeline options to customize the extraction. Defaults:pipeline_options = PdfPipelineOptions( do_ocr=True, do_table_structure=True, table_structure_options=TableStructureOptions( do_cell_matching=False, mode=TableFormerMode.ACCURATE ), ocr_options=EasyOcrOptions( force_full_page_ocr=True, use_gpu=False ), images_scale=1.0, generate_picture_images=True)# Set Docling backend. Default:backend = DoclingParseDocumentBackendparser = PDFParser(parser="docling", parser_kwargs={"pipeline_options": pipeline_options, "backend": backend}) ```

**When to Use Docling:**

* When dealing with complex documents requiring detailed layout analysis.
* For documents containing scanned images or text encoded in unknown fonts, where OCR is necessary.
* When precise table extraction is crucial for data analysis.

## 2\. PyMuPDF

![From Github: https://github.com/pymupdf/PyMuPDF](https://miro.medium.com/v2/resize:fit:460/1*zSeTGkdEScAwuvRV9QIjEA.png)

[PyMuPDF](<https://pymupdf.readthedocs.io/>) is a lightweight and highly efficient backend, perfect for tasks that prioritise speed and simplicity. Built on the MuPDF engine, it is ideal for parsing PDFs with minimal dependencies.

**Key Features:**

1. **High Performance:** Optimised for speed, making it suitable for processing large batches of PDFs.
2. **Minimal Dependencies:** Requires minimal installation, ensuring quick setup and low resource usage.

**Example Usage:**

```python from parsestudio.parse import PDFParserparser = PDFParser(parser="pymupdf") ```

**Best Use Cases:**

* Quick extraction.
* Scenarios requiring a lightweight parser with minimal setup.

## 3\. LlamaParser

![Image from https://bap-software.net/en/knowledge/llamaindex-and-how-it-works/](https://miro.medium.com/v2/resize:fit:640/1*h2hZV61W9uy4xx9qt0An7g.png)

[LlamaParse](<https://github.com/run-llama/llama_parse>) is an AI-enhanced backend, designed for handling unstructured complex layouts and non-standard content.

**Key Features:**

1. **AI-Powered Parsing:** Leverages AI models for improved accuracy in content extraction from documents with complex layouts.
2. **API-Driven Workflow:** Cloud-based solution for large or complex documents without stressing local resources. Requires an API key.

**Setup Instructions:**

1. Create a `.env` file in the root of your project.
2. Add your [Llama Index](<https://www.llamaindex.ai>) API key:`LLAMA_PARSE_KEY=your-api-key`

**Example Usage:**

```python from parsestudio.parse import PDFParser# Set options to customize extracion. Defaults:llama_options = { 'show_progress': True, 'ignore_errors': False, 'split_by_page': False, 'invalidate_cache': False, 'do_not_cache': False, 'result_type': 'markdown', 'continuous_mode': True, 'take_screenshot': True, 'disable_ocr': False, 'is_formatting_instruction': False, 'premium_mode': True, 'verbose': False}parser = PDFParser(parser="llama", llama_options) ```

**Best Use Cases:**

* Parsing unstructured documents with complex layouts.
* Applications requiring cloud-based AI for scalability.
