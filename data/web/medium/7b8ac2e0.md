Microsoft Copilot offers a convenient way to summarize your Teams meetings. It is integrated into the Microsoft 365 ecosystem, making it super convenient for summarizing meetings in real time. It pulls out key points, action items, and decisions, syncing effortlessly with your other Microsoft tools. But here’s the thing: Copilot is primarily designed for meetings on platforms like Teams. What if you have audio/video files from different sources, like panel discussions or casual brainstorming sessions? This article dives into the power of open-source tools, specifically Pyannote and Whisper, to achieve just that.

## Pyannote

[Pyannote](<https://github.com/pyannote/pyannote-audio>) is an open-source toolkit designed for speaker diarization, which is the process of segmenting an audio stream by speaker identity. This tool is crucial for meetings with multiple participants, as it allows for the identification and separation of different speakers within an audio recording. Pyannote uses advanced machine learning algorithms to achieve high accuracy in distinguishing between speakers. The core of Pyannote’s diarization pipeline involves:

* **Step 1 — Local neural speaker segmentation:** Applying the end-to-end neural speaker segmentation model using a sliding window of 5s with a step of 500ms.
* **Step 2 — Local speaker embedding:** Extracting Kw speaker embeddings for each window w: exactly one embedding per speaker who is active within the window w.
* **Step 3 — Global agglomerative clustering:** Clustering the resulting set of speaker embeddings to assign each local speaker to a global cluster.
* **Step 4 — Final aggregation:** Aggregating the clustered local speaker segmentation into an actual speaker diarization output.

If you want to review the technical report in detail, it is available [here](<https://huggingface.co/pyannote/speaker-diarization/blob/main/technical_report_2.1.pdf>). Pyannote also has a [commercial version](<https://pyannote.ai/>) available which, as per the website, is faster and more accurate. For our purpose though, the open-source version is more than enough.

## Whisper

Developed by OpenAI, [Whisper](<https://github.com/openai/whisper>) is a state-of-the-art model for speech recognition and transcription. Whisper excels at converting spoken language into text with high accuracy, even in noisy environments. The model employs a deep learning architecture, specifically a transformer-based neural network, to perform transcription tasks. Key features of Whisper include:

* **Robustness:** Whisper is trained on a diverse dataset encompassing various languages and audio conditions, making it robust to different accents and background noises.
* **End-to-end model:** Whisper processes raw audio directly to produce transcriptions, eliminating the need for intermediate feature extraction steps.
* **Pre-trained and fine-tuned models:** Whisper is available in multiple sizes, from small models suitable for real-time applications to large models that offer higher accuracy but require more computational resources.

## Step 4: Summarization

Now comes the summarization part. With a speaker-labeled transcript in hand, we can leverage the power of a large language model like Google Gemini 1.5 Flash or Open AI GPT 4. By feeding this transcript to Gemini or GPT, you can extract the key points and generate a concise summary of the entire meeting, capturing the essence of each speaker’s contribution. For this, you can also use open-source models like LLAMA 3.1. I will be using Google Gemini API here. The website user interface will work fine as well.

```python import google.generativeai as genaifrom IPython.display import MarkdownGOOGLE_API_TOKEN = userdata.get('GOOGLE_API_KEY')genai.configure(api_key=GOOGLE_API_TOKEN)llm = genai.GenerativeModel('gemini-1.5-flash', generation_config=genai.GenerationConfig( temperature=0.9, ))with open('transcription.txt','r') as file: transcription = " ".join(line for line in file) file.close() prompt = f"""This is a transcript of a discussion whereeach speaker is idenified along with the time that the spekaer is speaking.Please summarize this discussion by indicatingthe speaker names: {transcription}"""summarization_result = llm.generate_content(prompt) Markdown(summarization_result.text) ```

As briefly discussed above, using Pyannote and Whisper for meeting summarization offers several advantages over proprietary solutions like Microsoft Copilot:

* **Flexibility:** This method can be applied to any audio or video recording, not just those from Microsoft Teams meetings. This makes it versatile for various contexts, including panel discussions, webinars, and informal conversations.
* **Customization:** Open-source models can be tailored to specific needs, allowing for greater control over the processing and summarization steps.
* **Cost-effectiveness:** By leveraging free, open-source tools, organizations can reduce costs associated with proprietary software solutions.
* **Transparency:** Access to the underlying algorithms and data processing methods ensures transparency and the ability to optimize the models as needed.
