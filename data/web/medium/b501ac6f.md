# Reinforcement Learning from Prediction Feedback : LLM fine-tuning method to generate user summaries for Personalization systems

LLM-powered personalization agent systems use LLMs to predict users’ behavior from their past activities, with effectiveness hinging on ability to effectively leverage extensive, long user historical data due to its inherent noise and length of such data.

To address these challenges, authors of this paper[1] introduce Reinforcement Learning from Prediction Feedback (RLPF). RLPF fine-tunes LLMs to generate concise, human-readable user summaries that are optimized for downstream task performance

**Key contributions:**

* introduce the novel task of generating natural language user summaries for user modeling and personalization systems. This offers an interpretable alternative to traditional embedding-based representations and allows utilization by arbitrary LLMs without further training
* introduce RLPF, a novel and easy-to-implement method for training user summarizers. RLPF eliminates the need for reference summaries or hand-crafted prompts, while safeguarding user privacy.
* demonstrate that RLPF summaries outperform baselines on both the training task and unseen tasks across four datasets and domains
* evaluate RLPF summaries intrinsically and find significant improvements in factuality, abstractiveness, and readability

## Components

RLPF: Reinforcement Learning from Prediction Feedback (illustrated in Figure below),includes three components:

![image](https://miro.medium.com/v2/resize:fit:700/1*kbwimRhYuJrkGwCzWN8DKA.png)

### i) Summarization Model:

* A model is trained to generate succinct user summaries from raw activity data.

### ii) Prediction-based Reward Model:

* To compute a reward, we measure the effectiveness of the generated summaries in downstream prediction tasks.

### iii) Feedback Loop:

* The reward is then used to update the summarization model with RL, with an additional reward to encourage shorter lengths.
* This feedback loop guides the summarization model to continuously refine its ability to produce summaries that are not only concise but also highly effective for their intended applications.

## Methodology

### i) Problem Statement

* Consider a set of users U = {ui}Mi=1, where each user i has an associated chronologically ordered sequence of interactions, denoted as {v1i , v2i , …, vNi }. Each vji within this sequence (where 1 ≤ j ≤ N) comprises one or more textual features that describe a specific item, such as the titles or ratings of movies watched by the user.
* For each user i, we concatenate all of their interactions {vji }Nj =1 into a single string to form the user context ui.
* A summarizer model πθ takes as input the user context and generates a summary si = πθ(ui). The summary is then provided to off-the-shelf LLM to produce a prediction ˆyi = P(si) for a specific downstream task.
* We optimize πθ to generate summaries {si}Mi=1 that minimize the expected error between the predictions {ˆyi}Mi=1 and the ground truth task labels {yi}Mi=1.

### ii) Reinforcement Learning from Prediction Feedback

* summary generation can be formulated as a Contextual Markov Decision Process (CMDP).
* In this framework, the state encompasses both the input text and the partially generated summary, while actions correspond to the selection of tokens from the entire vocabulary.
* At each step, the policy model maps these states to probability distributions over the vocabulary, facilitating autoregressive token selection.
* This selection process is guided by the current context and the overarching objective of maximizing cumulative rewards.

**a) Formalizing RLPF for summarization**

Within the RL framework mentioned, we formalize RLPF in the context of user summarization as follows:

* State: The set of user contexts U = {ui}Mi=1, where each ui is a single string representing the textual features of a user’s N past activities.
* Action: The set of user summaries S = {si}Mi=1 generated based on the corresponding user contexts.
* Policy Model: The summarizer model, denoted by πθ, which maps user contexts (states) to user summaries (actions):π(ui; θ) → si.
* Reward: We leverage a frozen, pre-trained LLM to generate predictions P(si) for one or more specified tasks based on user summaries si. Then a scalar reward value is computed by comparing the prediction P(si) with its corresponding ground truth label yi of the specific task.

**c) Training Process**

* Unlike the standard RLHF pipeline, which sequentially involves supervised fine-tuning, reward modeling, and policy optimization, RLPF directly optimizes the policy in a single RL training step
* By leveraging LLMs’ inherent zero-shot summarization and prediction capabilities, RLPF eliminates the need for intricate prompt engineering, generating feedback for the RL process based on predicted future activities
* While RLPF is not tied to any specific RL algorithm, we utilize REINFORCE [2] with a baseline to update the policy model given that it is simpler yet still effective for our tasks. Both policy and value models are initialized from a frozen model.

## Experimental Details

### i) Dataset

* conducted experiments on four public datasets grounded in real-world user interactions, encompassing product reviews,movie watching behavior, and location data
* performed training on Amazon Books (He and McAuley 2016), Google Local Review (Yan et al. 2022), MovieLens 2015(Harper and Konstan 2015). Additionally, we utilized another four Amazon Review datasets with different product categories, as well as MovieLens 2003, which features distinct users and movie catalogs compared to MovieLens 2015).

**a) Data Generation**

* For each user’s interaction data, presented as a chronologically ordered list of activities ui ∈ U, we randomly select one item as the target for future activity prediction, denoted as yi
* utilize the N activities preceding this target as the past activities {vji }Nj =1. vji represents an item name and rating pair, where item name correspond to movie title for MovieLens, product name for Amazon Review, and place name + city name for Google Local Review, respectively

### ii) Evaluation

evaluate user summaries along the following three dimensions:

* **Predictiveness:** gauge the predictiveness of the summaries based on their prediction performance in various downstream tasks
* **Factuality, Abstractiveness, and Readability:** For each criterion and overall quality, the Auto Rater compares a pair of summaries, with their relative positions randomly assigned to eliminate potential bias in the evaluation.

### iii) Training Details

* summarizer model, or policy model πθ, is initialized from Gemini 1.0 Nano-2(instruction tuned) and fine-tuned using RLPF
* During training, reward computation (P(si)) is performed by a frozen, instruction-tuned Gemini 1.0 Pro model, which predicts future activity based on the generated summary si. Gemini 1.0 Pro was selected for its optimal balance of performance and inference efficiency.
* For all three training datasets (Amazon Books, Google Local Review, and MovieLens 2015), we trained the policy model with a batch size of 64, utilizing the Adafactor optimizer with a learning rate of 1e-6.

## Results

### i) Target Task Performance

* Figure below compares RLPF performance on the Future Activity Prediction task.

![image](https://miro.medium.com/v2/resize:fit:700/1*X1UCXo6n7Q-oTu7C9ca6oQ.png)
* Across all three datasets, RLPF demonstrates superior or comparable performance to various summarizers, including crafted prompting, a larger summarizer model, and RLAIF
* Overall, RLPF outperforms Nano-2 zero-shot summaries by +13.4% improvement, and outperforms RLAIF by +22% on average
* Compared to utilizing the full user context (all activities), RLPF achieves an average context length compression of -73.8% while still exhibiting a +12.4% performance gain

### ii) Transferability and Generalization

* RLPF summaries demonstrated a slight improvement on an unseen retrieval task, common city retrieval on Google Local Review, and performed on par with zero-shot summary on an unseen personalized text generation task, review generation on Amazon Books.

* evaluated whether an RLPF trained model can generalize to an unseen dataset, either in same domain or a different domain

* From the results, RLPF model trained on MovieLens 2015, showed improvements on both unseen datasets

## Conclusion

* introduced RLPF, a novel method for generating concise and human-readable user summaries from raw activity data.
* RLPF leverages readily available LLMs and downstream task performance as reward signals, overcoming challenges in traditional summarization approaches.
* experiments demonstrate superior performance, context compression, and generalizability across unseen tasks. Future work will extend RLPF to more complex scenarios, incorporate additional feedback mechanisms, and explore its application to other LLM capabilities
