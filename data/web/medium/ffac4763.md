>  _“The art of teaching is the art of assisting discovery.”_ — **Mark Van Doren**
>
>  _“The mediocre teacher tells. The good teacher explains. The superior teacher demonstrates. The great teacher inspires.”_ — **William Arthur Ward**

[Large Language Models (LLMs)](<https://github.com/SalvatoreRa/tutorial/blob/main/artificial%20intelligence/FAQ.md#:~:text=What%20is%20a%20Large%20Language%20Model%20\(LLM\)%3F>) have shown great abilities in solving reasoning problems, but they often require training on vast amounts of (problem, solution) pairs. Collecting these pairs from humans is obviously expensive and also takes quite some time. Therefore, researchers have tried to find an alternative approach: using [synthetic data](<https://en.wikipedia.org/wiki/Synthetic_data>). To obtain synthetic data, typically one [LLM](<https://en.wikipedia.org/wiki/Large_language_model>) is used to generate these pairs and then another LLM is trained on these synthetic data.

According to some studies, this approach not only works but is actually better than using pairs obtained from humans. In general, the rule is to choose a strong LLM to be able to generate these pairs (or at least more capable than the LLM we would fine-tune with these pairs). This means taking a large LLM and a set of problems and then conducting different sampling for each problem. Using a strong LLM for this approach is therefore likely to be expensive.

This approach in general is called [knowledge distillation](<https://github.com/SalvatoreRa/tutorial/blob/main/artificial%20intelligence/FAQ.md#:~:text=What%20is%20knowledge%20distillation%3F>), that is, when we try to distill the knowledge gained from one model and use it to conduct fine-tuning of another model. It is one of the most widely used approaches, especially when we want to teach a particular skill to a smaller model

> Can we instead use a model that is weaker but cheaper?

At infinite budget using a weaker but cheap model (WC) does not necessarily make sense. A stronger but more expensive (SE) model generally produces better reasoning and more correct answers. With a limited computing budget though, a WC model will produce many more errors, however, it allows us to produce many more and more varied answers (we can conduct more sampling).

When we conduct this sampling we are interested in three factors:

* **Coverage**. the number of unique problems that are solved.
* **Diversity**. the different solutions we get for each problem.
* **false positive rate (FPR)**. the percentage of problems that have a correct final solution but the reasoning is wrong.

Now a WC model will probably have a higher FPR, but it should produce for a fixed computing budget a higher diversity and coverage. Is this enough to get better fine-tuning models?

According to most researchers, it would be better to have few but good ones and then use an SE model, but is that really the case? A new Google DeepMind paper tries to get to the bottom of the question.

## [Smaller, Weaker, Yet Better: Training LLM Reasoners via Compute-Optimal SamplingTraining on high-quality synthetic data from strong language models (LMs) is a common strategy to improve the reasoning…arxiv.org](<https://arxiv.org/abs/2408.16737?source=post_page-----c31494057c67--------------------------------------->)

We have dataset D of problems with n issues q and n corrected answers a. For a subset of these problems, we pass them through an LLM and have it respond by producing an answer but also a reasoning chain (see chain-of-thought). Typically, we filter out those answers that are different from the golden answer (the one in the dataset). Instead, the problem is to filter out those answers that have yes correct answer but wrong chain-of-thought (when the learner arrives at the right answer by getting the reasoning wrong). Once we filter the obtained dataset we can calculate Coverage as the fraction of questions that have at least one correct solution and diversity and the average of correct solutions per question (for each correct solution we can have several correct reasonings).

For a specific fixed budget, one can generate more examples with a WC model than an SE model (an SE model has many more parameters and thus consumes the budget with fewer examples). Depending on the parameters of the two models we can calculate a sampling ratio (the ratio of examples generated for the same computing budget for two models). This ratio is a function of the parameters of the models (as somewhat expected).

image source: [here](<https://arxiv.org/pdf/2408.16737>)

The authors then decide to test three fine-tuning setups.

* **Student-LM finetuning**. classical [knowledge distillation](<https://neptune.ai/blog/knowledge-distillation>) in which they use a WC or SE model as a teacher.
* **WC-LM finetuning.** In this case, they conduct the [fine-tuning](<https://en.wikipedia.org/wiki/Fine-tuning_\(deep_learning\)>) of a WC model through self-generated data (or with SE data). Self-improvement is an interesting technique in which the model provides the same data and they compare it with distillation from SE.
* **SE-LM finetuning**. test a different approach to the one usually done (in classical distillation one conducts finetuning of the WC model with SE, here instead the perspective is reversed) and compare it with self-improvement of SE with self-generated data

The authors took two reasoning datasets for the system ([MATH ](<https://paperswithcode.com/dataset/math>)and [GSM-8K](<https://paperswithcode.com/dataset/gsm8k>)) containing several math problems. They used [Gemma2–9B](<https://huggingface.co/datasets/open-llm-leaderboard/google__gemma-2-9b-details>) and [Gemma2–27B](<https://huggingface.co/google/gemma-2-27b>) as WC and SE as models, respectively. For each problem, they generated several solutions (the second model being about three times the first, at fixed computing budget they had about three times as many problems solved).

Initial results show that:

* The smaller model has greater coverage than the larger model (meaning that more datasets can be obtained with a WC model since it can solve more unique questions with a fixed budget).
* With the smaller model, you also have more diversity, so you get more reasoning leading to a correct solution.
* As for the false positive rate (FPR) obviously is higher with the WC model, but still not dramatic in absolute terms.

At this point, they evaluated the models after fine-tuning. In the Student-LM Finetuning setting, the model trained with synthetic data from WC outperforms the results of the model finetuned on data from SE.

> Contrary to the common belief of stronger models being better for knowledge distillation, our results indicate that finetuning on data from WC is more compute-optimal than data from SE. — [source](<https://arxiv.org/pdf/2408.16737>)

Similar results are obtained when using a WC model to conduct self-improvement (WC-LM Finetuning), this approach is more compute-optimal than distillation from a stronger model. Similar results are also obtained in the third setting (SE-LM finetuning) so even a large model has a greater benefit with data obtained from a smaller model (this is particularly interesting for future developments where small models could be used to train larger models).

> Overall, our findings challenge the conventional wisdom that advocates training on samples from the SE model, by showing that training on samples from the WC model may be more compute-optimal across various tasks and setups. — [source](<https://arxiv.org/pdf/2408.16737>)

The authors conduct ablation studies, showing some interesting results. The first is the size of the dataset impacts this effect, this effect is more pronounced in the low problem regime (probably because if one uses many more examples the diversity effect obtained from the smaller model is lost).

Given the same examples, the SE model wins. So if one has enough compute budget there is no need to use a small model.

In addition, the authors note that the best results are obtained when you have datasets that have high coverage and high diversity, thus allowing the student to learn better.

image source: [here](<https://arxiv.org/pdf/2408.16737>)

In the last experiment, they confirmed the previous results using a state-of-the-art model ([Gemini](<https://deepmind.google/technologies/gemini/>)). For the same computing budget, the results with WC models are superior.

image source: [here](<https://arxiv.org/pdf/2408.16737>)

> We demonstrate that price-matched sampling from weaker SoTA LMs produces superior reasoners compared to finetuning with data from stronger SoTA models. — [source](<https://arxiv.org/pdf/2408.16737>)

This article is particularly interesting because it goes against the current opinion that in training a model in finetuning one must use synthetic data obtained from a strong model. Instead, for the same computing budget it is better to use the synthetic data obtained from a smaller and cheaper model.

Also shows that this applies even with models that are state-of-the-art. So it means that in case of a small monetary budget one may prefer to use a smaller model than having to spend money on a closed-source model.

a last result, the authors show the trend between smaller and larger models on math reasoning datasets, and this gap seems to be decreasing. This shows that using smaller models is a real prospect and will have an impact in the future.
