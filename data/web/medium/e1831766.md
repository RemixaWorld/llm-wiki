## Evaluating the Agent with Giskard.

The first step is to install the Giskard library

```python !pip install -q giskard[llm]==2.15.1from giskard.rag import KnowledgeBase, generate_testset, evaluate ```

After installing Giskard, three classes are loaded: **KnowledgeBase** , **generate_testset** , and **evaluate**.

The first of these classes will be used to create a knowledge base with the data we specify, which in this case will be the same as what we’ve inserted into the vector database, the one from the medical dataset.

This knowledge base is used to generate a test dataset composed of a set of questions along with their answers.

```python import pandas as pddf_giskard = pd.DataFrame([d.page_content for d in df_document], columns=["text"]) ```

Using the information from the dataset, we ask Giskard to create a Knowledge Base, which is nothing more than a set of questions along with their respective answers. Both the questions and answers are generated by OpenAI’s most advanced model, which is why it requires our OpenAI key to be provided.

``` kb_giskard = KnowledgeBase(df_giskard)# The more questions you generate, the more you will be charged.test_questions = generate_testset( kb_giskard, num_questions=10, agent_description="Medical assistant for diagnosis and treatment support.",) ```

Keep in mind that creating this dataset can involve a significant cost, as it requires making calls to OpenAI. In a real project, I would recommend to save the dataset instead of recreating it every time you want to evaluate the model.

Let’s se an example of a question /answer contained in the test_questions dataset:

**question** : What measures can be taken to prevent La Crosse encephalitis virus (LACV) infection?

**answer** : There are several approaches to prevent La Crosse encephalitis virus (LACV) infection: use insect repellent containing DEET, picaridin, IR3535, or oil of lemon eucalyptus on exposed skin and clothing; wear protective clothing….

Now, you can use the _evaluate_ function to compare the responses of the agent with those generated by the state-of-the-art model with Giskard.

```python def use_agent(question, history=None): answer=agent_executor.invoke({"input": question}) return answer['output']report = evaluate(use_agent, testset=test_questions, knowledge_base=kb_giskard) ```

A function is created that will be called from Giskard’s evaluate function. This function receives the question and returns the agent’s response.

Within the **evaluate** function, each of the questions in the dataset is used to call the **use_agent** function, and the returned result is compared with the reference result stored in the dataset.

The evaluation report has been stored in the variable _report_ with the data from the assessment performed on our system. All this information can be used to improve our RAG system, whether by adjusting the model used or by modifying how information is stored or retrieved from the vector database, or maybe, just adapting the prompt.

## Conclusion.

As you’ve seen, Giskard is a very powerful tool. Not only does it show us which types of questions challenge our system, but it also allows us to identify the topics that are the most difficult and pinpoint which part of the system requires more attention.

One of the most important features is that you can create a dataset with the questions Giskard deems incorrectly answered. In this dataset, you’ll find all the necessary information to analyze what might have gone wrong.

The biggest issue with Giskard is the potential cost of creating the question dataset and the evaluation process. Therefore, a clear update policy should be established for both.

It’s clear that the dataset should be created only once and maintained over time by gradually adding more questions. Similarly, evaluations don’t need to be performed on the entire dataset each time. After an initial baseline evaluation, you can focus on specific topics or question types for future evaluations.

The ways to improve the system are also varied. Giskard only provides the information but doesn’t suggest specific actions for improvement. You could change the agent’s memory system, or perhaps remove it, adjust the chunk size or overlap, improve the prompt… there are countless possibilities.
