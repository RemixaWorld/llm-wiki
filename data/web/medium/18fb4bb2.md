## Getting Started with ScoutSense Recruit

ScoutSense Recruit leverages AI-powered tools to simplify and enhance the recruitment process. This guide walks you through setting up the platform locally using a **Conda environment**.

### Prerequisites

Before setting up ScoutSense Recruit, ensure your system meets the following requirements:

* **Python 3.8 or higher**
* **Git** installed on your machine
* **Conda** (installed via [Anaconda](<https://www.anaconda.com/>) or Miniconda)

### Step 1: Clone the Repository

To start, clone the ScoutSense Recruit GitHub repository to your local machine:

``` git clone https://github.com/di37/scoutsense-recruit.gitcd scoutsense-recruit ```

This will create a local copy of the repository in a folder named `scoutsense-recruit`.

### Step 2: Set Up a Conda Environment

**1\. Create a Conda Environment**

ScoutSense Recruit requires specific dependencies. Create a dedicated Conda environment for the project:

``` conda create --name scoutsense python=3.10 -y ```

Activate the environment:

``` conda activate scoutsense ```

**2\. Install Required Dependencies**

Use the provided `requirements.txt` file to install the dependencies. Run:

```python pip install -r requirements.txt ```

### Step 3: Run the Application

Once the environment is set up and configured, you can start the application by running:

``` python app.py ```

The application will initialize, and the server will start running, usually accessible at [http://localhost:8501](<http://localhost:8501/>).

## The Technical Backbone

Scout Sense is built on a robust technical foundation, leveraging the following technologies:

* **Streamlit** : A simple and powerful framework for building interactive web applications, Streamlit powers the Scout Sense UI, providing a seamless user experience.
* **Large Language Models** : The platform integrates OpenAI’s GPT-4o and Google’s Gemini models, offering a range of options for resume analysis and question generation.
* **Python** : The backend is developed in Python, utilizing libraries such as PyPDF2 and Beautiful Soup for document parsing and web scraping.

## What sets Scout Sense apart from other HR apps?

Scout Sense stands out from other HR apps by offering a combination of features and technical strengths that differentiate it in the recruitment technology space:

**Real-time Analysis and Tailored Feedback:**

* It generates actionable feedback for candidates and offers compatibility scores that help recruiters make informed decisions in real time.

**Automated Interview Question Generation:**

* Based on a candidate’s resume and role requirements, the platform creates tailored interview questions.
* These questions are categorized by difficulty level, saving recruiters time and ensuring high-quality, targeted interviews.

**Scalability:**

* The platform can handle a large volume of resumes efficiently, making it suitable for organizations of all sizes, from startups to large enterprises.

**Bias Minimization:**

* By relying on data-driven insights, Scout Sense reduces the human biases often present in manual resume screening and interview preparation processes.

**Focus on Recruiters’ Needs:**

* Unlike other platforms that often prioritize candidates, Scout Sense is explicitly designed to make recruiters’ lives easier by automating mundane tasks and providing insightful data.
