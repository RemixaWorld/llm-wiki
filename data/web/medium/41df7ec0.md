### What Are Structured Outputs?

Structured outputs ensure that AI-generated content follows a specific, consistent format. This capability is particularly crucial for tasks where predictable results are needed — such as extracting structured data, generating JSON, or producing formatted code snippets. By tailoring outputs to meet exact requirements, Ollama eliminates the trial-and-error commonly associated with prompt engineering.

## How Does It Work?

Ollama uses a combination of advanced language models and schema validation frameworks like **Pydantic** to deliver structured outputs seamlessly. Developers can define the expected structure of outputs using tools such as Pydantic models and then pass these structures to the chat API. The AI is prompted to generate content conforming to the specified schema.

### Step-by-Step Process

1. **Define the Schema** :
Use Pydantic, a Python library for data validation, to define the structure of the desired output. For instance, you can define a model with attributes like `name`, `capital`, and `languages` for a country.

```python from pydantic import BaseModelclass Country(BaseModel): name: str capital: str languages: list[str] ```

**2\. Pass the Schema as a Format** :
The defined schema is passed to the `**chat**` function using the `format` parameter. The schema ensures that the AI generates a response adhering to the expected structure.

```python from ollama import chatresponse = chat( messages=[ { 'role': 'user', 'content': 'Tell me about Canada.', } ], model='llama3.1', format=Country.model_json_schema(),) ```

**3\. Validate the Response** :
The response from the AI is validated against the schema using `Pydantic`. If the response conforms to the schema, it is parsed into a Python object for further use.

``` country = Country.model_validate_json(response.message.content)print(country) ``` ![Image by Author](https://miro.medium.com/v2/resize:fit:700/1*VuMKn61GqUdXRbI1i5gkmg.png)

### Structured Output In JavaScript with Ollama:

```python import ollama from 'ollama';import { z } from 'zod';import { zodToJsonSchema } from 'zod-to-json-schema';// Define the schemaconst Country = z.object({ name: z.string(), capital: z.string(), languages: z.array(z.string()),});// Call the model and pass the schemaconst response = await ollama.chat({ model: 'llama3.1', messages: [{ role: 'user', content: 'Tell me about Canada.' }], format: zodToJsonSchema(Country), // Serialize schema to JSON});// Validate and parse the structured outputconst country = Country.parse(JSON.parse(response.message.content));console.log(country); ```

1. **Schema Definition** : Use **Zod** to define the expected structure of the output.
2. **Serialization** : Convert the Zod schema to JSON using `zodToJsonSchema()`.
3. **Validation** : Parse and validate the AI response with Zod’s `parse()` method.

This ensures the output conforms to the defined structure, making it predictable and usable.

### What Makes This Powerful?

* **Consistency** : The schema ensures that the AI output is predictable and machine-readable.
* **Validation** : Any deviation from the defined structure is flagged, reducing errors in downstream processes.
* **Flexibility** : Developers can define schemas for various use cases, from simple data structures to complex nested outputs.

By integrating schema-based validation directly into the generation process, Ollama minimizes the effort needed for data cleaning and ensures reliable results tailored to your application’s needs.
