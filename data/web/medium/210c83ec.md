In this blog, I will discuss using all kinds of Flux LoRA with Diffusers package in Python.

### 1\. Load Flux LoRA is not as simple as you think

When writing this blog (Sept 12, 2024), there are at least three types of Flux LoRAs. We can detect the LoRA type using the following Python code:

```python from safetensors.torch import load_filelora_path = "/path/to/flux_realism_lora.safetensors"original_dict = load_file(lora_path)print(original_dict.keys()) ```

1. Diffusers format, keys start with `transformer`.
2. xlabs format, keys start with `diffusion_model.double_blocks` or `double_blocks`
3. kohya format, keys start with `lora_unet`

Originally, Diffusers supported only LoRA with keys starting with `transformer`. Until most recently, in this [[LoRA] support kohya and xlabs loras for flux ](<https://github.com/huggingface/diffusers/pull/9295>), Diffusers start supporting both kohya and xlabs Flux LoRAs.

### 2\. Upgrade Diffusers

To use all three kinds of LoRA, you will need to upgrade diffusers to the newest version.

```python pip install -U diffusers ```

To double check your installation, make sure two new functions `_convert_kohya_flux_lora_to_diffusers `and `_convert_xlabs_flux_lora_to_diffusers `are included in code file `src/diffusers/loarders/lora_conversion_utils.py`

These functions will be used to help convert LoRA formats to Diffusers format (start with `transformers`) automatically.

To use unlimited prompt install `sd_embed `(optional)

```python pip install git+https://github.com/xhinker/sd_embed.git@main ```

### 3\. Load up Flux LoRAs

Take this [FLUX — GOLD ART FACE — MDNGUYEN](<https://civitai.com/models/714260/flux-gold-art-face-mdnguyen>) for example.

Load Flux pipeline:

```python from diffusers import DiffusionPipeline, FluxTransformer2DModelfrom torchao.quantization import quantize_, int8_weight_onlyimport torchfrom sd_embed.embedding_funcs import get_weighted_text_embeddings_flux1model_path = "/path/to/black-forest-labs/FLUX.1-dev_main"transformer_model_path = model_pathtransformer = FluxTransformer2DModel.from_pretrained( transformer_model_path # model_path , subfolder = "transformer" , torch_dtype = torch.bfloat16)quantize_(transformer, int8_weight_only())pipe = DiffusionPipeline.from_pretrained( model_path , transformer = transformer , torch_dtype = torch.bfloat16)pipe.enable_model_cpu_offload(gpu_id=0) ```

Load LoRA:

``` lora_path = "/path/to/flux_Golden_art_face.safetensors"pipe.load_lora_weights(lora_path) ```

Generate long weighted embeddings:

``` prompt = '''HanoiGirl, Golden art face, A close-up of a woman's face, with a captivating and intense gaze, framed by dark, flowing hair. Her large, expressive brown eyes are the focal point, reflecting light and depth. Golden flakes and delicate branches intertwine across her face, adding a surreal and artistic touch to the image. The contrast of the dark background with the bright gold elements creates a dramatic, ethereal effect, highlighting the woman's striking features and giving the portrait a dreamlike quality'''prompt_embeds, pooled_prompt_embeds = get_weighted_text_embeddings_flux1( pipe = pipe , prompt = prompt) ```

Generate the result:

```json seed = 10for i in range(seed, seed + 1): print(i) image = pipe( prompt_embeds = prompt_embeds , pooled_prompt_embeds = pooled_prompt_embeds # prompt = prompt # you can also provide the prompt here directly , width = 1680 , height = 1024 , num_inference_steps = 30 , generator = torch.Generator().manual_seed(i) , guidance_scale = 3.5 , joint_attention_kwargs = {"scale": 1.0} ).images[0] display(image) ```
