## The Promise of 1-bit LLMs

Traditional LLMs use 16-bit floating-point numbers (FP16) to store their parameters, which requires significant memory and computational resources. BitNet b1.58 takes a radical approach: it reduces each parameter to just three possible values: -1, 0, or 1. This simple change leads to remarkable improvements in efficiency and resulting to highly efficient operations while maintaining model accuracy.

* **4.1x faster** inference for 70B parameter models
* Up to **7.16x less memory** consumption
* **71.4x less energy** consumption for matrix multiplication
* **8.9x higher throughput** with larger batch sizes

The best part? These efficiency gains come with almost no compromise in performance. Starting from 3B parameters, BitNet b1.58 matches or exceeds the accuracy of traditional LLMs across various benchmarks.

## Breaking Down Quantization in BitNet b1.58

The quantization process in BitNet b1.58 is designed to reduce model weights to ternary values −1,0,1 thus achieving significant computational and memory efficiency without greatly sacrificing accuracy. Here’s a simplified explanation of the process:

### 1\. Quantization Function

The quantization function is key to how weights are transformed from full precision to ternary values. It operates in two main steps:

**A. Scaling Weights** : The weight matrix **W** is scaled by its average absolute value, denoted as **γ**. This ensures that all weights are normalized relative to the size of the matrix. The scaling factor **γ** is calculated using the formula:

![image](https://miro.medium.com/v2/resize:fit:700/1*zkDOOlBNX5kqIX4SS-m9zQ.png)

Here, **n** and **m** are the dimensions of the weight matrix, and the sum of the absolute values of all weights gives a scaling factor that represents the average magnitude of the weights. This scaling makes the weight values more uniform and easier to quantize.

**B. Rounding and Clipping** : After scaling, each weight is rounded to the nearest integer value from the set {-1, 0, 1}. This operation is performed using a function called `RoundClip`, which ensures that the resulting value is bounded within this ternary set:

![image](https://miro.medium.com/v2/resize:fit:700/1*vJ24v5bajHotqABnD54sAg.png)

Here, **ϵ** is a small value added for numerical stability. The `RoundClip` function rounds the scaled weights to the nearest integer and then ensures that the value lies between -1 and 1:

![image](https://miro.medium.com/v2/resize:fit:700/1*iNtdoBHxJnQlG08BiAyeaQ.png)

### Example of the Quantization Process:

Imagine we have a weight matrix:

![image](https://miro.medium.com/v2/resize:fit:700/1*S24CKeevSvpvu8-r4fABmQ.png)

**First, we compute the scaling factor (γ):**

![scaling factor formula](https://miro.medium.com/v2/resize:fit:700/1*HbgjidhhQELq3ZfJig9gaw.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*d6cmoFAFqwTVAt9WhYFrpw.png)

**Note:** The absolute value (written as |x|) represents the distance of a number from zero on a number line, regardless of whether the number is positive or negative. Think of it as measuring “how far” a number is from zero.

For example, with |-0.7|:

* -0.7 is 0.7 units to the left of zero on a number line
* The absolute value gives us just the distance: 0.7 units and so:
* |-0.7| = 0.7 (negative becomes positive)
* |0.5| = 0.5 (positive stays positive)
* |0.1| = 0.1 (positive stays positive)

And hence:

**γ** = ¼(0.3 + 0.7 + 0.5 + 0.1)

= 0.4

### Secondly: We Scale the Weight Matrix by γ:

Now, we scale each element of the weight matrix **W** by dividing it by **γ**. This normalizes the weights.

![Rounding and Clipping formula](https://miro.medium.com/v2/resize:fit:700/1*Ws6m6XzxTUWSQXdpe0pH2A.png) ![we replace γ with 0.4](https://miro.medium.com/v2/resize:fit:700/1*PCx_g018Q5RrpLVNsL3cdw.png) ![Divide each matrix weight with 0.4](https://miro.medium.com/v2/resize:fit:700/1*ExauDsuOnHToVRidiL9Wzg.png)

So the scaled weight matrix is:

![image](https://miro.medium.com/v2/resize:fit:700/1*V-JXvbGwkai6wy7Cr5Lpaw.png)

### **Thirdly: We** Apply the `RoundClip` Function:

Now we apply the `RoundClip` function to each element of the scaled matrix. The `RoundClip` function works as follows:

**RoundClip(x,a,b)=max(a,min(b,round(x)))**

* First, **round** the value to the nearest integer.
* Then **clip** the result between −1 and 1.

Let’s go element by element:

* For **0.75** , rounding gives 1. Since 1 is within the range [−1,1], we leave it as is. Thus, RoundClip(0.75,−1,1)=1.
* For **−1.75** , rounding gives −2. Since −2 is outside the range [−1,1], we clip it to −1. Thus, RoundClip(−1.75,−1,1)=−1.
* For **1.25** , rounding gives 1. Since 1 is within the range [−1,1], we leave it as is. Thus, RoundClip(1.25,−1,1)=1.
* For 0.25, rounding gives 0. Since 0 is within the range [−1,1], we leave it as is. Thus, RoundClip(0.25,−1,1)=0.

* We scaled the original weight matrix by its average absolute value (γ).
