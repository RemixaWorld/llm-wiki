## Introduction

Classification and Regression Trees (CART) emerge as a pivotal algorithm in the landscape of machine learning, navigating both classification and regression tasks.
Well-known for its elegance, interpretability, and remarkable accuracy, CART has cemented its popularity as an algorithm of choice.
This sophisticated decision tree approach holds the key to complex datasets, offering a mix of simplicity and precision that sets it apart in the realm of predictive modeling.
In this article, we delve into the inner workings of CART, unraveling its recursive journey of data partitioning, impurity minimization, and predictive power.

## How CART works

CART works by recursively splitting the data into smaller and smaller subsets based on the values of the input features. The split is chosen to minimize the impurity of the subsets, which is measured using the Gini index.

The Gini index is a measure of how heterogeneous a subset of data is, or in simpler terms, how sure the algorithm is about its predictions. It is calculated as follows:

where:

* S is the subset of data
* p(i) is the proportion of data points in S that belong to class i

The Gini index is zero for a perfectly pure subset, where all data points belong to the same class. It’s highest for a perfectly impure subset, where all data points are equally distributed among the different classes.
For example, imagine a binary prediction task, with labels 0 and 1, the Gini Index will be 1 when the prediction is 0.5, and 0 when the prediction is 0 or 1.

CART recursively splits the data until a stopping criterion is met. The stopping criterion can be based on the purity of the subsets, the size of the subsets, or the depth of the tree.

Once the tree is built, it can be used to make predictions on new data points. To make a prediction, the new data point is passed down the tree, starting at the root node. At each node, the value of the input feature at that node is compared to the splitting threshold. If the value is greater than or equal to the splitting threshold, the new data point is passed down to the left child node. Otherwise, the new data point is passed down to the right child node.

The process continues until the new data point reaches a leaf node. The leaf node contains the predicted class label or regression value.

## Assumptions of CART

CART makes the following assumptions:

* The data is independent and identically distributed (i.i.d.). This means that each data point is sampled independently from the same distribution.
* The features are all independent of each other. This means that the value of one feature does not depend on the values of the other features.
* The target variable is categorical for classification tasks and continuous for regression tasks.

CART is relatively robust to violations of these assumptions, but its performance may be degraded if the assumptions are violated severely.

Here are some additional assumptions that are often made when using CART:

* The data is balanced. This means that the number of data points in each class is roughly equal.
* The data is scaled. This means that the features are all on the same scale.
* The data is free of outliers. Outliers can cause CART to learn incorrect splits and make incorrect predictions.

It is important to note that these assumptions are not required for CART to work, but they can help to improve the performance of the model.

## Benefits of CART

* **Simplicity** : CART is a relatively simple algorithm to understand and implement. It can be implemented in a few lines of code in most programming languages.
* **Interpretability** : CART trees are easy to interpret, as they can be visualized as a series of if-then statements. This makes it easy to understand why the model makes the predictions that it does.
* **Accuracy** : CART trees can achieve high accuracy on a variety of classification and regression tasks. This is because CART trees are able to learn complex relationships between the input features and the target variable.
* **Robustness** : CART trees are relatively robust to noise and outliers in the data. This is because CART trees split the data into smaller and smaller subsets, which helps to isolate the effects of noise and outliers.
* **Versatility** : CART trees can be used for both classification and regression tasks. This makes them a versatile tool for a variety of machine-learning problems.

## Pitfalls of CART

* **Overfitting** : CART trees are prone to overfitting, which means that they can learn the training data too well and fail to generalize to new data. To prevent overfitting, it is important to use a cross-validation technique and to tune the hyperparameters of the model.
* **Computational complexity** : Training CART trees can be computationally expensive, especially for large datasets. This is because CART trees recursively split the data into smaller and smaller subsets.
* **Sensitivity to outliers** : CART trees can be sensitive to outliers in the data. Outliers can cause CART trees to learn incorrect splits and make incorrect predictions. To mitigate this, you can remove outliers from the data or use a robust CART variant.

Overall, CART is a powerful and versatile machine learning algorithm that can be used for a wide variety of tasks. It is a good choice for both beginners and experienced machine learning practitioners. However, it is important to be aware of the pitfalls of CART, such as overfitting, computational complexity, and sensitivity to outliers.

## Tips for using CART

Here are some tips for using CART:

* Use a cross-validation technique. A cross-validation technique can help to evaluate the performance of the CART model on unseen data. A good cross-validation technique to use is 5-fold cross-validation.
* Tune the hyperparameters. The CART hyperparameters include the minimum node size and the minimum leaf size. These hyperparameters can be tuned using a grid search or a random search.
* Use a pruning technique. A pruning technique can help to prevent overfitting. A good pruning technique to use is reduced error pruning.

## Implementation From Scratch in Python

Here is a simple implementation of CART in Python:

```python class CART: def __init__(self, min_node_size=1, min_leaf_size=1): self.min_node_size = min_node_size self.min_leaf_size = min_leaf_size def fit(self, X, y): # Calculate the Gini index of the root node. gini = self.gini_index(y) # Build the CART tree recursively. self.tree = self._build_tree(X, y, gini) def predict(self, X): # Make predictions for the new data points. predictions = [] for x in X: prediction = self.predict_one(x) predictions.append(prediction) return predictions def gini_index(self, y): # Calculate the Gini index of the given dataset. # Count the number of data points in each class. class_counts = np.bincount(y) # Calculate the proportion of data points in each class. class_proportions = class_counts / len(y) # Calculate the Gini index. gini = 1 - np.sum(class_proportions**2) return gini def _find_best_split(self, X, y): # Initialize the best split. best_split = None best_gini = 1 # Iterate over all features. for i in range(X.shape[1]): # Iterate over all possible splits. for split in self._find_splits(X[:, i]): # Split the data. left_X, left_y = X[split[0]], y[split[0]] right_X, right_y = X[~split[0]], y[~split[0]] # Calculate the Gini index of the split. gini = self.gini_index(left_y) * len(left_y) / len(y) + self.gini_index(right_y) * len(right_y) / len(y) # Update the best split if necessary. if gini < best_gini: best_split = (i, split[1], split[0]) best_gini = gini return best_split def _build_tree(self, X, y, gini): # If the node is pure, then return a leaf node. if gini == 0 or len(X) < self.min_node_size: return CARTLeaf(y) # Find the best split to minimize the Gini index. best_split = self._find_best_split(X, y) # Split the data into left and right child nodes. left_X, left_y = X[best_split[2]], y[best_split[2]] right_X, right_y = X[~best_split[2]], y[~best_split[2]] # Build the left and right child nodes recursively. left_child = self._build_tree(left_X, left_y, self.gini_index(left_y)) right_child = self._build_tree(right_X, right_y, self.gini_index(right_y)) # Return a CARTNode with the best split and the left and right child nodes. return CARTNode(best_split, left_child, right_child) def _find_splits(self, x): # Find all possible splits for the given feature. # Sort the feature values. sorted_x = np.sort(x) # Find the midpoints between adjacent feature values. midpoints = (sorted_x[1:] + sorted_x[:-1]) / 2 # Iterate over all midpoints. for midpoint in midpoints: # Find the indices of the data points to the left and right of the midpoint. left = x < midpoint right = x >= midpoint # Yield the indices of the data points to the left and right of the midpoint. yield (left, midpoint, right) def predict_one(self, x): # Traverse the CART tree to make a prediction for the given data point. node = self.tree while not isinstance(node, CARTLeaf): split = node.split if x[split[0]] < split[1]: # Change this line node = node.left else: node = node.right return node.prediction class CARTNode: def __init__(self, split, left, right): self.split = split self.left = left self.right = right class CARTLeaf: def __init__(self, y): self.prediction = np.argmax(np.bincount(y)) ```

Let’s break out the code into several steps:

`fit` method: Takes training data `X` and corresponding labels `y` to build the CART tree. It calculates the Gini index of the root node and then recursively builds the tree using the `_build_tree` method.

`predict` method: Takes new data points `X` and predicts their labels using the trained CART tree. It iterates through each data point, calling the `predict_one` method for each.

`gini_index` method: Calculates the Gini index for a given dataset. It uses the Gini index formula, which measures the impurity of the data.

`_find_best_split` method: Finds the best split for a given dataset by iterating over features and possible splits. It calculates the Gini index for each split and selects the one that minimizes the overall impurity.

`_build_tree` method: Recursively builds the CART tree. It checks for purity and node size conditions and splits the data based on the best split found by `_find_best_split`.

`_find_splits` method: Finds possible splits for a given feature by iterating over midpoints between adjacent feature values.

`predict_one` method: Traverses the trained CART tree for a single data point to make a prediction. It follows the splits until it reaches a leaf node, which contains the predicted label.
