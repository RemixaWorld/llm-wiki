Let’s Get started.

Step 01: Now Place your GGUF Models in Text generation UI Model folder as shown in screenshot below.

![image](https://miro.medium.com/v2/resize:fit:700/1*02YHAZqpaX5QdIbc2c9iJQ.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*jV0JZ2jppWRPETllSoqVAA.png)

Step 2: Now get into Text generation UI and run below command for Linux or /Mac, system will download relevant dependencies and provide WebUI on <http://localhost:7860> along with OpenAI-compatible API URL:

<http://127.0.0.1:5000>

``` ./start_linux.sh --api./start_macos. sh --api ``` ![image](https://miro.medium.com/v2/resize:fit:700/1*LUCxoUDiRwCZQvuhVfLAGQ.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*k2XEkyL00XU9sfYPYcPNbQ.png)

Step 03: Now go to localhost:7860 and click on models as shown in below screenshot.

![image](https://miro.medium.com/v2/resize:fit:700/1*sekABXuCJvJKUWpJ5-yNdw.png)

Step 04: Now Choose GGUF Models from the list as shown in below screenshots (Kindly note that not all GGUF Models will work, I will update list that will work without any issues).

![image](https://miro.medium.com/v2/resize:fit:700/1*utRpunve2gGN9w75EG8tbA.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*stHimjKJuAA0loKc4srdmQ.png)

Step 05: Once the Model is Downloaded, Choose the Model from Dropdown and Click on Load as shown in Below screenshot.

![image](https://miro.medium.com/v2/resize:fit:700/1*sTmZEfg_i7r7_gn-mouGqQ.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*Acn2MDOBLbgWAII7UsqE4Q.png)

Step 06: Now before testing GGUF models in Librewriter, You can click on Notebook to test the GGUF Models Response by clicking on Notebook and asking your question and click on generate button as shown in below screenshot.

![image](https://miro.medium.com/v2/resize:fit:700/1*YaWw9pEpqWx2DF05irvCmA.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*xMh2at4FVcfzGaXyLEsknQ.png)

Step 07: Now ask your question from GGUF Models as shown in screenshot below.

![image](https://miro.medium.com/v2/resize:fit:700/1*NuIiiwGYZftN1WhB2gZbdA.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*7DLscx8_GWSs1EsR6xBQJw.png)

Step 08: Expect Answer like this.

![image](https://miro.medium.com/v2/resize:fit:700/1*qdUxOjQoQzW257Um9C-FZA.png) ![image](https://miro.medium.com/v2/resize:fit:700/1*jtonkEzSobjl0yIu6F-Bew.png)

Here are quick youtube Video for Visual reference.

Step 9: Now to integrate AI writing in multiple languages, run Qwen2.5 or Aya LLM with Ollama and Along with host “localhost:11434” also provide Aya or Qwen2.5 models in localwriter setting and start asking questions.
