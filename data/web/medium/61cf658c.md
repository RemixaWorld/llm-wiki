## The Method

Let’s start by defining some basic variables.

* **All the hidden states of the LLM** are defined as **_h(t,j)_** where _t_ is the token position and _j_ is the layer position. Every token and layer position has a hidden state whose dimension is, say, (4096 x 1).
* **The input token at the time position _t_** is denoted by **_x(t)_**_._
* **The unembedding function** which converts a hidden state into a set of logits is denoted by **𝜙**.

### The Contrasting Layers Strategy

What we stated in Part I was that somehow, contrasting the two layers’ outputs could help bring out the truth. How exactly do we contrast these layers?

Our first job is to pick a specific internal layer that we want to contrast with the last layer.

### Layer Selection

We pick out the best internal layer that **contrasts the most** with the output layer. But how do we quantify how much a specific layer contrasts with the output layer?

We use the [Jensen-Shannon Divergence (JSD)](<https://en.wikipedia.org/wiki/Jensen%E2%80%93Shannon_divergence>) to quantify this. I won’t go over the nitty-gritty, but here’s a formalisation of the process of choosing the best layer M.

### Contrastive Decoding and Filtering function

Press enter or click to view image in full size

The function is defined by taking the logarithm of the ratio of the output from the Nth layer to the output from the Mth layer. So for a token like Seattle, if the outputs are approximately the same, then the ratio becomes 1 and the logarithm is 0. If the Nth layer output has a much higher probability than the Mth layer, then the logarithm is a positive number. If the Nth layer output is lower than the Mth layer, then the logarithm is negative.

There’s an added condition: the token itself needs to belong to “Vhead”.

This means that the token should be significantly high probability to begin with. This idea is called a **“filtering function”** , since we first filter out low probability tokens, and then apply the contrastive function. The idea is that if a token contrasts hugely (let’s say gets multiplied by 10), but that contrast is between a probability of qM = 0.00001 to a probability qN = 0.0001, then we don’t want that token’s probability to shoot up.

The filtering function’s purpose is to ensure that we are only considering tokens whose probabilities were high enough to begin with, and only if they are, we may go about boosting them here and there based on the contrast to determine the final output token.

## Conclusion (Summary)

And that’s it! In summary, we first mathematically defined how the “early exit” and last layer predictions were denoted. Next, we looked at the Jenson-Shannen Divergence and how it was used to find the optimal internal layer to contrast with. Finally, we showed how the filtering function can be used to exclude tokens that had a low probability to begin with, and contrast the predictions from the intermediate layer and the last layer to get the final output distribution.
