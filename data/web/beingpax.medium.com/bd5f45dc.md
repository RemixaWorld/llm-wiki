# Fabric: The Best AI Tool That Nobody is Talking About

## An open-source AI tool to automate every day tasks

Fabric is an open-source framework for augmenting humans using AI. That’s what they write in the GitHub README.

When I first went thought the README, I was confused. I had no idea how this would be useful. I didn’t know what this tool was trying to do.

Augment humans? Open-source AI? Patterns? All of this in terminal?

Despite the confusion, I marched ahead. I installed the tool and started using it.

10 minutes into the tool, and I was blown away by its capabilities.

TBH, fabric is not doing anything new. It’s not reinventing the wheel.

It works on the top of already existing LLM models. But the ease of integration is just out of the world.

In this article, we’ll talk everything about fabric. What it is, how do you set it up, and how you can leverage this tool in your daily life.
