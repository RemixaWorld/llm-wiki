## 0. 現有 LLM 困境

我們先從 Qwen3-Next 的 Blog 中開始，Qwen 官方團隊提到 “*Qwen3-Next is optimized for extreme context length and large-scale parameter efficiency*”

我想 extreme context length 跟 parameter efficiency 這兩點的重要性應該到 2025 大家都很好理解了，不過筆者還是快速提一下。

🔥**extreme context length 可以帶來更多的應用場景，並簡化 LLM 相關的技術架構**。像是當初在 2023 時，主要的 LLM 都是 4k context window，光是做一個文本摘要（document summarization）就要對 document 做 chunking 然後每一個 chunk 分別 summarize，最後再總結。不過到現在，LLM 動輒 128k context length，summarization 這種任務我想大家幾乎都是 1 次 LLM call 就解決。

而 parameter efficiency 則會大幅度影響我們的 LLM 效率，在筆者的 <詳解 LLM inference efficiency> 文章中就有提到，我們 forward 的運算量會跟 activate 參數量有關，而 decoding 的 Memory IO 也跟 activate 參數量有關，因此只要能夠提升 parameter efficiency，就可以得到更低的 prefilling latency（TTFT, time to first token）跟更低的 decoding latency（TBT, Time bewteen tokens）

.

在過去研究上，extreme context length 主要需要解決的問題有 3 個：

- Positional embedding 如何建構出有用的 long context relationship
- 如何有效訓練 long context LLM
- inference KV cache size 如何盡量小（不然即便有超大 context length 也用不了）

這三個問題都很大 XD，細講的話可能是一個兩小時的文章，筆者不希望本文失焦，因此我們就淺談這三個問題就好 XD

1️⃣ Positional embedding 在 long context 上最大的問題是 extrapolation 問題，也就是當模型遇到沒有訓練過的長度，就會壞掉。

因此對於 Positional Embedding 而言，一個最直接的做法就是訓練你想要的長度。

當我們目標的 context length 還是 4k, 8k 的時候，我們確實大可就把 8k 的 context window 訓練好，pretraining 的過程中大量用 8k 的長度來訓練，無傷大雅。

但當我們 context length 要到 128k 甚至到 Gemini 那種 1M, 2M 的時候，我們馬上就會遇到兩個問題：

**訓練效率極低**：因為 self attention 的特性，我們需要 quadratic complexity O(N^2) 來訓練長度 N，當我們單次訓練長度到 128k 時，訓練成本會遠大於單次訓練長度 4k 的，即便總共訓練 token 數量相同。**long context 資料極度稀缺**：在網路雖然長文本很常見，但真的需要 long dependency 的不多，也就是說大部分長文本其實用 short context 解讀即可，訓練不到 long context 能力。

因此為了節省訓練效率，並且加強模型 long context 能力，我們就會希望找到某種方法可以讓 LLM 訓練在 short context 但可以正確運用在 long context，而這種能力我們稱為 **length extrapolation**。

而當下最主流的做法就是 YaRN [1]（DeepSeek, Qwen 系列都有使用），藉由分段調整 RoPE 的旋轉角度，讓近距離的 Positional embedding 還是有高精度，但遠距離的 Positional Embedding 被調整回訓練區間，藉此加強 length extrapolation 的能力。

.

2️⃣ 不過習慣上我們還是會在 YaRN 之上，再做一定程度的 **long context training**，讓模型可以有機會藉由學習，調整自己 length extrapolation 的能力。所以我們回頭過來還是要**解 long context training 的效率問題。**

每次看到 Transformer quadratic complexity 被吐槽時，我們想到的第一個方法肯定是 **sparse attention**，藉由減少 self-attention 的 attend 對象來解決 Quadratic complexity。（最好變成固定數量，跟 context length N 無關，複雜度就可以從二次降為一次）。

而在 Training 這塊也是一樣，年初 DeepSeek 跟 Kimi 分別提出了 Native Sparse Attention [2] 跟 Mixture of Block Attention [3] 同時都對 LLM long context training 採取了 sparse attention 的策略。

並且都發現在 long context training 上，加入 sparse attention 其實是有機會做到很接近 lossless 的 training 效果。

.

3️⃣ 最後到 i**nference KV cache 的問題**，在當下主流方法就是我們在 <GPT-OSS 過度解讀 part1: sliding window> 講的 **Hybrid Window Full Attention**。

其實就是把 sparse attention 加到 inference time，目前主流是每 N 層裡面只有 1 層 full attention（N 通常 = 4），然後其他層用 **sliding window attention**，sliding window attention 只 attention 在最近的 context（主流是 4k），跟總長度 N 無關，因此也能大幅度減少 KV cache。

不只 GPT-OSS，我們在 LLaMA4, Gemma3 都看的到 Hybrid Window Full Attention 的設計。

當然另外也有兩種比較常見的技巧減少 KV cache size，像是 GQA, MQA 在不變 attention head 的前提下減少 KV head，以及 KV cache quantization 直接減少 bits per KV。

綜上所述，**當下的 context length 其實大部分問題都有對應的解法，我們目前大概可以在 16k 32k 的長度幾乎無痛（效果好、速度快）**，而到 64k 以上則大多會開始出現一定程度的 latency，以及 long context 能力在較複雜的任務上可能會出問題。

.

而 Parameter efficiency 的主要解法就更直接了，主要應該包含以下四種：

**Overtrain 小模型**，讓小模型的能力可以堪比大一個量級的模型**Distill**大模型的關鍵能力到小模型上**Mixture of expert**，每一次只 activate 有限的 parameter，減少單個 requests 的參數量。**Quantization**，讓模型的 bits per parameters 降低

碰巧這裡每一個觀念筆者過去的文章都有介紹過 XD，有興趣的朋友可以回去翻翻，特別推薦最近撰寫的 <GPT-OSS 過度解讀 part2: MXFP4> ⭐

不過簡單來談，前兩個做法在過去兩年最主流，但不論是 overtrain 還是 distill 都是針對小模型，我們很常看到 7b 8b 模型被 overtrain，但幾乎看不到 600B 模型 overtrain。以 DeepSeekV3 為例，671B 模型訓練 14.8T tokens，其實很接近 chinchilla scaling law。（當然 MoE 不太能這麼簡單換算）

因此對於大模型而言，更多是考慮 MoE 或是 Quantization 相關的方法來增加 parameter efficiecny，而 GPT-OSS 做的方法是 Quantization 到極致，Qwen3-Next 則是挑戰超級 Sparse MoE 模型。

.

好！到目前為止我們快速複習完當下的 LLM architecture Landscape，接下來我們就要來解讀 Qwen3-Next 的 *"extreme context length and large-scale parameter efficiency" *具體是在說什麼，並且重點關注以下三個技術：

- Hybrid Gated DeltaNet
- Gated Attention
- High-Sparsity MoE

## 1. Hybrid Gated DeltaNet：大幅提升運算效率、大幅減低 KV cache

不同於其他模型做 Hybrid Window Full attention，Qwen3-Next 採取的是 Hybrid **Gated Deltanet 及 Gated Attention**，gated attention 算是一種 softmax attention 的一種變形，我們下一個章節會簡單講解，**這一部分我們先重點說明讓 Qwen3-Next 的 training, inference efficincy 都大幅提高的主要幫手**，也就是 **Gated DeltaNet**。

**Gated DeltaNet 是 Linear Attention 的一種，或是更簡單來說，他是一種 Recurrent Neural Network。**（夢回 2017 XD）

對於 DeltaNet 以及 Linear Attention 相關知識，Gated DeltaNet 的一作 Songlin Yang 有一系列非常精彩的 Blogs [part1][part2][part3]，筆者之前學習 Linear Attention 時也反覆看了數十遍，推薦大家都可以去學習


1️⃣ **Linear Attention 哪裡好？**

我們過去一直提到 LLM 的 quadratic complexity，根本原因是因為 softmax self-attention 需要 attend 過去所有的 tokens，所以 self attention 本身就是 O(N) 的操作，而 training, prefilling 或是 autoregressive decoding 都要處理 N 個 tokens，因此總共就變成 O(N^2) 的複雜度。

前面我們解決 LLM quadratic complexity 的方法是藉由 sparse attention，減少 self-attention 的對象，來減少複雜度。

而 Linear Attention 則採取另一個角度，藉由 linear operation 的特性，降低運算複雜度，我們接下來來仔細看看這個邏輯。

我們傳統 softmax self attention，形式如下

而 Linear Attention，顧名思義，就是把 softmax operation 從 softmax attention 中拔掉，轉乘 linear operation，也就是以下這個形式。

到這裡我們乍看之下跟原本 softmax attention 差別不大，那 Linear attention transformer 是怎麼樣變成總共 O(N) 的 operation 呢？

主要原因就是因為當我們把 softmax 從 softmax attention 中拔掉，我們整個形式就變成 linear operation，**而 linear operation 有非常多很好的性質，其中一個最基本的就是「結合律」**，也就是說當我們 decode 第 t 個 tokens 時，公式可以如下推導。

到這裡就有意思了，我們把以往 softmax attention 需要先計算 q, k 內積的運算，透過結合律，轉換成先計算 v k 外積（outer product），並得到一個 S，紀錄過去 1~t 的所有重要資訊。

而我們就可以發現 **S_t 跟 S_t-1 其實就是一個基本的 recurrent form，其中就只差 v_t 跟 k_t 的 outer product。**🔥🔥

也就是說我們不用像 softmax attention 每一步 attention 都計算 q 跟所有 history k 的內積，我們只需要每一步維護 S，每一輪只需要做兩個計算。

**因此我們就可以說 linear attention 本身是一個 O(1) 的運算，進而讓整個 linear attention transformer 變成 O(N) 的運算。**🔥🔥🔥

而這其實就是 Recurrent Neural Network 的 forward 方式。（只是一般 RNN 是用一個 1*d 的 hidden vector 來記錄歷史，Linear Attention Transformer 則是用 d*d 的 Matrix S 來記錄歷史）

.

除了運算上變更高效以外，另一個重點就是 linear attention 的在 inference 時，就只需要 cache 住 S，而不需要存所有的 KV，而 S 本身是 d*d 的維度，跟 sequence length N 無關。

**因此 linear attention 也會大幅度減少 KV cache 的用量，如果都用 bf16 來存的話，可以從從 4*N*d 降低成 2*d*d。**🔥🔥

.

敏感的朋友應該馬上就看出來了，所以 Linear attention 的適用場景主要應該是兩者：**Long Context 跟大 Batchsize**。

**只有 context 夠長，N 才會遠大於 d**，**同時只有 Batchsize 夠大，KV cache 才會在 inference 變成 dominate term**，不過具體要多長的 context 以及多大的 Batchsize，則賣個關子 XD，推薦大家可以用我過去在 <詳解 LLM inference efficiency> 中的公式試算一下。

**同時只有 N 夠大，attention 的運算量才會主宰整體 transformer 的 forward pass**，因此以運算量的角度而言，也要一定 context 以上，Linear attention 才會出現效果。

.

2️⃣ **Linear Attention 哪裡不好？**

如果 Linear Attention 無限好，那為什麼過去架構很少見⁉️⁉️

實際情況就是 Linear Attention 在很大一段時間（2020~2022）都是在各種 toy benchmark 上超級強，但到 Language Modeling 或是 NLP 任務上超級爛 XD

其中有幾個猜測與做法，未來我們可以深入介紹，這邊我們為了讓大家理解 DeltaNet，就快速講一個比較直觀的觀點。

**原本的 Linear Attention update rule 對所有 tokens 一視同仁，但我們在 softmax attention 的經驗告訴我們，tokens 並不是平等重要。**

舉例而言，越近的 tokens 通常越重要，越遠的越不重要。因此 softmax attention 上像是 RoPE 之類的 Positional Embedding 都會帶有遠程衰減的屬性。

基於這個觀點，在初始的 Linear Attention 之上，**研究員們開始在 S 之上加各式各樣的 decay**，像是最基本的就是加一個 data independent decay （如下圖），而這個 decay term 會讓歷史資訊以 exponential 的速度消失，最典型就是 RetNet [4]。

另外我們也可以加 data dependent decay（input dependent decay），讓歷史資訊 decay 的大小依據當下 token t 決定（如下圖），而最典型就是 Mamba2 [5] 跟 xLSTM [6] 中的 mLSTM。

實際上我們可以讓這個 decay term 無限複雜下去，像是變成一個 matrix 提供更 fine-grained 的 decay，就有 GLA [7], RWKV6 [8]。

實際上 DeltaNet [9] 的思想跟最近一年很紅的 Test time train, Test time regression 完全相同，也就是所謂 fast weight programming，這個我們之後會開一篇重點介紹。（坑越來越多 ...）

.

3️⃣ **Combine Best of Both Worlds: DeltaNet + Mamba2 = Gated DeltaNet**

**Gated DeltaNet [11] 其實就是結合 data dependent decay (gating) 跟 DeltaNet。**

我們已知 DeltaNet 的核心公式是以下三條，提供給模型主動刪除歷史資訊的操作 (c)，並且提供調整新資訊參考量的 gate (b)。

而 Gated DeltaNet [11] 就是在之上，在針對 S_t-1 加入 data dependent decay，也就是 Mamba2 [5] 的技巧，讓歷史資訊可以 input dependent 衰減。

我們把 data dependent decay 加回去前面 DeltaNet 的 (a)(b)(c) 公式，其實就得到了 Gated DeltaNet [11]。

只要將這個公式重新整理一下，就可以得到 Gated DeltaNet [11] 論文中的對應的公式。

**因此 Gated DeltaNet 的論文才稱為 Improving Mamba2 with Delta Rule，因為本質上 Gated DeltaNet 就是在 DeltaNet 上加入 Mamba2 的 gating。**

實際上 Gated DeltaNet [11] 的論文中用比較嚴謹的方式從 fast weight programming 的角度說明為什麼 gated + delta rule 很好，但這個概念較複雜，未來筆者會直接獨立一篇來解讀，這邊大家可以把 Gated DeltaNet 當成 combine best of both worlds 的產物。

.

而 Gated DeltaNet 的論文中也提到我們大可把 Gated DeltaNet 跟一般的 sliding window attention 結合起來，得到 hybrid softmax attention / linear attention 的 network，論文中額外做了兩種變

- Gated DeltaNet-H1 = Gated DeltaNet + sliding window attention (SWA)
- Gated DeltaNet-H2 = Gated DeltaNet + sliding window attention (SWA) + Mamba2

而直接的結果就是在 Recurrent Model 上 Gated DeltaNet 具備極強的優越性，而與 Sliding Window Attention 結合後也可以穩定打贏 Transformer 以及其他架構。（如下表）

去年更是有 Microsoft 的 Samba [14], Nivida 的 Hymba [15] 以及今年的 Falcon-H1 [16] 這種 hybrid SSM / softmax attention 的模型，可以說 hybrid 某種 efficient attention architecture 已經越來越證明其價值與有效性。

而當下的 SOTA 可能是 Gated DeltaNet，所以更多架構選擇把 Gated DeltaNet 加入 Hybrid architecture，而針對 Gated DeltaNet 對應的 training/finetuning/inference 相關 tricks 就需要我們未來更多關注。

.

段落總結：Qwen3-Next 在架構中 hybrid 加入了 Gated-DeltaNet 這種 linear attention layer，linear attention layers 在 auto-regressive generation 的時候，因為只需要 O(1) 的時間計算出 S_t 跟對應的 y_t，因此計算量大幅下降，同時也不用存隨著序列長度成長的 KV cache，只需要存固定大小的 S，也大幅降低 cache size，因此在 long context, large batchsize 的場景都能得到顯著的效率提升。

而 Gated DeltaNet 是目前 Linear attention layer 中的熱門所選，結合 Mamba2 的 gating 以及 DeltaNet 的 Delta Rule，可以同時在 NLP 任務上超越 Transformer++，並在 in conext recall 相關任務上超過其他 recurrent models。

## 2. Gated Attention：穩定 attention scores，加強 long context 能力。

前面我們介紹完最大的 efficiency 來源：Linear attention layers，接著我們來討論 Gated Attention。

前面我們在 linear attention 的段落說 gating 有諸多好處，大量的 linear attention model 都加入了某種形式的 gating，一個直接的問題就是 gating 對於 softmax attention 有沒有幫助？

在筆者知識中第一個直接在 attention 中加入顯式的 gating 的，就是 Forgetting Transformer (FoX) [17]，Fox 在 attention 的計算過程，對每一個 position pair（attention map 中每一個值）都計算一個 data dependent gate。

並且 FoX 在超過 training tokens 的距離上表現遠超過一般的 LLaMA Transformer（如下圖），也就是說有顯著更好的 length extrapolation 能力。

而 Gated DeltaNet 的一作 Songlin Yang 跟 Qwen 團隊在年初就發表了一篇論文 <Gated Attention for Large Language Models: Non-linearity, Sparsity, and Attention-Sink-Free> [18]討論 gating 在 softmax attention 之中的角色。

Gated Attention [18] 首先在 attention 幾乎所有可能加入 gating 的地方都加入了 gating，發現在 SDPA 上加入 gating 效果最佳（FoX 也相當於是對 SDPA 加入 gating），得到更低的 test perplexity 以及更好的 test performance，同時 training 還能收斂更快且更穩定（更少 loss spike）。

接著 Gated Attention 對大量的 gating 相關的 hyperparameters 做 tuning，找出最佳的 gated setup，並且驗證 Gated Attention 在各種 transformer hyperparameter 下都有效果，有興趣的朋友可以去看原論文。

.

同時 Gated Attention 的論文提出了 4 種在 attention 上加入 gating 會變好的潛在理由：

1️⃣ **softmax attention 中 W_V 跟 W_O 之間缺乏 non-linearity，兩者其實可以被結合成一個 matrix。加入 non-linearity 可以加強 softmax attention 的表達能力。**

可以發現，其時 W_V 跟 W_O 之間完全都是 linear operation，而在傳統 Deep Learning 裡面教我們，如果你 Deep Network 都只有 linear operation，那不論幾層都可以被壓縮層一層，因為你可以先把這些 weight 全部乘開。

原始的 softmax attention 在這裡就出現了這種情況，**在 W_V 跟 W_O 之間沒有任何 non-linearity，因此兩者其實完全可以 merge 成一個 weight matrix，也就是說我們平白浪費了一個 W 的參數量。**

**因次在 W_V 跟 W_O 之間加入 gating 其實就是加入一種 non-linearity，讓兩組 weight 不會被合併，增強模型表達能力。**

.

2️⃣ **Gating 可以帶來 input dependent sparsity**

Gated Attention 其中的 gating score，大部分都 < 0.5，並且其實都非常靠近零，也就是說 Gated Attention 會在 attention 的基礎上，額外再引入新的

而這也是我們原本對 gating 的預期，藉由 data dependent gating，基於每個 input token，把不重要的資訊丟掉。

這也有可能是另一個 Gated Attention 效果更好的理由。

.

3️⃣ **Gating 可以避免 Attention sink**

Gated Attention 還能額外降低 Attention sink 的情況，相較於 softmax attention，Gated attention 的 first token score 顯著較低。（如下圖，上半是 softmax attention，下半是 Gated Attention）

而 attention sink 是很多糟糕的 attention 性質的元兇，像是 numerical issue 很多時候也是因為 attention sink，避免了 attention sink 對於 training stability 也會有幫助，length extrapolation, sparse attention 也常常跟 attention sink 有關，因為 attention sink 的 value 太大，如果直接移除掉壞導致 transformer 直接壞掉 [19]，因此在過去的方案上普遍都要把 sink tokens 留下來。

不過因為 gpt-oss 使用了在算完 attention score 後直接把 attention sink 丟掉的算法，也就是 <Attention is off by one> [20] 的技巧，目前看起來只要訓練時有跟著做對應的操作，效果也很好，因此 attention sink 的問題不一定要透過 Gated Attention 來解決。

.

4️⃣ **Gating 可以加強 length extrapolation**

在使用 Gated Attention 後，發現經過 YaRN extended，在 training length（32k）以內的 performance drop 顯著較少（相較於原本 softmax attention），而在 training length（32k）以外的，gated attention 的表現也顯著更好。

**因此 Gated Attention 對於 length extrapolation，如 YaRN 相關的方法，不論是在 training length 以內或是以外，都優於傳統 softmax attention。**

.

**段落總結：Gated Attention 在 softmax attention 各種可能可以做 gating 的地方做大量的實驗，找到 gating + attention 的最佳組合，同時效果更好，且訓練也更穩定。並且對 attention sink, length extrapolation 這些 LLM 核心問題也都有改善。**

Qwen3-Next 是第一個應用 Gated Attention 的開源大模型，Gated Attention 到底是不是真的這麼好，接下來可能要半年到一年的時間讓學界業界慢慢驗證。（筆者還是對 Gated Attention 比較樂觀的，不論是 Gated Attention 論文中的理論解釋還是 empirical results 都很 solid，前面還有 FoX 先做鋪墊，很有可能跟 MLA 一樣影響未來 1~2 年 LLM architecture design 的架構）

順帶一提，把 gating 加入 softmax attention 可以得到 gated attention，得到更好的 length extrapolation 能力，那如果把 delta rule 加入 softmax attention 會不會也有用？

答：有用，這就是 PaTH [21] positional encoding，未來會介紹。

## 3. High-Sparsity MoE：

最後我們來淺談一下 Qwen3-Next 說的他們使用 high-sparsity MoE。

Qwen3-Next 使用 50:1 的 sparsity 意思是每一個 token 在 forward 時只為 activate 到 1/50 的 expert。

我們先快速回顧 2023 年，當時的 MoE 模型大多都還是比較 low-sparsity，舉例而言最有名的應該是 Mixtral-8x7b [22]，總共只有 8 個 experts，並且每次 activate 2 個。

也就是說對於 Mixtral 8x7b 而言，Sparsity 是 4:1。

但是到了 2025 年，我們卻發現主流 MoE 模型的 expert sparsity 急劇升高：

- DeepSeek V3 原版使用了 256 個 experts，每次會 activate 9 個 experts（8 個 routed experts + 1 個 share expert），
**Sparsity ~= 28.5 : 1**。 - Qwen/Qwen3–235B-A22B 使用 128 個 experts，每次會 activate 8 個 experts，
**Sparsity = 16:1**。 - GPT-OSS 120B 使用 128 個 experts，每次會 activate 4 個 experts，
**Sparsity = 32:1**。 - Kimi K2 使用了 384 個 experts，每次會 activate 9 個 experts（8 個 routed experts + 1 個 share expert），
**Sparsity = 42.6:1**。

可以發現到 2025 年，MoE Sparsity 動輒就是 20~40 這種數字，跟 2023 年常見的 4:1 相比大了快一個量級。

為什麼到 2025 主流的 MoE 模型 expert sparsity 會變這麼大？就是我們這個章節的主要想要討論的點。

1️⃣ **好處很明顯，Sparsity 越大，Training, inference cost 都越低**

這應該很直覺，同樣總參數的模型，如果 Sparsity 從 4:1 變成 32:1，代表每次 activate 的 MoE parameters 變成 1/8，而 training 跟 inference 的各種成本都跟 activate parameters 比較相關，因此就可以得到大額收益。

在筆者年初分析 DeepSeek V3 的訓練成本合理性的文章中，筆者就曾提到 DeepSeek V3 看起來訓練成本異常低，其中 MoE 是主要的理由，總共 671B 參數的模型，每一次 forward 只會 activate 37B 參數，因此訓練成本其實跟 37B 模型差不多。（前提是 communication 可以 overlap 掉）

因此 High Sparsity 的好處其實滿直覺的，**Sparsity 越高 ==> 相同參數模型 activate 更少參數，因此 training, inference cost 都顯著更低。**

但主要問題是，在相同總參數底下，Sparsity 提高幾乎是一定會導致性能下降，因此我們主要需要考慮的是這點。

.

2️⃣**在同樣 activate parameters 下，增大總 experts 量（同比提高總 parameters 數），可以穩定提升效果**

最經典的證據就是 Switch Transformers，在 Switch Transformers 中，我們永遠都只 activate 1 個 expert，而但我們增大總 experts 數量（同比提高總 parameters 數），可以看到在 Test Loss 上都還是可以持續下降。

並且當我們跟同樣運算量的 Dense model（T5）相比，效果也好一截。因此在同樣 activate experts, parameters 下，總共的 experts, parameters 越多，整體性能越好。

而因為 activate parameters 才主導我們的 training, inference cost，因此我們可以藉由提高 Sparsity 來提升我們 MoE 模型的性能。

在 Kimi K2 的 technical report 中也直接闡明這點，在他們的 scaling law 底下，增加 sparsity 可以提升性能。

.

而都提到了 Scaling Law，實際上也有論文已經給出了 MoE Sparsity 的 scaling law。

.

3️⃣ **模型越大，Sparsity 可以越高**

MoE Sparsity 相關 Scaling law 體現出隨著 model size 變大，我們還可以持續提高我們的 Sparsity，並且在同樣的 compute budget 上可以得到更好的效果。[24]

因此隨著我們的模型越大，繼續提高我們的 MoE Sparsity 在各種邏輯上都是正確的選擇，**而 Qwen3-Next 目前走到了 50:1，未來說不定還會出現 100:1 甚至更高 sparsity 的模型。**

.

… 真的嗎？

前面我們對 MoE 的成本描述，不論是 training 還是 inference 的成本，主要都以 activate parameters 為標準在做計算，這其實是假設了我們 MoE 引入的 communication 可以被其他 computation overlap 掉，也就是 DeepSeek v3 的 DeepEP 在做的事情，但實際上當我們 sparsity 無限增大，並且一樣開跟 Experts 數量一致的 Expert Parallel，**遲早會有一個階段 communication latency 會開始無法被 computation overlap 掉**，這個剛好跟筆者正在撰寫的另一篇文章相關，我們未來再提 XD

## 總結

目前從 Qwen3-Next 在 Huggingface Transformer 的 PR 上，我們可以看到 Qwen3-Next 主要引入了三個新的設計：

**Hybrid Gated DeltaNet****Gated Attention****High-Sparsity MoE**

而其中 High-Sparsity MoE 是當下的共識，大部分的 MoE 模型在過去兩年都持續提高 MoE Sparsity，Qwen3-Next 也沒有到一個非常誇張的離群值，因此 High-Sparsity 本身較好理解。

Gated Attention 則是一種 softmax attention 的改進版，在 weighted V 跟 o_proj 之間加入一層 gating，不只有更好的 training 效率、穩定性以及更好的 testing performance，還可以減輕 attention sink 的情況並加強 length extrapolation 的能力。

而 Hybrid Gated DeltaNet 則可能是 Qwen3-Next 大幅優化 training, inference efficiency 的主要功臣，藉由 hybrid 加入效果較優的 Linear attention 架構 Gated DeltaNet，因為 Linear attention 的本質，我們forward pass 運算量可以大幅降低，而 KV cache size 也可以減少。

Qwen3-Next 是一個引入大量新技術，具體是不是真的那麼好？我們還需要等時間來驗證，但也不影響我們更多關注包含 Linear attention 以及各種 gating 運用的新技術，而新的架構也會引入新的 training, finetuning, inference 的知識，之後筆者也會更多把 linear attention 相關技術拉進來一起討論。
