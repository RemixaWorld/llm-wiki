# 基于embedding监控机器学习系统非结构化数据漂移

- **ML监控的重要性**
  - 本文探讨了监控使用非结构化数据的深度学习系统。
  - 上期讨论了结构化数据的监控，涉及数据分布和各种距离度量（如PSI、KL散度等）。

- **监控非结构化数据中的漂移**
  - **计算机视觉**：
    - 漂移可能由于像素分布的重大变化（模糊、亮度变化、旋转、裁剪等）引起。
    - 新对象或独特场景也可能导致漂移。
  - **自然语言处理（NLP）**：
    - 新词汇、新类别、新语言及术语变化可能导致模型性能漂移。

- **嵌入（Embeddings）**
  - 嵌入是处理非结构化数据的核心，通过深度学习模型或通用模型（如BERT、GPT）来生成。
  - 基线（训练数据或历史窗口）和生产窗口的嵌入均值需计算，以便比较性能，如使用欧几里得距离等度量。

- **如何计算嵌入**
  - 嵌入可以通过深度学习或其他方法（如SVD、PCA）计算。
  - 使用自定义深度学习模型提取嵌入时，需要清楚模型的架构和提取技术。
    - CNN和Transformer模型的提取点有所不同。
  - 使用预训练模型（如BERT、GPT）更为简单，但缺乏特定用例的控制。

- **数据版本控制的重要性**
  - 不同提取方法或模型的变化可能导致嵌入的语义和维度变化。
  - 版本控制确保对数据和嵌入的管理，适用于结构化和非结构化数据。数据版本化工具（如S3 + DVC）可有效助力。
