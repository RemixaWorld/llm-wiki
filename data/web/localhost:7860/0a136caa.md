# 使用Gradio应用简单快速构建MCP服务并于Huggingface部署

本文的重点是创建个人MCP服务器，将Python函数转化为MCP，供私有API使用。
- **使用Gradio创建MCP服务器**
  - Gradio不再仅仅是一个网页应用构建工具，而是可以用来构建MCP服务器。
  - 安装Gradio：
    - 运行命令 `pip install "gradio[mcp]"` 或 `uv add "gradio[mcp]"`。

- **示例：计算投射体飞行距离**
  - 提供了一个计算投射体飞行距离的Python函数`compute_projectile_distance`，该函数接收初始速度和发射角度，返回水平距离。
  - 将此函数通过Gradio包装成MCP：
    - 使用`gr.Interface()`定义函数的输入输出和描述。
    - 启动MCP服务：调用`app.launch(mcp_server=True)`。
    - 本地访问地址是 `http://localhost:7860/gradio_api/mcp/sse`。

- **与MCP客户端的连接**
  - Gradio同时启动了应用的网页界面，访问地址为`http://localhost:7860`。点击“Use via API”可以获取与客户端连接的指令。
  - 以Claude Desktop为例：
    - 使用Node.js方法，将指令复制到Claude Desktop的配置文件`claude_desktop_config.json`。
    - 需要重新启动Claude Desktop以使改动生效。

- **测试MCP功能**
  - 提供示例提问，检验Claude Desktop通过MCP调用功能计算结果。

- **MCP的托管问题**
  - 私有MCP服务器需要托管，可以选择在Hugging Face Spaces上获得免费托管。
  - 创建Space时选择Gradio作为SDK，并在`app.launch`方法中添加`share=True`：
    - 这样可以让MCP和API能从外部访问，Gradio会提供公共URL。

- **总结**
  - 使用Gradio创建和连接MCP服务器相对简单，适合个人使用。
  - 作者已经创建了多个个人MCP，鼓励读者分享自己的经验和方法。
