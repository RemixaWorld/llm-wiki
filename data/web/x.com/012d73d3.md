# qwen2.5-coder的数据合成思路启发

1. 生成数据内容
    - 使用效果较好的模型来大规模生成数据。
    - 专注于多样性、高质量。
2. 验证
    - 使用过滤机制仅保留高质量数据。
3. 指令数据创建
    - 使用效果较好的模型根据已有数据来生成指令。
    - 根据生成的指令再生成答案。
    - 可多次进行上述两方面操作获得更具多样性的指令数据。
    - LLM评分过滤。
4. 整合
    - 结合合成数据和开源指令数据。
5. 多语言扩展
    - 使用Agent编排来跨语言制定新的指令和答案。
