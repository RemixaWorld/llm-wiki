# OpenAI的RFT（Reinforcement Fine-Tuning）的原理概述

RFT 助力推理模型（如 o1）仅需几十个示例即可学习。相较于标准的监督式微调（SFT），它在数据利用上更为高效，因为它不仅教会模型正确答案，还指导其如何进行相关推理。
- 大体流程：
    1. 收集一个具有易于验证输出（明确对错）的数据集
    2. 模型生成推理轨迹 + 输出。
    3. 评分员对每个输出进行评分。
    4. 使用 RL（如 PPO）更新模型权重，优先选择高分输出。
- 何时使用：
    1. 任务难度较高（简单任务可能无需微调）。
    2. 输出易于验证（评分明确）。
    3. 标注数据难以收集。
    
一个关键技巧是对部分正确性进行评分。例如，对于一个判断文本情感极性的文本分类问题，如果正确答案是“悲伤”，但模型将“悲伤”排在第二位而非首位，它仍可能获得部分分数。这种“更密集”的奖励信号有助于模型更快、更稳定地学习。
