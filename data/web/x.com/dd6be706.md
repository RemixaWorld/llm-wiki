# Claude提出的在RAG分块时使用LLM进行澄清可以使得RAG效果更好

也就是分块的时候使用llm结合上下文改写下块内容作为元数据，这样就能使得块内容不会因为分块丢失上下文。例子：
```
原话：“公司收入比上一季度增长了 3%。”

Claude 处理后的上下文大块：“此大块来自 ACME Corp 的 2023 年第二季度 SEC 文件。上一季度收入：3.14 亿美元。收入比上一季度增长 3%。”
```
