# 模型合并方法（model merging）小综述

通过将同结构的模型进行合并，从而得到更强的相关能力，实际上就是对模型权重值进行调整。大体可以分为几种方法：
- 线性合并（Linear Merging）：模型间采用加权线性组合的形式来合并，最基本的情况下考虑取0.5的系数，也可通过验证集来搜索相应的权重。
- 任务向量导向（Task Vectors）：权重参数之间的差值可以表示“任务向量”，通过对任务向量进行调节（取负、加减等）来实现任务整合、风格调节等。
- 其他：可能是综合了线性合并和任务向量导向，例如TIES使用任务向量来决定对权重值的操作、取舍。
