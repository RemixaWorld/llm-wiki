# llamaindex的workflow实现各种AgenticRAG的教学

通过下述两种方案，可以了解如何使用llamaindex在检索器之上封装Agentic层来实现AgenticRAG。
- 如果RAG得到的上下文不相关，则进行网络搜索并附加网络搜索结果的方法C(orrective)RAG。
    - https://www.youtube.com/watch?v=3manp6wnmL8
    - 还介绍了似乎挺好用的监控器phoenix（ https://docs.llamaindex.ai/en/stable/examples/cookbooks/oreilly_course_cookbooks/Module-5/Observability/ ），可以直接浏览每次运行的底层流程、文本、延迟等内容。
    - 方法流程：
        1. 传入query。
        2. 通过检索得到上下文。
        3. 判断上下文是否能为query提供答案。
            - 如果不能则进行网络搜索。
        4. 将上下文、网络搜索结果（如果进行了网络搜索）进行摘要。
        5. 基于摘要生成response。
- 通过few-shot指示LLM对query分析提取元数据过滤，提前使用元数据过滤出相关文档集然后才开始常规RAG。
    - https://www.youtube.com/watch?v=z3smcBXytsY
