# LLM自动化对齐方法综述

- 通过归纳偏差进行对齐
- 通过行为模仿进行调整
- 通过模型反馈进行调整
- 通过环境反馈进行调整

这是一个重要的课题，因为 LLM 的功能变得越来越强大，并且对自动化对齐的需求越来越大，而不是依赖人工注释。

论文引用：“对于自动对齐，最关键的部分是找到一个可扩展的对齐信号，它可以取代人类手动创建的偏好信号，并在 LLM 的快速发展中保持有效。”
