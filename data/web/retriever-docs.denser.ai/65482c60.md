# 通过训练过的xgboost将多个异构检索器（embedding、关键词、rerank）结果整合起来得到更优检索结果的框架Denser Retriever

探讨使用Denser Retriever，结合传统的关键词检索、向量检索和机器学习重排的混合策略，以提升检索系统的整体表现。

- **方面介绍**：
    - **关键词检索（Keyword-Based Search）**：采用BM25等传统检索技术，解决准确匹配的问题。
    - **向量检索（Vector Search with Embeddings）**：使用BERT或Sentence Transformers等模型，将文档和查询编码为高维向量，捕捉语义关系。
    - **机器学习重排（Machine Learning Re-Rankers）**：利用深度上下文理解调整候选结果的排序。
  
- **实施步骤**：
    1. **创建虚拟环境**并安装所需的库。
    2. **加载文档**：使用TextLoader将文本文件加载入系统。
    3. **文本分割**：使用RecursiveCharacterTextSplitter将文档拆分为小块。
    4. **设置Denser Retriever**：配置向量数据库（Milvus）和关键词搜索（Elasticsearch）。
    5. **文档导入**：将分割的文本导入检索器。
    6. **运行查询**：基于查询内容获取结果，并返回相关文档及其得分。
    7. **清理**：完成后清除索引以释放空间。

通过以上方法，Denser Retriever在多个基准数据集上展现了优越的表现，特别是在NDCG@20和Recall@20指标上取得了显著提升。
