# 使用llamaindex实现agentic RAG以及使用Trulens进行RAG三元评估

探讨如何使用RAG技术和LlamaIndex框架生成私有语料库，并通过评估工具TruLens衡量系统性能。
- 关键点
    - **RAG技术**：结合最新的信息生成回答，解决模型的知识截止问题。
    - **私有语料库生成**：
        - 使用GPT模型生成针对虚构公司的语料库。
        - 示例公司包括：Ukraine Boats Inc.、Nova Drive Motors等。
    - **数据库存储**：
        - 利用Neo4j数据库对生成的数据进行存储和处理。
    - **查询引擎设计**：
        - 设计了基于RAG的查询引擎，支持OpenAI和Meta Llama 3.2模型进行性能比较。
    - **性能评估**：
        - 采用RAG三元组（回答相关性、上下文相关性、基础性）进行评估。
        - 使用TruLens进行详细反馈和持续评估。
- 方面介绍
    - **私有语料库生成方法**：
        - 使用GPT模型生成虚构公司数据。
        - 生成问题和答案对以支持测试。
    - **数据库集成**：
        - Neo4j作为数据存储解决方案，支持向量搜索和信息检索。
- 实施步骤
    1. 确定生成的私有语料库。
    2. 使用GPT生成公司信息和相关问答对。
    3. 将数据存入Neo4j数据库作为向量存储。
    4. 构建基于RAG的查询引擎。
    5. 设置评估框架，使用TruLens进行性能评估。
