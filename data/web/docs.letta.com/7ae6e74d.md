# 可用于LLM长期记忆存储的框架Letta

Letta 专为构建有状态的 LLM 应用程序的开发者设计，例如：
- 需要长期记忆并随时间更新（自我编辑）人格的个性化聊天机器人（例如伴侣）
- agents 连接到外部数据源，例如私营企业部署的类似 ChatGPT 的应用程序（连接到您公司的数据），或连接到患者病历的医疗助手
- agents 连接到自定义工具，例如一个能够通过网络搜索回答最新新闻相关问题的聊天机器人
- 自动化的 AI 工作流程，例如一个agent系统，它监控您的电子邮件收件箱，并向您发送紧急邮件的短信提醒以及每日邮件摘要。

核心原理来自于MemGPT的self-editing memory（自编辑记忆）：
- 内存管理：在 MemGPT 中，一个LLM操作系统将数据移入和移出LLM的上下文窗口以管理其内存。
- 存储层次结构：“LLM OS”将LLM的内存（即其“虚拟上下文”，类似于计算机系统中的“虚拟内存”）划分为两部分：上下文内内存和上下文外内存。
- 通过工具调用的自编辑记忆：在 MemGPT 中，管理记忆的“操作系统”本身是一个LLM。LLM使用指定的记忆编辑工具在上下文窗口中移动数据。
- 多步推理借助心跳机制：MemGPT 通过“心跳”概念支持多步推理（允许agent按顺序执行多个步骤）。每当LLM输出工具调用时，它可以选择通过将关键字参数 request_heartbeat 设置为 true 来请求心跳。如果LLM请求心跳，LLM操作系统将继续在循环中执行，使LLM能够“再次思考”。
