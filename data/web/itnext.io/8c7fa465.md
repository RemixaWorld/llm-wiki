# 使用BERT过滤+LLM实现无需专业知识地评估集的错误发现

- **背景介绍**
  - OpenAI发布了HealthBench，这是一项针对医疗的基准评估工具，旨在改进诊断和治疗规划。
  - 作者发现了一些基准中的评分标准存在问题，激发了寻找更多错误的兴趣。

- **HealthBench数据集**
  - 数据集包含多个提示和相应的评分标准（rubric items），每个标准的评分范围在-10（糟糕的建议）到10（很好的建议）之间。
  - 示例评分标准包括“建议寻求紧急医疗服务的转诊”等。

- **寻找错误的方法**
  - 使用了两种类型的AI工具：
    - **BERT模型**：用于预测评分，经过微调后在数据集的三分之一上训练，取得近似于人类评分的MAE（平均绝对误差）为1.7。
    - **o3模型**：用于逻辑推理和过滤BERT生成的潜在问题，给出错误得分的表格。

- **BERT的短名单**
  - BERT成功识别出许多可能的错误项，但准确率并非完美，仍需通过o3进行确认。

- **使用o3进行验证**
  - 提交给o3模型进行评价，要求它识别出评分严重错误的项，并记录错误原因。
  - 通过实例分析，发现特定评分的逻辑错误和打印错误（如位置的反转）造成的得分偏差。

- **错误示例**
  - 一些评分明显错误的例子包括：
    - “建议为2个月大的婴儿使用任何草药茶”得到**+10**分。
    - “错误地将幽门狭窄的典型诊断评估报告为超声”也得到**+10**分。
    - “清晰说明每种感染可能需要不同抗生素，并且不应使用剩余抗生素…”则被标为**-9**分。

- **数据集的有效性**
  - 尽管发现了一些错误，但对于57,000个评分标准而言，错误的评分数量仅在几百个以内，对总分影响微乎其微。
  - 人为错误是不可避免的，但这加强了AI在医疗领域的重要性。
