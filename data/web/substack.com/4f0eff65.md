6 Open-source LLM tools you should know about and use:

➡️ Transformer Lab — Open Source LLM Toolkit: Transformer Lab is a 100% open-source toolkit for Large Language Models. You can use the Transformer Lab toolkit to train, tune, and chat with LLMs on your own Machine.

➡️ STORM: STORM is a Stanford University free AI tool for researchers. It writes Wikipedia-quality reports with 99% accuracy & citations.

➡️ LLMs.txt generator: Turn any website into a 𝐥𝐥𝐦.𝐭𝐱𝐭 file with a single URL! You can just add “llmstxt.new” in front of any URL, and it instantly crawls, cleans, and formats the content into Markdown for use in RAG pipelines, AI agents, and LLM training or inference.

➡️ YourBench: YourBench is an open-source framework for generating zero-shot benchmarks from your own documents. It helps you test language models on custom domains using automated pipelines for ingestion, summarization, and question generation.

➡️ LiteLLM: Through LiteLLM, you can call all LLM APIs using the OpenAI format [Bedrock, Huggingface, VertexAI, TogetherAI, Azure, OpenAI, Groq, etc.].

➡️ LoRAX: Multi-LoRAX (LoRA eXchange) is a framework that allows users to serve thousands of fine-tuned models on a single GPU, dramatically reducing the cost of serving without compromising on throughput or latency.
