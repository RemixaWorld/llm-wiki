# How to build AI agents to automate web browsing with human level reasoning? An Introduction.

One step towards building AGI is creating agents that can browse the internet, talk to APIs, submit forms etc. And if they can do this with human level reasoning, we’ll be darn close to that AGI.

In this article we will explore how we can take first steps in building such an agent. And even if we can’t build AGI level yet, we will try to build agents that can at least do simple things like web scraping, software testing etc. Along the way we might be able to answer how to build AGI level web agents. Hint: It involves raising 7 trillion for mass chip manufacturing by Sam Altman. Anyway let’s start.

The primary ingredient we need is a tool through which we can automate web browsing. There are couple of options but most popular ones are Selenium, Playwright and Puppeteer. These tools are usually used to write tests for automated testing on multiple browsers. But lot of people use them for scraping, automating repetitive tasks and so on. They are really powerful tools built upon Browsers or Browser engines.

Here is an example of how a simple script in playwright works

`from playwright.sync_api import sync_playwright`


with sync_playwright() as p:

browser = p.chromium.launch(headless=True)

page = browser.new_page()

page.goto('https://example.com')

title = page.title()

browser.close()

print(title)

When run this will automatically go to example.com and print the title of the page.

In my opinion to build a system which can browse automatically we need to build a system where we can run playwright in such a way that LLM writes one step to perform a process at a time, playwright performs that step, LLM checks what comes after that step based on current webpage and then creation and execution keeps happening in a loop.

For example if we tell an agent to go to some website. Find all emails and print them. The agent has to first browse that website, look at the source code and then extract all the emails.

In order to do this we need some to and fro communication between browser and the executable code. Such that the browser executes and send back the source of the html page, and at the receiving end the backend creates next line of code to be executed.

The best place to take inspiration with a similar system is a VSCode Python Debugger. There we can execute one line at a time and the pointer keeps moving onto the next step. Similar debugger is available with Playwright too.

We need a similar system where we execute one line at a time. After that execution AI generates the next line and we keep moving forward.

The most important function to do this will be the exec function in python. It can execute the AI generated code string one at a time.

So in summary here are the steps that could make automated browser:

- Give the main prompt and current html(if step>1) to Code generator.
- Code is generated. Run the code with the browser engine.
- Scrape the new HTML and clean it.
- Repeat Step 1.
