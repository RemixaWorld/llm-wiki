# 为数据隐私考虑的信息编辑或匿名化的开源工具

文档编辑和匿名化都涉及更改文档以保护敏感信息。编辑侧重于删除机密详细信息，而匿名化则侧重于一般隐私保护，例如通过删除或替换个人身份信息。
- 开源工具：
    -  OpenNyAI（ https://github.com/OpenNyAI/legal_docs_redaction ）：该开源模型通过屏蔽使用机器学习识别的命名实体，为法律文档提供离线半自动数据编辑。编辑过程的输出必须由人工审核，以确保所有敏感信息都已被正确屏蔽
    - Codexify（ https://github.com/DataFog/codexify ）：Codexify 使用户能够使用各种编辑方法（例如固定字符串、随机值和哈希函数）编辑 CSV、Excel 和 JSON 文件中的敏感数据。这可确保从文件中删除敏感数据，同时保留剩余数据的完整性。
    - Phileas（ https://github.com/philterd/phileas ）：Phileas 是一个 Java 库，可从文本中编辑个人身份信息 (PII)、受保护的健康信息 (PHI) 和其他敏感信息。该图书馆分析文本以识别敏感信息，例如姓名、年龄和地址。
    - Fuko Masked（ https://github.com/fuko-php/masked ）：Fuko\Masked 是一个用于屏蔽敏感数据的小型 PHP 库：它将黑名单元素替换为经过编辑的值。
    - Redact Engine（ https://github.com/rusty-ferris-club/redact-engine ）：通过替换字符串或 JSON 格式 API 文档中的敏感数据，通过动态编辑来保护机密性。
    - PDF Redaction（ https://github.com/ABCpdf-Team/PDF-Redaction ）：PDF 中文本编辑的开源模型。
