# windows使用配置WSL使用unsloth来微调模型

windows使用unsloth的要点在于：
1. 在windows商店中下载WSL。
2. 进入WSL。
3. 确认WSL有权访问GPU：`nvidia-smi`。
    - 出现NVIDIA驱动内容为正常访问。
    - 如果没出现，则需要去`https://www.nvidia.com/en-us/drivers/`查找适配的驱动并安装，然后使用`nvcc --version`查看是否成功安装。
4. 安装C编译器（C compiler）：`sudo apt-get update && sudo apt-get install build-essential`。
5. 安装python-dev环境：`sudo apt-get update && sudo apt-get install python3-dev`。
